# Step 2: Install Neutrinos Studio

<https://documentation.neutrinos.com/articles/#!build-an-app-on-neutrinos-platform/install-neutrinos-studio>

After you get access to the Neutrinos Platform, install the **Neutrinos Studio** - the IDE for developing apps. Perform the following steps:

1. Sign in to [Neutrinos Console](https://console.neutrinos.co/) with your username and password. Neutrinos Console is the portal which allows you to:
  - Download the Neutrinos Studio to build apps
  - Access, manage, build, and deploy apps on Cloud using the** 1-click Serverless deployment **feature.
  - Manage your organization's users and teams.
  - Access the Neutrinos Knowledge Center
2. On the **Home** page of the Neutrinos Console, choose your operating system and click the** Download** button to download Neutrinos Studio. The executable file gets downloaded to your local machine.
    ![Comsole homepage](/resources/Storage/build-an-app-on-neutrinos-platform/app-builder-s-user-guide/console_new.png)
3. Install the software. The steps may differ based on the operating system you are using. On windows, double click the executable file to open the installer and install the software.
    ![neutrinos install page](/resources/Storage/build-an-app-on-neutrinos-platform/neuinstall.png)
4. Choose the destination folder and click **Install**.
5. Neutrinos Studio gets installed on your machine.
6. Launch the studio. You will be directed to the Studio home page.
    ![studio homepage](/resources/Storage/build-an-app-on-neutrinos-platform/studio%20homeage.png)
