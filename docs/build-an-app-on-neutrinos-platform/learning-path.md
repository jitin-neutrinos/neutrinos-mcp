# Build a Simple Web App

<https://documentation.neutrinos.com/articles/#!build-an-app-on-neutrinos-platform/learning-path>

**Neutrinos is a multi-experience, low- code application development platform which enables Enterprises, Startups, Independent Developers, and Citizen developers to build a wide range of complex enterprise-grade applications.**

This learning path will provide you an overview of what you can do using the Neutrinos Platform.

Completing this path and building a simple app will provide you with a bigger picture of the features and capabilities of the platform and lets you explore what you can achieve with the platform.
