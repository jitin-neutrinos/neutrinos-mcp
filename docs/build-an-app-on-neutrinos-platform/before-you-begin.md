### Read the Free Trial terms

Free trial terms:

- The registered user is provided with the Organization Admin or organisation admins privileges. An organisation admins can onboard any number of users to the platform to evaluate.
- A total of 5 apps can be created and deployed on the cloud.
- A user can design and deploy Web and Mobile apps (Android only). The iOS build is not available.
- [Neutrinos Support](mailto:support@neutrinos.co) will assist in onboarding a Client's organization (organisation admins of the organization) on receiving the free trial request.
- Upload and download of documents in the app will not be supported.
- Apps deployed on the cloud cannot be deleted by the user.
- Only one build can be scheduled at a time for a given app.
- On Neutrinos Console, any team name starting with** Neutrinos** is reserved for only the Neutrinos organization.
- New deployments will override all previous deployments irrespective of the type of build.

### Install the Required Software

Read the purpose of the software before installing it. If you want to create a web app, a few software are not required to be installed.

| **Software** | **Purpose** | **Version** | **Description** |
| --- | --- | --- | --- |
| **Node.js** | Required for installing dependencies for Neutrinos Studio and additional software. | Supported versions- 10.13.0 to 12.x.x | NPM is bundled with Nodejs. [Download](https://nodejs.org/en/download/releases/)[Installation Guide](https://nodejs.org/en/download/package-manager/) |
| **Angular CLI** | Required for running the designed app locally. | Supported versions- 8.x.x | [Download](https://github.com/angular/angular-cli#installation)[Installation Guide](https://cli.angular.io/) |
| **Cordova** | Required for generating hybrid mobile apps locally. | Supported version- 9.x.x | [Download](https://cordova.apache.org/)[Installation Guide](https://cordova.apache.org/#getstarted) |
| **Android Studio** | Required for generating and emulating android specific hybrid applications locally. | Supported version- 3.1.x or later | [Download](https://developer.android.com/studio/install.html)[Installation Guide](https://developer.android.com/studio/install) |
| **Java ** | Required to run Andriod builds. | Supported version - 1.8 | [Download](https://www.java.com/en/download/) |
| **Gradle** | Required to run Andriod builds. | 6.1 or later | [Installation Guide](https://gradle.org/install/) |
| **Git** | Required for collaboration | Supported version- 2.17.x or later | [Download](https://git-scm.com/downloads)[Installation Guide](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git) |
