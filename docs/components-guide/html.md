## HTML

OverviewHTML component is a container component for user written HTML code.**Usage**The HTML component is used when a user wants to define elements other than the already available components in the neutrinos platform.How to useDrag and drop the **HTML** component from the **Advanced** Category where it is needed on that page.Double click on the **HTML** component and fill it with the HTML code.Save the changes.ExampleCreate a page called **page**.Drag and drop the **HTML** component.Double click on that component.Write the below code. <h1>This is H1 tag of html</h1>Save the changes.**Support****Devices:** Android, iOS**Browsers:** Latest version of all modern browsers**Dependencies version:**Angular CLI version: 6.0.0 +Cordova version: 7.1.0 +
