## Overview

In the release 5.0.0 of Neutrinos Studio, we have introduced the following Advanced components and have enhanced the existing attributes window.

- Card components such as Card Header, Card Footer, Card sub-title, etc are grouped into a single **[Card](/articles/components-guide/card5)** component.
- A **[Table](/articles/components-guide/tables)** component is added to the palette which allows you to add columns, filters, paginators, and droppable columns to the page.
- You can validate a user's input and configure **[Error](/articles/components-guide/input5)** for Select, Input, Date Picker components using their respective attributes window.
