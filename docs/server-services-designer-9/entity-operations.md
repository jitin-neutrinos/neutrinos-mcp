# Entity Operations

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/entity-operations>

To generate a Data Model Endpoint follow these steps:

1. In the neutrinos studio, navigate to data models and add a data model.
2. Once the data model is added, click on the ![](/resources/Storage/server-services-designer-9/entity-operations-2023-04-27.png) icon.
3. Click on Add operations.
4. Click on the edit icon to edit the properties of the end point.

![](/resources/Storage/server-services-designer-9/Operations.png)

5. Select the DM Processor node.

6. Click **Save**.

| ![Information](/resources/Storage/server-services-designer-9/info.png) | The Mock data values can be filled using database admin tool or swagger docs available within Neutrinos studio. |
