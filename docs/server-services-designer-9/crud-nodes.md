# CRUD nodes

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/crud-nodes>

Working with databases and entities involves performing daily data-related tasks using the database operations to re-use, manipulate, and access data later. For example, you can create a new entity, rerieve information of the enitiy, or delete if needed.

Data Model CRUD nodes are used to create custom HTTP endpoints to perform Database Operations on a data model that includes,

1. CREATE node
2. FIND node
3. UPDATE node
4. DELETE node
5. Processor node

All CRUD nodes comes with a properties window to configure associated attributes for an operation. These nodes can further be combined with other Server-Side-Designer nodes to create a custom HTTP CRUD operation requests.
