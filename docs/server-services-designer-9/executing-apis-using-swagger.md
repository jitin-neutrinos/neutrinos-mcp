# Executing APIs using Swagger

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/executing-apis-using-swagger>

Follow the steps given below to execute the APIs using Swagger tool.

1. Select the Initialize button from the drop-down list and click on play.
   ![](/resources/Storage/server-services-designer-9/executing-apis-using-swagger-2023-05-05-5.png)
   A new server is initialized. You will need to wait until the initialization is complete.
2. Once the initialization is completed, select the live view button from the drop-down list and click on play.
   ![](/resources/Storage/server-services-designer-9/executing-apis-using-swagger-2023-05-05-6.png)
3. Click on the ![](/resources/Storage/server-services-designer-9/executing-apis-using-swagger-2023-05-05-7.png)icon and navigate to swagger docs.
4. Swagger docs will be opened in the browser.
   ![](/resources/Storage/server-services-designer-9/executing-apis-using-swagger-2023-05-05-8.png)
5. Access and execute the required APIs.
