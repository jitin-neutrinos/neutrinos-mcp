# Nodes Journey

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/nodes-journey>

The process begins by logging into Neutrinos studio and viewing the different types of nodes.

![](/resources/Storage/server-services-designer-9/Main%20Screen.png)

To search for a specific node, type a text relevant to its configuration, for example **Sql**, and click Search.

Click Clear to reset the search criteria.
