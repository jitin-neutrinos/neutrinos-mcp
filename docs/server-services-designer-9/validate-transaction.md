# Validate Transaction

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/validate-transaction>

The service is named as **Validate Transaction** and consists of a flow that will help you validate transactions related to customer policy.

![](/resources/Storage/server-services-designer-9/validate-transaction-2023-05-04.png)

The validate Transaction flow has to be triggered using Data Model. Use the step-by-step instructions given below to trigger the flow:

1. Navigate to Data Model > Transaction table.

2. Click on the ![](/resources/Storage/server-services-designer-9/icon.png) corresponding to operations.

3. Hover next to any operation.

This displays the edit operation icon.

![](/resources/Storage/server-services-designer-9/edit.png)

4. Click on the edit icon.

The Operation Properties window is displayed.

![](/resources/Storage/server-services-designer-9/validateflow.png)

5. Click on the arrow corresponding to validate_transaction and navigate to flow.

The validate transaction in the Data Model is now triggered.

![](/resources/Storage/server-services-designer-9/valtransaction.png)
