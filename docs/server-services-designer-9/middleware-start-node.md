# How to use

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/middleware-start-node>

A **Middleware Start** node is used to create a flow on the services that can be used in the middleware sequence.

### How to use

- Open the Services editor window.
- Click the** plus icon** to add Service or open an existing server service from the service list.
- In the Nodes Palette, drag and drop a **Middleware Start** node to the workspace.
- Drag and drop other nodes to create a flow. Make sure the flow starts with a **Start node** or an **HTTP In** node.

### Associated Attributes

- **Name:** Unique name for the node.This name will display on the canvas when you save the node.
