# Create an API only app

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/create-an-api-only-app>

To Create an API only app:

1. Click on the ![](/resources/Storage/server-services-designer-9/create-an-api-only-app-2023-05-02.png)icon within the Studio Home page.
   The Create New App pop-up window is displayed.
   ![](/resources/Storage/server-services-designer-9/APIonlyapp.png)
2. Enter the following details within the app details pop-up window:

- **App Name**: Enter the name of the app. The app name must have a minimum of 6 characters with no special characters except the hyphen (-).
- **Version**: Enter the app version. By default, the value is 1.0.0.
- **Tenant**: The application tenant. Each customer organization is called a tenant. By default, the tenant is neutrinos.
- **Description**: Enter a brief description of your application.
- Upload a preview image of your app. Select an image from your local machine.
