# Create Tables in Database

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/create-tables-in-database>

After creating services, a table needs to be created within the database.

Follow the steps given below to create a table within the database:

1. Navigate to the Data Model and Initialize the app.
   ![](/resources/Storage/server-services-designer-9/create-tables-in-database-2023-05-05-2.png)
2. Right click on the Data Model name and download DDL's.
   ![](/resources/Storage/server-services-designer-9/create-tables-in-database-2023-05-05-3.png)
3. The downloaded DDL’s will generate sql scripts for the tables that are created for data models.
4. Use the generated scripts to create tables in your database.
