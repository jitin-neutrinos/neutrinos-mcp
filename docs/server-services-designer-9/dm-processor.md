# DM Processor

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/dm-processor>

The DM Processor node is used to interpolate custom flows that are executed during an operation. DM processor nodes can also be used to create service flows that can be used as the processor flow for the abstract data models.

To use a DM Processor node:

1. Navigate to the Server Services editor window.

![](/resources/Storage/server-services-designer-9/Services.png)

2. Click the ![](/resources/Storage/server-services-designer-9/dm-processor-2023-04-27.png)button to add a new service.

3. In the Data Model Nodes Palette drag and drop the Processor node.

![](/resources/Storage/server-services-designer-9/DM%20Processor.png)

| ![Information](/resources/Storage/server-services-designer-9/info.png) | By default Bh Variables in the processor node are defined as output variables. |
