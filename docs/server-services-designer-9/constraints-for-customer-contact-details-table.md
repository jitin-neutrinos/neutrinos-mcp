# Constraints for Customer Contact Details

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/constraints-for-customer-contact-details-table>

Add a unique constraint named **unique_contact**. By default a constraint named **default_customer_contact** is added by Neutrinos studio.

| ![Information](/resources/Storage/server-services-designer-9/info.png) | The default constraints are auto-populated within the neutrinos studio. Once a relation is drawn, the default constraints will be read-only. |
