# Creating Services

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/creating-services>

Services contain one or more flows and each flow consists of nodes that perform an operation. The flow consists of nodes that perform operations and helps achieve the end result that you want your server flow to perform when executed.

The following services are created to showcase the usage of DM Nodes :

- [Create Policy](/articles/server-services-designer-9/create-policy)
- [Get Policy](/articles/server-services-designer-9/get-policy)
- [Remove Customer](/articles/server-services-designer-9/remove-policy)
- [Update Contact Details](/articles/server-services-designer-9/update-contact-details)
- [Validate Transaction](/articles/server-services-designer-9/validate-transaction)
