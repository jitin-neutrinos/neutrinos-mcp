# Adding Operations to Entities

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/adding-operations-to-entities>

Entity Operations allows you to add basic CRUD operations, while being extensible to allow any kind of custom operation.

The entity operations have to be added to the following tables:

- Agent
- Policy
- Claims
- Transaction
- Customer
- Customer Contact Details

To add an entity operation:

1. In the Neutrinos studio, navigate to the Data Model.

2. Click on the ![](/resources/Storage/server-services-designer-9/continue.png)corresponding to an entity table.

The add operations feature is displayed.

![](/resources/Storage/server-services-designer-9/addoperations.png)

3. Click on add operations.

The CRUD operations are automatically added.

| ![Information](/resources/Storage/server-services-designer-9/info.png) | The operations field must be added to all the mentioned tables. |
