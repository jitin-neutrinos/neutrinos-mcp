# Edit Database Model

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/er-model-properties>

A Database model is a representation of data entities, attributes, and the association between them. With Neutrinos database models, users can design an Entity-Relationship Model which is further deployed in a database.

To create a Database Model,

1. Add a new Data model using the Data Model Explorer.
2. Data Model Properties window is displayed.
3. Choose Database Model.

| ![Information](/resources/Storage/server-services-designer-9/info.png) | Users must configure a database by adding a new database or adding an existing database to the data model. |
| --- | --- |

### Edit Database Model

### Right-click on a database model in the explorer to perform the following actions

- **Save **- allows you to save the database model
- **Discard** - allows you to discard all changes in the data model
- **Rename** - enables you to rename the database model
- **Delete **- enables you to delete a database model
- **Download DDL's** - enables you to download the data-definition-language for a database model.
