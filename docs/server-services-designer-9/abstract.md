# Edit Abstract Model

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/abstract>

Abstract Model is a database model without an underlying database. Abstract models are designed to model and validate the data before sending it to any third party server, External APIs, web pages or internal APIs.

Downloading Data Definition Language functionality is not available for abstract models as this type of data model does not include a database.

To create an Abstract Model,

1. Add a new Data Model using the Data Model Explorer.
2. The Data Model Properties window is displayed.
3. Choose Abstract model.

### Edit Abstract Model

Right-click on a abstract model in explorer to perform the following actions,

- **Save **- allows you to save the database model
- **Discard** - allows you to discard all changes in the data model
- **Rename** - enables you to rename the database model
- **Delete **- enables you to delete a database model
