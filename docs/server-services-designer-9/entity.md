# Entity

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/entity>

An entity is anything real or abstract about which we want to store data. Entity types fall into five classes: roles, events, locations, tangible things or concepts. E.g. employee, payment, campus, book. Neutrinos data model allows you to create entities, add attributes, define constraints, and perform entity specific actions.

To Create an Entity:

1. Navigate to Data Model.
2. Add a Data Model.
3. From the data model editor toolbar, Click **Add Entity**.

![](/resources/Storage/server-services-designer-9/AddEntity.png)

**Note: ** An  attribute "id" is created as a primary key by default when you create a new entity, which gets auto-incremented whenever a new record is inserted.

**Entity Actions**

Within the entity the following actions are performed:

![](/resources/Storage/server-services-designer-9/Entityactions.png)

- **Delete Entity**: enables you to delete an entity
- **Add Operations** : enables you to add an entity [operation](/smart/project-concepts/operations).

Editing an Entity

1. Navigate to Neutrinos studio.
2. Click on the ![](/resources/Storage/server-services-designer-9/entity-2023-04-27.png)icon corresponding to a data model.

![](/resources/Storage/server-services-designer-9/Editentity.png)

3. Make necessary changes and click **Save**.
