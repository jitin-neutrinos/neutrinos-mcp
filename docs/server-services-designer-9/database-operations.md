# DM Nodes

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/database-operations>

Data Model CRUD nodes are fully functional units that encompasses Data Model, Entity and objects to be used to create custom HTTP endpoints to perform Database Operations.

Data Model Nodes includes:

- [INSERT node](/articles/server-services-designer-9/insert-node)
- [FIND node](/articles/server-services-designer-9/find-node)
- [UPDATE node](/articles/server-services-designer-9/update-node)
- [REMOVE node](/articles/server-services-designer-9/delete-node)
- [Processor node](/articles/server-services-designer-9/processor-node)
- [Validate Node](/articles/server-services-designer-9/validate-node)

Using the intuitive properties window of the data Model nodes you can seamlessly configure associated attributes for a node. These nodes can further be combined with other Server-Side-Designer nodes to create a custom HTTP requests.
