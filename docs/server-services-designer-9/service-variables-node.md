# How to Use

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/service-variables-node>

The **Service Variable** node is used to set and get service variables of the flow. These variables are used to store data that can be accessed outside the flow without executing the flow.

### How to Use

- Open the Services editor window.
- Click the** plus icon** to add a new server-service or open an existing service from the service list.
- In the Nodes Palette, drag and drop a **Service Variable** node to the workspace.
- Drag and drop other nodes to create a flow. Make sure the flow starts with a **Start node** or an **HTTP In** node.

### Associated Attributes

- **Name****: **The name of the node.This name will display on the canvas when you save the node.
- **Operations: **The type of operation the node should perform.
- **Variables list**: Displays the list of variables added for the particular operation type.See [Properties](/articles/server-services-designer-9/properties-in-server-services) to learn more.
