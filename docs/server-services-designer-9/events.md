# Events

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/events>

**Pub Sub Server **or** Events **nodes are used for publishing and subscribing to messages. They have an asynchronous communication method in which messages are exchanged between applications without knowing the identity of the sender or recipient. This helps keep your program predictable as the originator of topics will not be blocked while consumers process them.

The Event nodes are:

- [Emit node](/articles/server-services-designer-9/emit)
- [Listen node](/articles/server-services-designer-9/listen)
