# Adding Entities

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/adding-entities>

Once the database model is created, add multiple entities for each parameter. The following entities need to be created and configured:

- Agent
- Policy
- Claims
- Transaction
- Customer
- Customer Contact Details

For more information on adding an entity, refer to the [Entity](/articles/server-services-designer-9/entity) section within this document.
