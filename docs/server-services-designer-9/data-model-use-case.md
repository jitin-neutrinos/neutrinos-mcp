# Data Model Use Case

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/data-model-use-case>

In this use case we have provided detailed information about building an insurance data model. The purpose of this use case is to give you a taste of what it's like using a data model and understand the key considerations used when building it.

**Prerequisites**:

Basic understanding of the DBMS concepts and usage provided in this guide.
