# Attributes

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/attributes>

An attribute identifies, names and defines a characteristic or property of an entity type. For example an Item entity type will have an ItemID attribute as a unique identifier. An attribute cannot exist independently from an entity type. Accordingly all attributes are always identified and shown as part of entity types. w.r.t. databases, attributes act as a column in an entity.

By default each entity consists of a primary key id attribute.

To add an attribute:

1. Create an [entity](/smart/project-concepts/entity).
2. Click on ![](/resources/Storage/server-services-designer-9/attributes-2023-05-02.png).
3. Define attribute type and properties.
