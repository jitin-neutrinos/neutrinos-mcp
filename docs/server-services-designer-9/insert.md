# Insert

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/insert>

Insert node is used when service flows are created to insert a new record in an entity of a Data Model.

To use an Insert node:

1. In the Neutrinos studio, navigate to the Server Services editor window.

![](/resources/Storage/server-services-designer-9/services.png)

2. Click the ![](/resources/Storage/server-services-designer-9/insert-2023-04-28.png)button to add a new service.

3. In the Data Model Nodes Palette drag and drop the Insert node.
