# Adding Constraints

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/adding-constraints>

Constraints are a very important feature in a data model. It is an expression of a rule that restricts what is permissible. They are used for modeling limitations on the relations between entities.

For detailed information related to adding constraints, refer to the [Constraints](/articles/server-services-designer-9/constraints) section within this document.
