# Data Definition Language

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/data-definition-language>

Data definition languages are the scripts used to create or re-create database schema objects. With Neutrinos Data Model editor, you can easily download the data definition language (DDL) statements for a Database Model.

To generate DDL of a database Model:

### 

1. Navigate to Data Model Explorer.
2. Right click on the Data Model.

![](/resources/Storage/server-services-designer-9/ddl.png)

3. Click on Download DDL's
