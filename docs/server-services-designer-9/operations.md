# Operations

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/operations>

Neutrinos Data Model Editor allows you to seamlessly create HTTP endpoints for all the CRUD operations which facilitate interaction with the database by communicating using REST APIs. Keeping in mind that you may need to inject custom validation (such as Authentication methods) into the HTTP endpoints to meet your application need, the data model editor provides you with the ability to configure middleware to be executed before the endpoint execution takes place and pre and post-execution flow to be executed during the database operation and bind them to your endpoint to alter the behavior of the HTTP request.

Click on Entity Action ![](/resources/Storage/server-services-designer-9/operations-2023-04-27.png)to add operations to an entity.
