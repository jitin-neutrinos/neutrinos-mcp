# Database Structure

<https://documentation.neutrinos.com/articles/#!server-services-designer-9/database-structure>

The sample database structure provided below depicts the database layout for an insurance provider.

![](/resources/Storage/server-services-designer-9/DM%20Usecase.png)

Let us understand each of these tables, how they are built and the functionalities associated with them.

To create a Database Model:

1. Add a new ERD in the Data Model Explorer.
   ![](/resources/Storage/server-services-designer-9/database-structure-2023-05-05-1.png)
   The ER Model Properties window is displayed.
2. Select the Data Model Type as Database Model.

Editing a Database Model:

- Save - allows you to save the database model.
- Discard - allows you to discard all changes in the data model.
- Rename - enables you to rename the database model.
- Delete - enables you to delete a database model.
- Download DDL's - enables you to download the data-definition-language for a database model.
