## Get Information

Use this API to get information about Neutrinos Art. This APi is similar to the PING command and notifies to the user if Neutrinos Art is up and running. It also displays some basic information about Neutrinos Art, such as the version number.


 GET/info

 **Responses:**



 **Code**

 **Description**


 200

 Operation Successful


 401
 Unauthorized. Failed to fetch the information.






 See [Status Codes](/articles/neutrinos-art-api-reference-guide/status-codes) for more information about HTTP status codes.
