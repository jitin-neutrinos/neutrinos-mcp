## Learn About Neutrinos Art

ART stands for Application Run Time. It is the API run time engine of Neutrinos which contains all the REST Services (CRUD DB Operation), Rendition Engine for all UI, Smart Libraries, and a set of APIs. It supports deployment on multi-platform of operating systems including Mac, Linux, and Windows.

Neutrinos Art stores and manages all the applications, data models, security constraints, and configurations built on Neutrinos Studio. It is deployed in NodeJS, and is ReSTful (Representational State Transfer) and stateless engine which solely communicates with JSON messaging making it easy to integrate with any external application.

Neutrinos Art is platform agnostic and maintains no session states. All the session management is performed by individual clients based on their requirements, and the operating system or device constraints. SlamData Reporting, a key component of Neutrinos Art, employs the industry’s most advanced pushdown technology to keep data processing and analytics close to Big Data. It helps you perform embedded reporting, data discovery, operational analytics on large dataset volumes.

Once the application is built using Neutrinos Studio and Neutrinos Modelr, it can be hosted on Neutrinos Art. After which Neutrinos Art can be deployed on clusters configured with failover capabilities of active-active clusters or active-passive clusters as required by you.
