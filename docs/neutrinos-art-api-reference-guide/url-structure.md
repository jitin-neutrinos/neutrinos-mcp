## URL Structure

Use the following URL structure to access the Neutrinos Art REST endpoints:

Copy CodeHTMLhttps://host_name:port_number/context-path/endpoint-path

Where:

host_name:port_number is the Host name or the IP address where Neutrinos Art is running. The port_number is the port which was configured when Neutrinos Art was setup. You can configure these parameters in the Neutrinos Art configuration file.context-path is the base path which was set up for Neutrinos Art . The default value is bhive-art.endpoint-path is the API that you want to call.
