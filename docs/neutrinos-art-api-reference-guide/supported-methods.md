# Supported Methods

<https://documentation.neutrinos.com/articles/#!neutrinos-art-api-reference-guide/supported-methods>

## Supported Methods

You can manage Neutrinos Art using standard HTTP method requests, as summarized in the following table.

| Method | Description |
| --- | --- |
| GET | Retrieves information from Neutrinos Art. For example, retrieve information about the tenant name, or namespace. |
| POST | Performs operations on Neutrinos Art. For example, specify the connection URL to the database. |
| `Delete` | Deletes the information in Neutrinos Art . For example, delete a data model based on the data model ID. |
| Put | Adds information to Neutrinos Art . For example, add data to a data model. |
| Patch | Makes partial changes to existing information on Neutrinos Art. For example, update the existing data model object value in Neutrinos Art. The PUT method only allows a complete replacement of a document. Whereas a PATCH request is used to make changes to a part of the data model. |
