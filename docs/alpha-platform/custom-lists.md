# Create Custom List

<https://documentation.neutrinos.com/articles/#!alpha-platform/custom-lists>

Custom lists are user-defined lists created by admins using existing filters. These lists can be shared with specific user groups or made visible to all users, based on requirements. This topic outlines how admins can create, edit, and update custom lists in the Admin module of Neutrinos Alpha.

## Create Custom List

The following steps outline the process for defining a custom list in the Admin module.

1. In the Admin page, click Custom Lists from the left navigation menu. This opens the Custom Lists page, which displays the lists created by admin. The custom lists are shown in a tabular format with the following details:
    ![alpha-custom-lists-landing-page](/resources/Storage/alpha-platform/images/alpha-custom-lists-landing-page.png)
    A search bar is available to find custom lists on the platform. Additionally, pagination and the number of custom lists displayed per page can be customized using the options on the Custom Lists page.
    If no custom lists are available, an empty Custom Lists page is displayed. Admins can create a new custom list by either clicking the Add button at the top of the page or the Add New Custom List button within the table.
    ![alpha-custom-lists-empty](/resources/Storage/alpha-platform/images/alpha-custom-lists-empty.png)
  - **Name**: Displays the name of the custom list.
  - **Description**: Displays the description specified when the custom list was created.
  - **Source**: Displays the type of inbox list for which the custom list was created.
  - **Groups**: Displays the groups to which the custom list applies. Users in these groups can use the custom list filter created by the admin.
  - **Users**: Displays the total number of users across all groups who can use the custom list.
  - **Created at**: Displays the date and timestamp when the custom list was created.
  - **Updated at**: Displays the date and timestamp of the most recent update to the custom list.
  - **Actions** contains the kebab icon, which allows you to edit or delete a custom list.
2. On the Custom Lists page, click the Add button in the top-right corner to create a new custom list.
    ![alpha-custom-lists-add](/resources/Storage/alpha-platform/images/alpha-custom-lists-add.png)
3. In the Create Custom List page that is displayed, provide the below details:
    ![alpha-custom-lists-create-list](/resources/Storage/alpha-platform/images/alpha-custom-lists-create-list.png)
  - **List name**: Enter the name for the custom list.
  - **Description**: Enter the description for the list.
  - **Select the List**: From the **Choose the List Source** dropdown, select the type of inbox list to which the custom list applies.
      ![alpha-custom-lists-create-list-choose-list](/resources/Storage/alpha-platform/images/alpha-custom-lists-create-list-choose-list.png)
  - **Add Filters**: Add filters to define the custom list. Select the required filters from the available options to configure the list as needed.
      ![alpha-custom-lists-create-list-add-filter](/resources/Storage/alpha-platform/images/alpha-custom-lists-create-list-add-filter.png)
  - **Choose Groups**: Select the user group(s) that can access the custom list.
      ![alpha-custom-lists-create-list-select-groups](/resources/Storage/alpha-platform/images/alpha-custom-lists-create-list-select-groups.png)
  - **Choose User**: Select the required users from the list. The selected users will have permission to view or use the custom list.
      ![alpha-custom-lists-create-list-select-users](/resources/Storage/alpha-platform/images/alpha-custom-lists-create-list-select-users.png)
4. After entering the required details, click the Create button at the bottom of the Create Custom List page. The new custom list will now appear in the table of available custom lists.
    ![alpha-custom-lists-create-list-create-button](/resources/Storage/alpha-platform/images/alpha-custom-lists-create-list-create-button.png)

## Edit Custom List

This section outlines the step-by-step process for editing an existing custom list.

1. On the Admin page, click Custom Lists from the left navigation menu to open the Custom Lists page.
    ![alpha-custom-list-navigate-custom-list](/resources/Storage/alpha-platform/images/alpha-custom-list-navigate-custom-list.png)
2. Locate the required custom list from the available lists on the platform.
    ![alpha-custom-list-locate-list](/resources/Storage/alpha-platform/images/alpha-custom-list-locate-list.png)
3. In the Action column, click the kebab icon and select Edit.
    ![alpha-custom-list-edit-option](/resources/Storage/alpha-platform/images/alpha-custom-list-edit-option.png)
4. On the next page, update the custom list details such as the name, description, users, and/or groups as required.
    ![alpha-custom-list-edit-list](/resources/Storage/alpha-platform/images/alpha-custom-list-edit-list.png)
5. After updating the details, click the Update button at the bottom of the page.
    ![alpha-custom-list-edit-update-button](/resources/Storage/alpha-platform/images/alpha-custom-list-edit-update-button.png)

Additionally, to delete a custom list, click the Delete option from the kebab icon in the Action column.




 ![alpha-custom-list-delete-option](/resources/Storage/alpha-platform/images/alpha-custom-list-delete-option.png)
