# Workbench User Manual

<https://documentation.neutrinos.com/articles/#!alpha-platform/workbench-user-manual>

The **Workbench **in the Neutrinos Alpha Platform is typically a low-code/no-code environment that provides developers with a workspace to build and configure applications efficiently.

This section discusses various concepts related to Workbench Neutrinos Alpha Platform

| [Case Assignment and Task States](/articles/alpha-platform/case-assignment-and-task-states) | A brief about case assignment and states of tasks. |
| [Layouts, Categories and Forms](/articles/alpha-platform/layouts-categories-and-forms) | Layout for task pages. |
| [Global Pages](/articles/alpha-platform/global-pages) | A reusable layouts or components that can be used across tasks. |
| [Navigation Links](/articles/alpha-platform/navigate-links) | Navigate across the platform or to an external link using Main Menu or Headers in Workbench. |
| [Task Allocation](/articles/alpha-platform/task-allocation) | Distribute tasks effectively either manually or using Task Automation System. |
| [Workbench Glossary](/articles/alpha-platform/workbench-glossary) | Contains Key Terms used in Workbench |
