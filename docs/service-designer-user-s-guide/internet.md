# Internet Resolver

<https://documentation.neutrinos.com/articles/#!service-designer-user-s-guide/internet>

The **Internet** nodes are used to check the browser's access to the Internet. It comprises two nodes:

- [Is Online](/articles/service-designer-user-s-guide/is-online-node)
- [On Online](/articles/service-designer-user-s-guide/on-online-node)
- [On Offline](/articles/service-designer-user-s-guide/on-offline-node)
