bh.system.localStorageService allows you to access the data stored in the local storage of the client. The stored data is saved across browser sessions. localStorage is similar to [sessionStorage](/articles/service-designer-user-s-guide/system-sessionstorageservice), except that while data stored in localStorage has no expiration time, data stored in sessionStorage gets cleared when the page session ends.
