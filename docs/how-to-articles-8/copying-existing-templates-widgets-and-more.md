# Reuse Plugins from Neutrinos Store

<https://documentation.neutrinos.com/articles/#!how-to-articles-8/copying-existing-templates-widgets-and-more>

Neutrinos allows you to use existing plugins such as [app templates](/smart/project-concepts/app-templates), [components](/articles/concepts-publication/component), [nodes](/articles/concepts-publication/node), and [directives](/smart/project-concepts/directive) that are available on [Neutrinos Store](/articles/concepts-publication/neutrinos-store). This saves you development time and helps reuse existing ideas. You can launch the Store by navigating to [https://store.neutrinos.co/](https://store.neutrinos.co/web/catalog/featured), or from Neutrinos Studio by using the Plugins Manager:

![Plugins Manager](/resources/Storage/how-to-articles-8/plug_store.png)

In Neutrinos Store, each plugin is listed under a category and displayed as a card. You can click on the categories, and then download the plugin of your choice, or use the search bar to look for a plugin.

![Neutrinos Store](/resources/Storage/how-to-articles-8/store.png)

Once downloaded, you can manage all the plugins from Neutrinos Studio. See [Manage Plugins and Dependencies](/smart/project-sample-how-to-guide/manage-plugins-dependencies) to learn how to manage plugins downloaded from Neutrinos Store .

You can also create your own plugin and contribute to Neutrinos Store . See [Creating a plugin](/smart/project-create-a-widget/create-component-preface) to learn more.
