# How to use

<https://documentation.neutrinos.com/articles/#!server-side-service-designer-publication/date>

Date nodes are used to parse, validate, manipulate, and display date and time. It internally uses [moment.js](https://momentjs.com/docs/) and allows displaying of date as per localization and in a human-readable format.

Date nodes are:

- [Parse](/articles/server-side-service-designer-publication/date-parse)
- [Validate](/articles/server-side-service-designer-publication/date-validate)
- [Format](/articles/server-side-service-designer-publication/date-format)
- [Duration](/articles/server-side-service-designer-publication/date-duration)
- [Date Operations](/articles/server-side-service-designer-publication/date-operations)
- [Get Set](/articles/server-side-service-designer-publication/date-get-set)

### How to use

- Open the **Server Services** editor window.
- Open an existing service from the service list or click the** plus icon **to add a new Server Service.
- Download the Plugin from Neutrinos Store. See [Download from Store](/articles/studio-guide-7/import-plugin).
- In the Nodes Palette, search for the installed node and drag and drop the node to the canvas.
- Drag and drop other nodes to create a flow. Make sure the flow starts with a Start node.
