# Create the Subscribe Page

<https://documentation.neutrinos.com/articles/#!tutorial-create-a-pwa/create-a-subscribe-page>

The** Subscribe** page is used to show a pop-up to users to subscribe to the weather of a city for which they wish to receive push notifications.

To design the **Subscribe** page, perform the following steps:

1. Click the **New File **icon on the Page Explorer to create a new page.
2. In the **Enter Page Name** dialog box, enter the name of the page as **Subscribe **and press **Enter**.
