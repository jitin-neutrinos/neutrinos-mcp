# Test the PWA

<https://documentation.neutrinos.com/articles/#!tutorial-create-a-pwa/working-of-the-pwa>

To test the working of the PWA:

1. Type **http://****localhost:8083** in the browser's address bar to access the weather app.
2. You will see an **Install **icon in the browser's address bar. This indicates that the app is successfully converted into a PWA.
3. Click the** Install** icon to install the PWA to your machine.
