# Initialize the app

<https://documentation.neutrinos.com/articles/#!tutorial-create-a-pwa/set-up-live-preview>

Initializing your app fetches all of the necessary packages to run the app. Perform the following:

1. On the top-center of the [Application page](/smart/project-concepts/studio-application-page), you will see a drop-down list of tasks. Click the down arrow.
    ![Live view for LMS](/resources/Storage/tutorial-create-a-pwa/IL1.png)
2. Select the **Initialize** task from the list and click the **Run **button. The command on which the initialization happens is nmp install. This command installs **node_modules** for the app.

| ![Information](/resources/Storage/tutorial-create-a-pwa/info.png) | Hovering over each of the tasks in the task list reveals a brief description of that task. |
| --- | --- |

You![](http://docs1.neutrinos.co/DXR.axd?r=1_88-Qerdk) can track the progress of the task from the Terminal window.

| ![Warning](/resources/Storage/tutorial-create-a-pwa/warning.png) | Make sure that you are connected to the internet to run the **Initialize** task successfully. |
| --- | --- |
