# Build the PWA

<https://documentation.neutrinos.com/articles/#!tutorial-create-a-pwa/build-the-pwa>

To take a build of the PWA in your local machine, perform the following step:

In the default terminal of Neutrinos Studio, navigate to the app folder within your app and run the command to create a build:

```markdown
npm run build-web
```

![npm build-web](/resources/Storage/tutorial-create-a-pwa/tutorial-build-a-pwa-2021-04-05.png)

A **dist** folder is generated within the app folder. This folder will contain all the build files.
