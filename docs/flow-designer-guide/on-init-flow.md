# On Init Flow

<https://documentation.neutrinos.com/articles/#!flow-designer-guide/on-init-flow>

When you create a page on Neutrinos Studio, a page On Init flow is generated by default on the[Page Flow Designer](/smart/project-concepts/page-designer/a/h3_520216706). This flow is triggered when the page is initialized and set the page variables.

![On init flow](/resources/Storage/flow-designer-guide/on_init.png)

The flow contains the following nodes:

- [OnInit node](/articles/flow-designer-guide/on-init-node): In this node, you can specify the [input and output variables](/articles/flow-designer-guide/properties-page-designer) required for the page.
- [Page Variables node](/articles/flow-designer-guide/page-variables-node): In this node, you can set or get call a page variable.

You can edit the flow to perform certain actions when the page is initialized. Such as:

1. Set page variables using the [Page Variables](/articles/flow-designer-guide/page-variables-node) node in the flow.
  - For example, you can bind the initialized page variable to set conditions for UI components such as show, hide or disable some elements in the UI based on the page variables set on initialization.
  - Let us consider a case to show or hide an HTML block based on the page variables set on the on init flow. These are the page variables that are set.
  - Once these variables are set, you can bind these variables from the UI element. In this example, the **showBlock** variable is set to hide and show the HTML block of the UI.
2. Add handlers for subscriptions and event listeners. See[Listen to DOM events](/smart/project-how-to-articles/listen-to-dom-events) topic for an example.
3. Add other nodes from the nodes palette to this flow to perform any function on the initialization of the page. For example, you can use an [HTTP Request](/articles/flow-designer-guide/http-request-node) node in this flow to call a server API when the page is loaded.
