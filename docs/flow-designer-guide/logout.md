# Logout

<https://documentation.neutrinos.com/articles/#!flow-designer-guide/logout>

The **Logout **node opens the IDS logout page and logs the user out. For mobile applications, this method returns a promise.

Node Properties**Name:** A unique name for the node.**Function Name: **This is a read-only field. The function name is generated based on the name that you enter in the Name field. It is used to identify the node while debugging.**Redirect URL:** Enter the URL defined for the page on the Routes editor to redirect the user to a different page post logout.
