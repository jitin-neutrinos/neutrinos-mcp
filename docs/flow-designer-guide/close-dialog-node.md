# Node Properties:

<https://documentation.neutrinos.com/articles/#!flow-designer-guide/close-dialog-node>

This is the default topic template.

The** Close Dialog **node is used to close the dialog window.

| ![Information](/resources/Storage/flow-designer-guide/info.png) | This node should be used on the page which is displayed as a dialog window. |
| --- | --- |

### Node Properties:

- **Name:** A unique name for the node.
- **Function Name:** This is a read-only field. The function name is generated based on the name that you enter in the **Name** field. It is used to identify the node while debugging.
- **Data: **The data to be emitted after the dialog box is closed. Select the [property](/articles/flow-designer-guide/properties-page-designer) type and enter the variable name in which you want to save the data.
