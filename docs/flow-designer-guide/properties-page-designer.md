# Page Properties

<https://documentation.neutrinos.com/articles/#!flow-designer-guide/properties-page-designer>

The [Page designer](/smart/project-concepts/page-designer) has two types of properties:

- [Page properties](/articles/flow-designer-guide/properties-page-designer/a/h3_545829551)
- [Flow properties](/articles/flow-designer-guide/properties-page-designer/a/h3__1075892433)

### Page Properties

When you create a page, Neutrinos creates a default page variable of an object reference type called page to access the properties of the page. It also creates the following namespaces to perform specific functions:

- page.input: Used for inter-component communication (parent to child) when this page is used as a child view on another page.
- page.output: to emit data from the page view to the parent pages.
- page.services: to invoke functions of a service designed in the [Client Services Designer](/smart/project-concepts/client-services-designer).
- page.local: to declare properties local to the ngOnInit flow of the page.
- page.dm: to access and set data to the data model objects that were defined in the [datamodels editor](/smart/project-sample-how-to-guide/designing-data-models). See [Accessing Data Models on the Page UI](/smart/project-sample-how-to-guide/accessing-data-models-on-the-page-ui) to learn more.
- page.locales: to access locales properties that were defined in the [locales](/smart/project-sample-how-to-guide/apply-internationalization) editor. See [Accessing Locales Properties on the Page UI](/smart/project-sample-how-to-guide/translate-the-app-ui-to-multiple-languages) to learn more.
- page.system.environment.properties: to access the environment properties that were configured in the [Environments](/smart/project-sample-how-to-guide/what-is-an-environment) editor.
- properties set by the user using the [Page Variables](/articles/flow-designer-guide/page-variables-node) node.

#### Page Variables

When you assign variables to the page property, they are called **page variables**. These variables offer a straightforward way for the page designer to interact with the HTML template of the page, as well as the page flows. They also store data that can be shared and accessed across the flows of a page.

### Flow Properties

When you create a flow on the Page Designer, Neutrinos creates a flow level variable of an object reference type bh to access input, local, error, and system properties of the flow. Flow properties include:

bh.input: contains variables that are provided as arguments to the function created by the flow. They are not available outside the flow unless they are defined as Output variables or set to a page variable using the [Page Variables](/articles/flow-designer-guide/page-variables-node) node. bh.local: contains variables that are private to the flow. They are additional variables that can be used inside the flow. They cannot be accessed outside the flow unless they are defined as Output variables or set to a page variable using the  [Page Variables](/articles/flow-designer-guide/page-variables-node) node. bh.error: contains the error object after an exception occurs. These exceptions are caught by the [Catch](/smart/project-service-designer-user-s-guide/catch-node) node.bh.system: contains all the variables and services that are pre-defined by the Neutrinos Platform. See [System-defined variables](/smart/project-service-designer-user-s-guide/system-defined-properties) to learn about these variables.bh.pageViews: Gets populated dynamically when a View or a Component gets queried using the [View Picker](/articles/flow-designer-guide/view-picker-node) node. It is scoped to the flow where the View Picker node lives.bh.pageInput: contains the **input** variables that are defined in the On Init node. See [On Init Flow](/articles/flow-designer-guide/on-init-flow) to learn more.bh.pageOutput: contains the** output **variables that are defined in the [On Init](/articles/flow-designer-guide/on-init-node) node. See [On Init Flow](/articles/flow-designer-guide/on-init-flow) to learn more. If you are reusing the Page UI as [Views](/smart/project-sample-how-to-guide/views), these output variables can be used in the [Output](/articles/flow-designer-guide/output-node) node to emit data from the child view to the parent page.Scope of Flow PropertiesFlow properties are limited to the flow they are created in, and cannot be accessed outside the flow unless you bind them to a page property.The input and local variables are defined by the user.The system variables are generated by the Neutrinos Platform.
