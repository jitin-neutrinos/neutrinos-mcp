# Node Properties:

<https://documentation.neutrinos.com/articles/#!flow-designer-guide/get-dialog-data-node>

This is the default topic template.

The** Get Dialog Data **node is used to get data of the dialog window from the page on which it is displayed.

| ![Information](/resources/Storage/flow-designer-guide/info.png) | This node should be used on the page which is displayed as a dialog window. |
| --- | --- |

### Node Properties:

- **Name:** A unique name for the node.
- **Function Name:** This is a read-only field. The function name is generated based on the name that you enter in the **Name** field. It is used to identify the node while debugging.
- **Dialog Data Mapping: **The page or flow variable to which you want to map the data received from the parent page. Select the [flow or page property](/articles/flow-designer-guide/properties-page-designer) and enter the variable name in which you want to save the data.
