# On Online Node

<https://documentation.neutrinos.com/articles/#!flow-designer-guide/on-online-node>

The **On** **Online **node is used to listen to the internet events when the application gains network.

Node Properties**Name:** A unique name for the node.**Function Name: **This is a read-only field. The function name is generated based on the name that you enter in the Name field. It is used to identify the node while debugging.
