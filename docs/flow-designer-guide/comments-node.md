# Node Properties

<https://documentation.neutrinos.com/articles/#!flow-designer-guide/comments-node>

This is the default topic template.

The** Comments node is** used to write a description or comment in the page flows.

### Node Properties

- **Name: **The name of the node. It is used to uniquely identify the node on the canvas. It does not make any behavioral difference on the end app.
- **Comments Editor:** A rich text editor where you can add comments for the page flow.
