# Node Properties

<https://documentation.neutrinos.com/articles/#!flow-designer-guide/host-listener-node>

This is the default topic template.

The **Host Listener **node is used to listen for [DOM events](https://www.w3schools.com/jsref/dom_obj_event.asp) on the page. You can use this node to listen to the page event and then perform any desired action. For example, you can listen to the mouseover event on the button and change the color of the button on hover.

### Node Properties

- **Name:** A unique name for the node.
- **Function Name:** This is a read-only field. The function name is generated based on the name that you enter in the **Name** field. It is used to identify the node while debugging.
- **EventName: **The [DOM event](https://www.w3schools.com/jsref/dom_obj_event.asp) that you want to listen to.
