# Auth State Listener

<https://documentation.neutrinos.com/articles/#!flow-designer-guide/auth-state-listener>

The **Auth State Listener **node is used to emit multiple events when a user session becomes invalid. This node can be used to notify the user about his/her active session and can prompt the user to log back into the app.

Node Properties**Name:** A unique name for the node.**Function Name: **This is a read-only field. The function name is generated based on the name that you enter in the Name field. It is used to identify the node while debugging.**Result Mapping: **The result of the event. Enter the [page or flow variable](/articles/flow-designer-guide/properties-page-designer) in which you want to save the result.
