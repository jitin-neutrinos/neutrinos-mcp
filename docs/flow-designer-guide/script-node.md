# Node Properties

<https://documentation.neutrinos.com/articles/#!flow-designer-guide/script-node>

This is the default topic template.

The **Script **node is used to write the business logic of a flow depending on the application requirement.

### Node Properties

- **Name:** The name of the node on the canvas. This is only used to uniquely identify the node on the editor. It does not provide any behavioral difference on the end app.
- **Function Name:** This is a read-only field. The function name is generated based on the name that you enter in the **Name** field. It is used to identify the node while debugging.
- **Code Editor: **The editor to write the business logic in JavaScript.

To create variables in this node, see:

- [Create or update flow variables](/smart/project-sample-how-to-guide/create-flow-variables)
- [Create or update page variables](/smart/project-sample-how-to-guide/create-page-variables)
