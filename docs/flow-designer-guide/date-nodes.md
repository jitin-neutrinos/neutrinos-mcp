# Date nodes

<https://documentation.neutrinos.com/articles/#!flow-designer-guide/date-nodes>

This is the default topic template.

Date nodes are used to parse, validate, manipulate, and display date and time. It internally uses [moment.js](https://momentjs.com/docs/) and allows displaying of date as per localization and in a human-readable format.

The Date nodes are:

- [Parse](/articles/flow-designer-guide/date-parse-node)
- [Validate](/articles/flow-designer-guide/date-validate-node)
- [Format](/articles/flow-designer-guide/date-format-node)
- [Duration](/articles/flow-designer-guide/date-duration-node)
- [Date Operations](/articles/flow-designer-guide/date-operations-node)
- [Get Set](/articles/flow-designer-guide/date-get-set-node)
