# Save a page

<https://documentation.neutrinos.com/articles/#!studio-guide-9/adding-pages>

Every application consists of one or more [pages](/smart/project-concepts/page). On Neutrinos Studio. you can:Create pagesSave pagesdelete pagesCreate a Page![add new page](/resources/Storage/studio-guide-9/newpage.png)
To create a [page](/smart/project-concepts/page):Click the **Pages** button in the Editor pane, and click** Add New**. In the **Enter Page Name** dialog box, enter the name of the page. Note that the page name field accepts only a single string value with no spaces.![adding new page](/resources/Storage/studio-guide-9/pageuser.png)



 ![Information](/resources/Storage/studio-guide-9/info.png)


 When you create an app on using a template, some pages get generated by default. These pages are called **default pages**.

### Save a page

To save a [page](/smart/project-concepts/page), open the page and click ![save icon](/resources/Storage/studio-guide-9/save.png) on the top right corner of the screen. Or, press the keyboard shortcut **Ctrl+S**.

### Delete a Page

To delete a [page](/smart/project-concepts/page), open the page and click ![Delete icon](/resources/Storage/studio-guide-9/delete.png) on the top right corner of the screen. Reconfirm the page deletion by clicking **Yes** on the confirmation popup window.
