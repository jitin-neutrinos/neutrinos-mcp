# Add Custom Properties to a Component

<https://documentation.neutrinos.com/articles/#!studio-guide-9/work-with-component-properties>

Every component has a set of default properties or attributes that can be configured using its attributes window. See the [Component documentation](/smart/project-components-documentation-copy/components) to learn about each property of a component. You can also click ![help icon](/resources/Storage/studio-guide-9/help_icon.png) on the component's attributes window to access the respective documentation.

If you want to add additional properties to the component, you use the **Custom Properties** section.

#### Add Custom Properties to a Component

To add custom properties, navigate to the **Custom Properties **section of the component's attributes window.

Depending on the type of custom property you want to add, you can toggle between **Attribute** and** Key&Value **types.

- If you select the **Attribute** type, enter only the attribute name and click the **+** button to add that property to the component. Neutrinos Studio auto-completes the attribute's value field.
- If you select the **Key&Value** type, you should provide the **key** and the **value** data and click the **+** button to add the property to that component.
