# Install an App template

<https://documentation.neutrinos.com/articles/#!studio-guide-9/manage-app-template>

### Install an App template

To install an [App template](/smart/project-concepts/app-templates), perform the following:

1. Click **Plugins** on the top menu of the [Studio Home page](/articles/concepts-publication/studio-home-page) and select **Go to store.**
2. On Neutrinos Store, select **Templates** on the left navigation to view a list of templates.
3. Click the **Download** icon on the template card.
    ![login template](/resources/Storage/studio-guide-9/login%20template.png)
4. Click **Yes** on the prompt to download the template on Neutrinos Studio.

After the template is downloaded, you can select the template when you create an application.

### Manage App templates

After downloading, you can reuse [app templates](/smart/project-concepts/app-templates) any number of times while creating new apps. To manage app templates, you use the **Plugins Manager **on the [Studio Home page](/articles/concepts-publication/studio-home-page).

Click **Plugins** on the top navigation and select **Manage Plugins**.

Click the **Templates** tab to view and delete templates from Neutrinos Studio.

![Templates in Plugins Manager](/resources/Storage/studio-guide-9/templates_pm.png)

You can also create an app template and contribute to Neutrinos Store. See [Create an App Template](/smart/project-create-a-widget/create-an-app-template) to get started.
