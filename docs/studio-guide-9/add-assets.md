# Add Assets

<https://documentation.neutrinos.com/articles/#!studio-guide-9/add-assets>

You upload images to be used on the frontend application in the Assets editor. You can use the existing images or you can upload relevant images by using the drag and drop feature.

Click **Assets Editor** on the editor pane to view platform-specific folders.

All the icons, images, and splash screens should be uploaded to their respective folders.

Upload the Android-specific images to the **Android **folder. For Android devices, icons and splash screens are based on the resolution of the device. therefore, upload the assets based on the resolution of your Android device.Upload the iOS-specific images to the **iOS** folder. Upload icons and splash screens to relevant folders within the **Resources **folder.Upload the web-specific images to the **Web **folder. Upload the icons to the **Icons** folder. Note that to use an image as a web asset, you should configure the path starting from the relevant source folder name.

Click an image to preview the image. You click on the slider to preview between images in a selected folder. In the image preview, you can also click the **Delete** icon to delete the image.

To upload icons, images, and splash screens, select the folder and click the **Upload** button in the preview window.
