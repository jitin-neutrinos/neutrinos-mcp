# Duplicate Service Flows

<https://documentation.neutrinos.com/articles/#!studio-guide-9/duplicate-service-flows>

You can make a copy of any [service flow](/smart/project-concepts/services-designer-elements/a/h3__2138058983) by using the CTRL + C and CTRL + P keyboard shortcuts. You can make a copy of the service flow within the same service, or copy the flow to another service within respective designers (Client or Server Services Designer).

Perform the following steps:

1. Select the service flows that you want to copy by dragging and dropping the mouse pointer on the canvas. Press CTRL + C to copy the service flows. If you want to copy all the flows, click on the [canvas](/smart/project-concepts/studio-application-page/a/h3__2105229662) and press CTRL + A.
    ![selecting the service flows](/resources/Storage/studio-guide-9/copy1.png)
2. Press CTRL + P to paste the service flow on the same service. To paste the service flow on another service, navigate to the other service, click on the canvas to indicate where you want to paste the flows, and press CTRL + P.

| ![Information](/resources/Storage/studio-guide-9/info.png) | Copying service flows from Client to Server Services Designer, and vice versa is not allowed. Neutrinos Studio throws an error if you try to do so. |
