# Add Nodes on a Page

<https://documentation.neutrinos.com/articles/#!studio-guide-9/design-page-flows>

You design the logic of a page using page flows. On the [page explorer](/articles/studio-guide-9/page-explorer), click **Flow** to open the [Page Flow designer](/smart/project-concepts/page-designer/a/h3_520216706). On this designer, drag and drop [nodes](/smart/project-concepts/services-designer-elements/a/h3__1499176760) to the page canvas and [wire](/smart/project-concepts/services-designer-elements/a/h3__837447059) them to create [flows](/smart/project-concepts/services-designer-elements/a/h3__2138058983). Make sure the flow starts with a Start node such as [Start](/smart/project-page-services-designer-guide/start-node), [On Init](/smart/project-page-services-designer-guide/on-init-node), etc.

Before getting started with designing page flows, learn the basics. See [page designer basics](/smart/project-page-services-designer-guide/basics-of-page-services-designer).

#### Add Nodes on a Page

1. On the page explorer, select the **Flow **of the page to which you want to add nodes.
2. From the nodes palette, select a node and drag and drop it to the canvas.
3. Click the node to open its attributes window and configure its functionality.

#### Arrange Nodes and Flows on a Page

To cut/copy/paste a node or a page flow, you can use the following shortcuts:

**On Windows:**

Ctrl + Z / Ctrl + C / Ctrl + V

**On Mac:**

Cmd + Z / Cmd + C / Cmd + V

You can cut/copy/paste nodes and flows only within a page. You cannot cut/copy/paste them across pages.

To arrange nodes, drag them and move them to any location within the page canvas.

#### Delete Nodes from a Page

To delete a node from a page, select the node and press **Delete**.

#### Access Node Properties Window

Double-click the node to access its attributes/properties window.

#### Access Node documentation

Click the ![help icon](/resources/Storage/studio-guide-9/help_icon.png) on the node's properties window to open its respective documentation.
