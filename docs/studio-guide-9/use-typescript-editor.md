# Use TypeScript Editor (Deprecated)

<https://documentation.neutrinos.com/articles/#!studio-guide-9/use-typescript-editor>

If you have migrated your app from the previous versions, the TypeScript editor (TS editor) of each page is retained by Neutrinos Studio.

You can access the TS editor from the [page explorer](/articles/studio-guide-9/page-explorer), by expanding the page and selecting **TS (Deprecated)**. It contains the business logic that you had defined for a page. You can further customize or implement individual business logic by writing or modifying the TypeScript code.

| ![Information](/resources/Storage/studio-guide-9/info.png) | You cannot design page flows for pages having the TS editor. |
