# Accessing Page Properties

<https://documentation.neutrinos.com/articles/#!studio-guide-9/properties-of-a-page>

When you create a page on Neutrinos Studio, default page properties are auto-generated. You can use these properties across the page UI and page flow. See [Properties in Page Designer](/smart/project-page-services-designer-guide/properties-page-designer) to learn about them.
