# Add Components on a Page

<https://documentation.neutrinos.com/articles/#!studio-guide-9/design-page-ui>

You design the user interface of the page by selecting the UI of the page on the [page explorer](/articles/studio-guide-9/page-explorer). This opens the Page UI designer. On this designer, you drag and drop components for the [palette](/smart/project-concepts/palette/a/h4_1518247481) and design the look and feel of the page.

#### Add Components on a Page

1. On the page explorer, select the **UI **of the page to which you want to add components.
2. From the components palette, select a component and drag and drop it to the canvas.
3. Click the component to open its attributes window and configure its functionality.

#### Arrange Components on a Page

To cut/copy/paste you can use the following shortcuts:

**On Windows:**

Ctrl + Z / Ctrl + C / Ctrl + V

**On Mac:**

Cmd + Z / Cmd + C / Cmd + V

You can cut/copy/paste components only within a page. You cannot cut/copy/paste components across pages.

To arrange components, drag them and move them to any location within the page canvas.

To delete a component from a page, select the component and click the **Delete** icon on the component.

#### Hide Components on a Page

To hide a component on a page, and not display it on run-time, click the component and select the **Comment** icon. This action does not delete the component and its child components, instead, hides them from the screen when you preview/deploy the app.

Add Store components:

To add [store components](/smart/project-components-documentation-copy/store-components) to a page, you should first download the component from Neutrinos Store. The component will then be available on the palette to use in designing the page.
