# Preview the App

<https://documentation.neutrinos.com/articles/#!studio-guide-9/live-preview-web-app>

To test and debug, preview the application locally. After initializing the app, select the **Live View** option from the Task drop-down list and run the task.

![live view](/resources/Storage/studio-guide-9/live_view_new.png)

You can see the **Live View** task running for **Client** and/or **Server **services based on the type of application you are initializing.

![Live view of server](/resources/Storage/studio-guide-9/liveserver.png)

- See [Preview server service](/articles/studio-guide-9/preview-server-flows) flows to learn more about how the Live view works for Server Services.
- See [Preview client services](/articles/studio-guide-9/preview-client-service-flows) flows to learn more about how Live view works for Client Services.

The preview of the application opens on your default browser with the default URL - **https://bs- XXXX.appspot.com/**. You can test the functionality of the client and/or the server using a web browser or Postman.
