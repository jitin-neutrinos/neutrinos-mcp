# .nos File Extension

<https://documentation.neutrinos.com/articles/#!studio-guide-9/export-a-nos-file>

### .nos File Extension

When you export an application built on Neutrinos Studio, a .nos file gets created in the same name of the app. The exported .nos file is a sharable bundle of application artifacts that contains everything that you have designed in the app; from table definitions and scripts to UI layouts, and reference data.

### Export an Application

You export an app to a .nos file in the following scenarios:

- To share the app without the version-control mechanism.
- To move an app from one workspace to another workspace.
- To create a backup of the app.

To export an app:

1. Navigate to the home page of the Neutrinos Studio.
2. Click the **More options** button on the application card from which the **.nos file** should be exported.
   ![More options for exporting](/resources/Storage/studio-guide-9/exportmore.png)
3. Click **Export as .nos **and select the folder to save the file in your local machine. All the application artifacts get exported to a .nos file.
