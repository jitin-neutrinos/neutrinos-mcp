# Update Plugins

<https://documentation.neutrinos.com/articles/#!studio-guide-9/update-plugins>

To update a plugin, perform the following steps:

1. Click** Plugins** on the top menu.
2. In the Manage Plugins window, select the **Check for updates** tab.
3. If there is an update for the plugin that you have installed in your app, it appears in this tab. Select the plugin and click** Update**.

The plugin gets updated in the app and the [workspace](/smart/project-concepts/studio-workspace).
