# Assign Admin Privileges

<https://documentation.neutrinos.com/articles/#!studio-guide-9/manage-organization-admins>

If you are an organisation admin, you can perform role-based access control, add/remove users and teams, and assign or revoke Admin privileges to other users in your organization.

![](/resources/Storage/studio-guide-9/org_admin.png)

### Assign Admin Privileges

To assign the  organisation admin privilege to a user:

- Log in to the Neutrinos Console and click **Organization Admins**.

- Click ![the Add Team icon](/resources/Storage/studio-guide-9/add_usesr.png) on the top right of the screen.
- Add the organization Admin user name and click ![the Edit icon](/resources/Storage/studio-guide-9/correct.png)

### Remove Admin Privileges

To remove the organisation admin privilege of a user:

- Log in to the Neutrinos Console and click **Organization Admins**.
- Select the user whose privileges you want to revoke. You can use the search bar to find the user.
- Click ![the Delete icon](/resources/Storage/studio-guide-9/delete_icon.png) next to the user.
- A pop-up window is displayed asking to confirm your action. Click **Yes**.
