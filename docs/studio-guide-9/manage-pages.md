# Open a Page

<https://documentation.neutrinos.com/articles/#!studio-guide-9/manage-pages>

Pages define the end-user interface of an application. When working with pages, you can perform the following tasks:

#### Open a Page

A page can be listed as an individual element or be included in a folder. To open a page on Neutrinos Studio:

1. On the [page explorer](/articles/studio-guide-9/page-explorer), navigate to the location of the page.
2. Select the page you want to open.
3. The **UI** and **Flow **sections of the page are displayed on the explorer and the UI of the page is displayed by default on the [canvas](/smart/project-concepts/studio-application-page/a/h3__2105229662).

To open a page within a folder:

1. On the p, open the folder where this page is located.
2. Navigate to the page’s location inside the folder.
3. Select the page you want to open.
4. The **UI** and **Flow **sections of the page are displayed on the explorer and the UI of the page is displayed by default on the [canvas](/smart/project-concepts/studio-application-page/a/h3__2105229662).

#### Add a Page

To add a new page:

1. On the page explorer:
  - Select a folder in which you want to create the page
  - Or, select the page above which you want to create the page
2. Click the **Add page** icon
3. Enter the name of the page
4. Press** Enter**

#### Delete a Page

To delete a page:

1. Right-click on the page that you want to delete
2. Select **Delete** from the list of options
3. Click **Yes** on the pop-up window to confirm your action
