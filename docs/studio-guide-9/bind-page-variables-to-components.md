# Bind Page Variables to a Component's Attribute

<https://documentation.neutrinos.com/articles/#!studio-guide-9/bind-page-variables-to-components>

To bind a page variable to a component attribute, use this.page.<variable_name>. For example, if you have a page variable called language created using the [Page Variables](/smart/project-page-services-designer-guide/page-variables-node) node, you can bind that variable to the attribute of any component by entering this.page.language in the value field.

Similarly, you can bind properties created in the Locales, Environments, and Data models editor to a component.
