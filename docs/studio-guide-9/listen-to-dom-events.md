# Listen to DOM Events

<https://documentation.neutrinos.com/articles/#!studio-guide-9/listen-to-dom-events>

To listen to the DOM events of a page, use the [Host Listener](/smart/project-page-services-designer-guide/host-listener-node) node. After you get a handle on the DOM event, you can perform any action that you desire on that event. See [Listen to DOM events](/smart/project-how-to-articles/listen-to-dom-events) for an example.
