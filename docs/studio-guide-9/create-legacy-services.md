# Create Legacy Services

<https://documentation.neutrinos.com/articles/#!studio-guide-9/create-legacy-services>

Before the introduction to [Client Services Designer](/smart/project-concepts/client-services-designer) and [Server Services Designer](/smart/project-concepts/server-services-designer) on Neutrinos Studio, developers were required to hard-code Angular services. Such services are called **Legacy Services**. If you have migrated your app from older versions of Neutrinos Studio (version 6 and below), all your services are listed as legacy services. To access these services, click the side menu on the [Studio application page](/smart/project-concepts/studio-application-page) and select **Services > Legacy**. You can also add new legacy services in the latest version of Neutrinos Studio to add Angular route guards and call them on the **Routes **editor.

To add a legacy Service:

1. Click the **Services** from the editor pane.
2. Select **Legacy **and click** Add New**.
3. Enter the name of the service, and click **Add**.

![Creating legacy service](/resources/Storage/studio-guide-9/legacy.png)

To learn how to call a legacy service on a page, see the [How-to guide](/smart/project-how-to-articles/how-to-invoke-a-legacy-service-on-a-page).
