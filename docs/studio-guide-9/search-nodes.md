# Search Nodes

<https://documentation.neutrinos.com/articles/#!studio-guide-9/search-nodes>

Use the Keyboard shortcut Ctrl + P to view the list of nodes used in your application. Click a node to quickly access it on the respective designer. Any node added to the canvas of any designer ([Client Services Designer](/smart/project-concepts/client-services-designer), [Server Services Designer](/smart/project-concepts/server-services-designer), or [Page Designer](/smart/project-concepts/page-designer)) is displayed in the search drop-down list.

You can also type the name of the node to narrow down your search.

You can also view the search list by selecting **Edit > Node Search** on the top menu of the Studio Application page.
