# Design Data Models

<https://documentation.neutrinos.com/articles/#!studio-guide-8/designing-data-models>

[Data models](/articles/concepts-publication/data-model) are useful to get consistent data for your application in a proper format. To design data models, click **Models** on the side menu of the Studio Application page.

![The Data Models editor](/resources/Storage/studio-guide-8/datamodels.png)

Creating a Data ModelTo create a data model, click the **Models** button from the editor pane, and select **Add New button**. In the New Data Model dialog box, enter the following information, and click **Add**.**Data Model**: Name of the data model**Description**: A short description of the data model**Data Source**: Name to the database where the data residesNavigate to [Create Data Models](/smart/project-tutorial-leave-management-system/designing-data-models) to see an example.Importing a Data ModelNeutrinos Studio allows you to import a data model from an existing application in the current workspace. To import a data model:Click **Models **in the editor pane and select **Add New.**Select **Clone** in the Data Model pop-up windowIn the **Select App** field, select an existing app in the workspace where the required data model resides.In the **Select Data Model** field, select the name of the data model which is to be imported.Designing a Data ModelAfter creating a data model, click **Models** from the editor pane, and select the data model that you want to design. Enter the data model attributes: **Name: **Define attribute name**Type: **Select the data type of the attribute from the drop-down list. You can choose simple data types such as **Number**, **String**, **Boolean**, and **Date **to design a simple data model, or select **Model** to design a complex data model.**isArray:** Select this option to specify if the attribute is a list.Click **Add **to add the attribute.Repeat the process until you add all the attributes of the data model.Modifying a Data ModelTo edit a data model, select **Models **in the editor pane, and select the data model you need to modify. Click the field you want to modify and enter the new value. Use the **Delete** icon to the right of the field to delete the field. If you want to add a new field, use the top section of the window, enter the name, select the type of the field, and click** Add**.
