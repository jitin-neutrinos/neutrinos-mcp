# Add Users

<https://documentation.neutrinos.com/articles/#!studio-guide-8/manage-users>

An organisation admins can manage users and their access to Neutrinos Studio and the apps built on Neutrinos Studio.

To do that, navigate to [Neutrinos Console](https://console.neutrinos.co/) and click the **Users** option on the left navigation menu.

The **User** screen displays a list of registered users for an organization account.

![Manage users screen](/resources/Storage/studio-guide-8/users_list.png)

### Add Users

To add a user:

1. On the Users page, click ![Add User icon](/resources/Storage/studio-guide-8/add_usesr.png) on the top right corner of the screen.
2. Enter the following user details in the Add User section that appears to the right.
  1. **First Name**: Enter the given name of the user.
  2. **Last Name**: Enter the last name of the user.
  3. **Organization Name**: Read-only field that displays the name of your organization.
  4. **Email**: Enter the organization email address of the user. This will be the default user name for the user to login.
  5. **Password**: Enter a password to enable the user to access their account.
  6. **Confirm Password**: Enter the password again.
  7. **Teams**: Click the drop-down list and assign the user to one or more teams. Users, when assigned to teams, will get access to all the apps that the team has access to. This is how the user will be authenticated against apps on Neutrinos Console.
3. Click ![the Add User icon](/resources/Storage/studio-guide-8/correct.png) to onboard the user.

The onboarded user will receive an email with the temporary login details to reset the password. Once the user is added as part of a team, the user can access the resources.

### Search Users

To search users:

1. Log in to the [Neutrinos Console](https://console.neutrinos.co/web/) and click **Users**.
2. In the search field, enter the **Email ID**, **First name**, or **Last name** of the user and click the **Search** icon. As you enter the search criteria, the matched results are displayed.

![](/resources/Storage/studio-guide-8/searchuser2019-07-10_12h44_56.png)

By default, Console displays 10 users per page. You can modify this default value by changing the **Items per page** count in the drop-down list. You can also use the pagination icons to navigate through the user list.

### Reset Password

To reset the password for a user:

1. Log in to the [Neutrinos Console](https://console.neutrinos.co/web/) and click **Users**.
2. Click the name of the user whose password you want to reset or search the user in the search bar. Click the user. The user information is displayed in the right section.
3. Click ![the Reset password icon](/resources/Storage/studio-guide-8/reset_pwd_icon.png). You will see a pop-up window with a note saying that the temporary password will be sent to this User’s registered Email ID. Click **Yes**.

The user should log in to Neutrinos Console with the temporary password to reset the password.

### Delete Users

To delete a user:

1. Log in to the [Neutrinos Console](https://console.neutrinos.co/web/) and click **Users**.
2. Click the name of the user you want to delete. The user information is displayed in the right section.
3. Click ![the Reset password icon](/resources/Storage/studio-guide-8/delete_icon.png). You will see a pop-up window with a note asking you to confirm your action. Click **Yes**.

Once users are deleted, they are also deleted from the **Teams** they are assigned to.
