# Page Explorer

<https://documentation.neutrinos.com/articles/#!studio-guide-8/page-explorer>

The** Page Explorer** allows you to create application pages and organize them into different folders, where each page item contains [UI](/smart/project-concepts/page-designer/a/h3__1090805748) and [Flow](/smart/project-concepts/page-designer/a/h3_520216706).

Using the page Explorer, you can also:

- **Search** – enter the name of a folder, flow, or page into the **Search **field to search them within the Page Explorer. When filtering by a folder name, all content (pages and flows explorer items) of the matching folder is displayed.
- [Manage Pages](/articles/studio-guide-8/manage-pages)
- [Manage Folders](/articles/studio-guide-8/manage-folders)
- **Collapse all explorer items **– click the **Collapse** icon at the top of the Page Explorer to collapse all items.
- **Expand or collapse an individual folder/page/flow **– to expand/collapse the contents, click the **expand **or **collapse** icon to the left of the folder/page/flow.
- [Access the UI and Flow of a page](/smart/project-concepts/page-designer)
- Right-click the page item to save or discard the changes.
