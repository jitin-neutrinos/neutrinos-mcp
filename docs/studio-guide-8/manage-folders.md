# Add a folder

<https://documentation.neutrinos.com/articles/#!studio-guide-8/manage-folders>

Folders help in organizing pages within an application. You store app pages relating to a feature or a subject in one folder. For example, all app pages that display a dialog box are placed within the **Dialog** folder.

You manage folders on the [Page explorer](/articles/studio-guide-8/page-explorer) of the application.

#### Add a folder

To add a folder to the page explorer:

1. Click the **Add Folder** icon on the top of the page explorer
2. Enter the name of the folder
3. Press **Enter**

#### Expand/collapse a folder

To expand or collapse a folder click the **expand** or **collapse** icon to the left of the folder.

#### Rename a folder

To rename a folder:

1. Right-click on the folder that you want to rename, or press the F2 key when the folder explorer item is active.
2. Select **Rename** from the list of options
3. Enter the new name of the folder
4. Press **Enter **to save the new name

#### Move a folder

Drag the folder and drop it to the location where you want to place it and release the click. Note that you cannot move a folder inside a Page.

#### Delete a folder

To delete a folder:

1. Right-click on the folder that you want to delete
2. Select **Delete** from the list of options
3. Click **Yes** on the pop-up window to confirm your action
