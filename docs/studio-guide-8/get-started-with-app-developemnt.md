Get Started with the Neutrinos Platform and start building your first app.

![Application Development](/resources/Storage/studio-guide-8/app_dev.jpg)

### Create an Account

If you haven't signed up yet, start by creating a free account on [goneutrinos.com](https://goneutrinos.com/).

### Install the Development Environment

Download and install the latest version of [Neutrinos Studio](/articles/concepts-publication/studio) (the Integrated Development Environment (IDE) to build your apps) from the link you receive in your email. The link in your email will take you to [Neutrinos Console](/articles/concepts-publication/neutrinos-console). Select your operating system to download the IDE.

Install Neutrinos Studio on your local machine. Once the installation is complete, you can start developing right away!

Make sure you also download and [install the required software](/articles/studio-guide-8/before-you-begin) along with the IDE.
