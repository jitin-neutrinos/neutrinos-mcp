# Integrate with Active Directory

<https://documentation.neutrinos.com/articles/#!studio-guide-8/integrate-with-active-directory>

In most enterprises, AD is the authoritative user directory that governs access to basic IT services such as email and file sharing. Often, AD is also used to control access to a broader set of business applications and IT systems.

Managing multiple separate user directories that are not integrated with Active Directory can easily lead to a set of untenable security and access management challenges. Therefore, seamless integration with AD is a must for any solution used to manage access and authorization to applications.

Using the Neutrinos Server Services Designer, you can integrate with your existing Active Directory by using the [Active Directory node](/smart/project-server-side-service-designer/active-directory-node). To use this node, all you need to do is enter the active directory credentials of your organization and set up your Active Directory configuration
