# Managing User Roles

<https://documentation.neutrinos.com/articles/#!studio-guide-8/perform-user-management>

You perform user management on [Neutrinos Console](/articles/concepts-publication/neutrinos-console) to authenticate and authorize users and provide access to applications and Neutrinos Platform products. This task is mandatory and should be performed by the organisation admins.

The organisation admins can perform both Authentication and authorization on Neutrinos Console.

**Authentication** is used to validate user credentials such as User Name/User ID and password to verify identity.

**Authorization** occurs after the user identity is successfully authenticated. It gives you access to the applications, and Neutrinos Platform products such as Neutrinos Store, Neutrinos Console, Neutrinos Studio, etc. based on the access provided by the organisation admins. Authorization determines the user's ability to access the Neutrinos resources and up to what extent.

On Neutrinos Console, the user with organisation admins privileges should onboard the organization users, create one or more teams, assign users to those teams, and configure applications to which the users will be provided access.

If you are an organisation admin, perform the following tasks on Neutrinos Console:

- [Manage Users](/articles/studio-guide-8/manage-users)
- [Manage Teams](/articles/studio-guide-8/manage-teams)
- [Manage Organization Admins](/articles/studio-guide-8/manage-organization-admins)

Users with no organisation admins privileges will have read-only access.
