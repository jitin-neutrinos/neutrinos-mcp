# Create a Client Service Flow

<https://documentation.neutrinos.com/articles/#!studio-guide-8/create-a-client-service-flow>

To create a client service flow, perform the following steps:

1. Click the **Services** menu option on the [studio application page](/smart/project-concepts/studio-application-page) and select **Client**.
2. Click the **plus** icon on the explorer. Enter the name of the service that you want to create and click the **Add** button. The service gets added to the Services list.
3. Drag and drop nodes and wire them together to perform a functionality.
