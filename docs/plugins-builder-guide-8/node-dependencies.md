# Node Dependencies

<https://documentation.neutrinos.com/articles/#!plugins-builder-guide-8/node-dependencies>

Use this editor to select the third-party npm dependencies that are required for the node. These third-party dependencies can be selected only if they are already added in the [NPM Dependencies](/articles/plugins-builder-guide-8/npm-dependencies) editor.

From the list, select the dependencies that are to be applied for the node.
