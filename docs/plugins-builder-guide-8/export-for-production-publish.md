# Export for Production Publish

<https://documentation.neutrinos.com/articles/#!plugins-builder-guide-8/export-for-production-publish>

After testing the functionality of the node, use the **Export for Production Publish** button to export your node package as a .zip file to your local machine.

Submit the .zip file to Neutrinos by raising a support ticket on [support@neutrinos.co](mailto:support@neutrinos.co). The node will be reviewed for its accuracy and uniqueness before uploading to the [Neutrinos Store](/smart/project-concepts/neutrinos-store) for the other developers to download and use it.
