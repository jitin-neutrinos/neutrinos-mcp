# Names and Descriptions

<https://documentation.neutrinos.com/articles/#!plugins-builder-guide-8/best-practices>

Before you create a node in Plugins Builder, consider asking yourself the following questions:

- Are there nodes that I can reuse instead of creating a new node?
- What [type of node](/smart/project-concepts/node/a/h3__1155479691) do I want to create?
- What functionality do I want my node to have?
- What configuration options/attributes will my node have?
- What are the most important use cases, and how will my node help solve these use cases?
- How should my node appear on Neutrinos Studio?

Answering these questions will help you gain clarity on the functionality of the node and how the node should look when downloaded by other users.

### Names and Descriptions

Once your node is uploaded to [Neutrinos Store](/smart/project-concepts/neutrinos-store), names and descriptions help users understand what is the goal of your node and how to use it. It also keeps your folder structure unique within the Neutrinos repository to make sure that the node import does not fail.

Names should be clear and clarify the functionality of the node. Therefore, make sure you give a clear name for your node and enter a proper description that describes the purpose of the node.
