# Add a Common Node

<https://documentation.neutrinos.com/articles/#!plugins-builder-guide-8/add-a-common-node>

| ![Information](/resources/Storage/plugins-builder-guide-8/info.png) | Before you add a node, learn about the [types of nodes](/smart/project-concepts/node) in Neutrinos Studio. |
| --- | --- |

To add a common node:

1. Expand **Nodes** and click the plus icon next to the **common **option.
    ![Add a node](/resources/Storage/plugins-builder-guide-8/common%20node.png)
2. Enter the name of the node that you want to create and press the **Enter **button. Make sure you name the node based on its functionality. The node gets added under the **common **section. Expand the node to view the editors that you can use to customize the node.
    ![Adding a node name](/resources/Storage/plugins-builder-guide-8/common%20node%201.png)![folder structure for client node](/resources/Storage/plugins-builder-guide-8/coomon%20node%20folder.png)
3. Enter the [node details](/articles/plugins-builder-guide-8/node-details).
4. Define the [node attributes](/articles/plugins-builder-guide-8/node-attributes).
5. Add the [node dependencies](/articles/plugins-builder-guide-8/node-dependencies).
6. Define the [code generation](/articles/plugins-builder-guide-8/code-generation) logic.
7. Add the required [node utility](/articles/plugins-builder-guide-8/node-utils) files.
8. [Publish](/articles/plugins-builder-guide-8/publish-the-node-package) the node package to test the node in the respective designer.
9. [Export to Production Publish](/articles/plugins-builder-guide-8/export-for-production-publish) to send the node to Neutrinos.
