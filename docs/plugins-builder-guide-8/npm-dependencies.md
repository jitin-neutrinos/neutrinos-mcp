# NPM Dependencies

<https://documentation.neutrinos.com/articles/#!plugins-builder-guide-8/npm-dependencies>

Use this editor to add npm dependencies that are required for all the nodes that you will be creating in this package.

Each node can depend on a third-party package to achieve its functionality. Any third-party package that the node depends on should first be added to the NPM dependencies editor. You can then select the required dependency that the node requires in the [Node dependencies](/articles/plugins-builder-guide-8/node-dependencies) editor.

To add an npm dependency, open the NPM Dependencies editor, enter the **Name **and **Version **of the dependency, and click **Add**.

The dependency gets added to the package and appears in the list. You can delete the dependency from the list if it is not required by nodes within the package.
