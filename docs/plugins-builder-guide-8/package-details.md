# Package Details

<https://documentation.neutrinos.com/articles/#!plugins-builder-guide-8/package-details>

Use this editor to add or edit package details such as:

- **Display name: **The name of the package to be displayed on [Neutrinos Store](/smart/project-concepts/neutrinos-store).
- **Version: **The version of the package. By default, the version is 1.0.0.
- **Description: **The purpose of the package.
- **Generated Package Name: **The package name provided by Neutrinos Studio.
- **Package Store Icon: **The icon to represent the package on Neutrinos Store.
