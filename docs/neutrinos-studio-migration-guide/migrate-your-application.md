# Migrate App

<https://documentation.neutrinos.com/articles/#!neutrinos-studio-migration-guide/migrate-your-application>

Whenever you upgrade Neutrinos Studio to a new version, you must upgrade the applications you created in your previous version to the latest version as well.

To Auto-migrate your app, perform the following steps:

1. Launch the Neutrinos Studio version 7.2.0.
2. Click the one-click migrate ![](/resources/Storage/neutrinos-studio-migration-guide/migrate.png)icon to migrate your app.
