### Migration Steps

#### Save the Parser nodes

If you have used parser nodes in the Server Services of the apps created before Neutrinos Version 7.2.0, the parser nodes will be unsaved in the services after migration. To save the parser nodes after migration, perform the following steps:

1. Migrate your app to version 7.2.0 and open the app. Navigate to Server Services.
2. Open the parser nodes and save it again manually.
