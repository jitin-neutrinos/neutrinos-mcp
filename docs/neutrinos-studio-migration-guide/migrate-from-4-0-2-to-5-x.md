# Migrate from 4.0.2 to 5.x

<https://documentation.neutrinos.com/articles/#!neutrinos-studio-migration-guide/migrate-from-4-0-2-to-5-x>

There are no manual migration steps to be performed to migrate from version 4.0.2 to 5.x.

If you are migrating your app from previous releases of Neutrinos Studio to version 5.x, perform the migration steps mentioned in the below topics (based on the version which you are upgrading from) before you proceed with this topic.

- [Migrate from 3.3.1 to 4.0.2](/articles/neutrinos-studio-migration-guide/migrate-to-402)
- [Migrate to 3.3.1](/articles/neutrinos-studio-migration-guide/migrate-to-3)
