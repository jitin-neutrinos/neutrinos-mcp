# Configure Phone Number Code

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/configure-the-phone-number-code>

You configure a phone number code that will be used as a default code for the phone number field in the contacts and cases module using the **Settings** > **Phone Number Code **page.

To configure the Phone Country node for the application:

1. On the **Settings** page, select **Theme and Logos**.
2. Select **Phone Country Code**. The **Configure Phone Country Code** page appears on the right.
3. Select the country code from the auto-select drop-down list.
4. Click **Save**.
