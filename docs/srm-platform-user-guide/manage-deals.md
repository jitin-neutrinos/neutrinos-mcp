# Deals Details Page

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/manage-deals>

### Deals Details Page

When you [add a deal](/articles/srm-platform-user-guide/add-a-deal)or click on an existing deal, you are navigated to the **Deal Details** page. This page allows you to perform different sales activities related to the deals.

It includes the following sections:

- Deal Header
- Deal Summary
- Documents
- External Links
- Notes

### Deal Header

This section displays a few details of the deal such as deal name, contact name, [deal owner](/articles/project-user-guide-srm/deal-owner), and the deal ID. It also provides icons to [call](/articles/srm-platform-user-guide/place-a-call) the contact associated with this deal and [delete](/articles/srm-platform-user-guide/delete-a-deal) the deal.

This section also displays the deal pipeline using which you can configure the state of the deal. See [Deal Pipeline](/articles/project-user-guide-srm/deal-pipeline)to know about the different stages of a deal.

---

### Deal Summary

This section displays the details of the deal such as basic details, nominee details, etc. Click the **Edit **icon on the header to edit the deal details.

The **Edit Deal **page appears to the right. Edit the deal details and click the **Update** button.

![edit deal details window](/resources/Storage/srm-platform-user-guide/edit_deal_window.png)

---

### Documents

This tab displays all the documents related to the deal. You can upload additional documents by clicking the **Add Document** icon. See [Work with documents](/articles/srm-platform-user-guide/work-with-documents) to learn about the operations that you can perform with the documents.

### External Links

This tab display links that re-directs the agents to external applications such as an eFNA platform or an EKYC or any web form that can be embedded.

The link would be common to all the users of the application and is configured as per the client’s needs. The links are not configurable by the admin user and can only be updated by the Neutrinos team.

---

### Notes

This section allows you to add sticky notes about the deal. You can also view the notes that are added by other users. See [Work with Notes](/articles/srm-platform-user-guide/work-with-notes) to learn about the operations that you can perform with notes.
