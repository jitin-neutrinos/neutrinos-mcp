# Configure Default Currency

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/configure-default-currency>

You configure the default currency for the money fields that you add in the [contacts](/articles/srm-platform-user-guide/manage-contact-module)and [deals](/articles/srm-platform-user-guide/manage-deal-module)modules management section using the **Settings > Default Currency** page.

To configure the default currency for the application :

1. On the **Settings** page, select **Default currency. **The Configure Default Currency page appears on the right.
2. Enter the following details:
  - **Currency Type:** Select the default currency from the drop-down list.
  - **Separator Type:** Select the type of separator from the drop-down list.
  - **Decimal Value: **This is a read-only field. By default, the decimal value is 2.
3. Click **Save**.
