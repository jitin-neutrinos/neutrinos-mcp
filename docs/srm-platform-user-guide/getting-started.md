# Getting Started

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/getting-started>

The SRM platform allows businesses to produce, store, and track sales for all leads and contacts in one place. The platform is equipped with a robust set of features that allow agents and hierarchical users to perform a variety of sales operations, such as tracking and progressing new product sales, maintaining existing sales pipelines with daily summary and dashboard capabilities.
