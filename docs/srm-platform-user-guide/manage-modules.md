# Manage Modules

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/manage-modules>

The Neutrinos SRM application has two main modules namely, contacts and deals. You can configure these modules by selecting **Module Management** on the **Settings **page.

- [Manage contacts module](/articles/srm-platform-user-guide/manage-contact-module)
- [Manage deals module](/articles/srm-platform-user-guide/manage-deal-module)
