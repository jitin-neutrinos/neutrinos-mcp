# Edit a Label

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/work-with-labels>

You can assign labels to a contact from the Contact Details page or the Contact List page.

- To assign a label to contact, click the Add Label icon on the [Contact Details](/articles/srm-platform-user-guide/srm-platform-ui/a/h4__1524852451) page.
- To add labels to multiple contacts, select one or more contacts on the [Contact List](/articles/srm-platform-user-guide/srm-platform-ui/a/h4_1409235390) page and click the** Add label** icon.

After adding a label, you can:

- [Edit a Label](/articles/srm-platform-user-guide/work-with-labels/a/h3__1240667552)
- [Delete a Label](/articles/srm-platform-user-guide/work-with-labels/a/h3__924632505)
- [Re-order Labels](/articles/srm-platform-user-guide/work-with-labels/a/h3_976312257)

### Edit a Label

To edit a label:

1. Open the contact from the Contact List page whose labels you need to edit.
2. Click the **Add Label **icon.
3. On the** Add and View Label** page, click the **Edit** icon next to the label you want to edit.
4. Make the changes and click** Save**.

### Delete Label

To delete a label:

1. Open the contact from the contact list page whose labels you need to delete.
2. Click the **Add Label **icon and the **Add and View Labels** page appears.
3. Click the **Delete **icon and the label gets deleted.

### Re-order Labels

To re-arrange the order of labels:

1. Open the contact from the contact list page whose labels you need to re-arrange.
2. Click the **Add Label **icon and the** Add and View Labels** page appears.
3. Rearrange the order of the labels using the **Re-arrange** icon.
