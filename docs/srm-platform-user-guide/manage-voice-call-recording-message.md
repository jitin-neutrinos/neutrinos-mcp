# Manage Voice Call Recording Message

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/manage-voice-call-recording-message>

You configure a recording message that will be played before the client is connected to the voice call using the **Settings** > **Voice Call Recording Message **page.

To configure the Voice Call Recording Message:

On the **Settings** page, select **Theme and Logos**.Click **Voice Call Recording Message**.In the **Configure Voice Call recording Message** window, enter any message that has to be played before starting the voice call recording. For example: "**Hi, This call will be recorded for training and quality purposes."**Click **Save**. ![Voice recording message](/resources/Storage/srm-platform-user-guide/voice_message.png)
