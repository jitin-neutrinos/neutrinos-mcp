# Action Panel

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/srm-platform-ui>

The UI of the SRM platform is divided into the following sections:

### Action Panel

This panel is static across the SRM application. It displays a search bar, an Add button, a calendar icon, and the user profile.

Using the search bar, you can perform a global search.

Using the Add button, you can:

- add contacts,
- add cases,
- add tasks,
- add appointments,
- Import Contacts

By clicking on the calendar icon, you can view the calendar of the month.

By clicking on User Profile, you can log out of the application.

---

### Module Navigation Panel

This panel contains different modules that are available on the platform. The modules are Daily Summary, Contacts, Deals, Dashboard, and Import Contact History.

---

### Editor Workspace

The editor workspace allows you to perform actions with respect to the editors.

#### Contacts List Page UI

- **Page Header**: Displays the name of the page.
- **Contacts ****Tab**: Helps navigate between My Contacts and Team Contacts.
- **Contacts List**: Displays the list of contacts.

#### Contact Details Page UI

Once you click any contact from the **Contacts List **page, the **Contact Details** page will appear.
