# Bulk Add Labels

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/perform-bulk-actions>

### Bulk Add Labels

To bulk add labels to the contacts:

1. Open the [Contacts List](/articles/srm-platform-user-guide/srm-platform-ui/a/h4_1409235390) page and select the contacts.
2. Click the** Add Label** icon and enter the label name.
3. Click Save label or press Enter.

See [Work with Labels](/articles/srm-platform-user-guide/work-with-labels) to learn more about the operations that can be performed on the labels.

### Bulk Re-assign Contacts

To bulk Re-assign contacts:

1. Open the Contacts List page and select the contacts that you want to re-assign.
2. Click the** Re-Assign Contacts** icon and enter the following:
  - Total contacts selected for re-assignment:
  - User: Enter the name of the user to whom you want to assign a contact.
3. Click **Re-assign**.

### Bulk Export as CSV of Contacts

To bulk export contacts and the corresponding details to a CSV file:

1. Open the Contacts List page and select the contacts.
2. Click the** Export as CSV** icon. The CSV file will be downloaded to your local machine.

### Bulk Export CSV of Deals

To bulk export deals and the corresponding details to a CSV file:

1. Open the Deals List page and select all deals.
2. Click the** Export as CSV** icon. The CSV file will be downloaded to your local machine.
