# Add Roles

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/add-roles>

You can add roles on the SRM platform based on your organization's requirements. Roles in an organization can be Manager, Team Lead, Developer, etc.

### Add Roles

To add a role:

1. On the **Settings **page, select **Users and Roles**.
2. On the **User Management** page, Navigate to the **Roles **tab.
3. Click the **Add Role** icon and enter the following details in the **Add Role** window that appears to the right. Enter the name of the role in the **Role Name** field. For example, **Manager**.
    Under **Primary Permissions**, assign the primary permission of the role.
    Under **Additional Permissions,** assign additional permissions to the role. These permissions are based on the primary permission assigned to the role.
  - **My Access**: Select this checkbox to provide privileges to access and edit assigned contacts and deals.
  - **Global Access**: Select this checkbox to provide privileges to access and view all the records on the platform.
      ![Information](/resources/Storage/srm-platform-user-guide/info.png)
      You have to assign Primary permission for each role.
  - **Contact Re-Assign**: Select this checkbox to provide privileges to re-assign contacts.
  - **Delete Contact**: Select this checkbox to provide privileges to delete contacts.
  - **Delete Deal**: Select this checkbox to provide privileges to delete deals.
  - **Admin**: Select this checkbox to provide admin privileges to the role.
4. After entering the details, click **Add **to add the role.

### Edit Role

To edit role details:

1. On the **Settings **page, select **Users and Roles**.
2. On the **User Management** page, Navigate to the **Roles** tab.
3. Click the **Edit Role **icon next to the role you want to edit.
    ![edit role](/resources/Storage/srm-platform-user-guide/admin_edit_role.png)
4. The **Add Role** page is displayed to the right. Edit the name or permissions of the role and click the **Update **button.
