# Sign In

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/sign-in>

To log in to the SRM platform, navigate to [https://srm.neutrinos.co/](https://srm.neutrinos.co/).

You can log in to the platform through the following methods (depending on the login method your organization supports).

- **Neutrinos IDS:** This allows you to log in using the username and password managed by Neutrinos.
- **Google AD Account**: This allows you to log in using a Google account. Enter the registered Google email address and password.
- **Azure AD Account**: This allows you to log in using an Azure AD account. Enter the registered Azure AD email address and password.
