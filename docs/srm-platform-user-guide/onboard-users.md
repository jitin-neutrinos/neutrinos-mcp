# Add a User

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/onboard-users>

After you [define roles](/articles/srm-platform-user-guide/add-roles), you can onboard users on the SRM platform and assign roles to them. The users you onboard can be a manager, a team lead, or an agent.

### Add a User

To add a user:

1. On the **Setting** page, click **Users and Roles**.
2. On the **User Management** page, click the **Add User** icon and enter the following details in the **Add User **window:
    ![add user icon for users](/resources/Storage/srm-platform-user-guide/add_user_icon.png)
  - **First name**: The first name of the user.
  - **Last name**: The last name of the user.
  - **Mobile number**: Select the country code and enter the mobile number of the user.
  - **Email Address**: Enter the email address of the user.
  - **Select role**: Select the role of the user from the drop-down list. The roles drop-down list displays a list of roles that you created in the [Add Roles](/articles/srm-platform-user-guide/add-roles) section.
  - **User Status**: Check the status of the user. The status can be either **Active **or **Inactive**.
3. After adding the user details, click the **Add **button and the user gets added to the list of users.
    ![add user credentials](/resources/Storage/srm-platform-user-guide/new%20user.png)

### 

### Search Users

### 

To search a user:

1. Click the search icon on the top navigation.
2. In the search field, enter the **Email ID**, **First name**, or **Last name** of the user and click the **Search** icon. The results that match your search query will be displayed.

### Edit Users

To edit the details of the user:

1. Click the **Edit User **icon for the user you want to edit. The user details will be displayed on the right.
2. Edit the details and click the **Update** button. The changes will be saved.

| ![Information](/resources/Storage/srm-platform-user-guide/info.png) | If you want to disable the user from using the platform, you can set the status of the user to **Inactive**. |
