# Download File

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/re-assign-imported-contacts>

Once the CSV file is uploaded, the CSV file is sent for processing.

To view the status of the file, open the **Import Contact History** module.

- When the file is uploaded and sent for validation, the status of the file is displayed as **Processing**.
- If the format of the file is invalid, then the status of the file is displayed as **Invalid File **and any further actions on this file cannot be performed.
- If the file is successfully validated, the status of the file is displayed as **Pending Assignment**.

If the status of the file is **Pending Assignment**, you can perform the following actions:

- [Download File](/articles/srm-platform-user-guide/re-assign-imported-contacts/a/h3_430278192)
- [Re-Assign Contacts](/articles/srm-platform-user-guide/re-assign-imported-contacts/a/h3__2012226744)
- [Cancel File](/articles/srm-platform-user-guide/re-assign-imported-contacts/a/h3__800851418)

### Download File

To download a file:

1. Open the **Import Contact History** Module.
2. Click the **Cancel **icon on the file name that you have imported. If the status of the file is displayed as Invalid File, you can view the reason for valid and invalid records in this file.

### Re-Assign Contacts

To re-assign the imported contact:

1. Open the **Import Contact History** Module.
2. Click the **Re-assign **icon on the file name.
3. Enter the following details:
  1. **Total number of contacts**: Displays the count of Total Contacts you’ve selected to be reassigned.
  2. **User**: The user you want to assign the contacts to.
4. Click **Assign**.

### Cancel File

To delete a file:

1. Open the **Import Contact History** Module.
2. Click the **Cancel **icon on the file name that you want to delete. A pop-up appears to confirm the deletion.
3. Click **Yes**. Once the file is cancelled, the status of the file is updated to **Cancelled**.
