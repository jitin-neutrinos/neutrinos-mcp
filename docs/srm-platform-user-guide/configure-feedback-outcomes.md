# Add a Feedback Outcome

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/configure-feedback-outcomes>

You configure the default list of outcomes that can be tagged to an appointment or call using the **Settings > Feedback** **Outcome **page.

On this page, you can:

- [Add a Feedback Outcome](/articles/srm-platform-user-guide/configure-feedback-outcomes/a/h3_1770273299)
- [Edit Outcome](/articles/srm-platform-user-guide/configure-feedback-outcomes/a/h3__1418262298)
- [Delete Outcome](/articles/srm-platform-user-guide/configure-feedback-outcomes/a/h3__833992201)
- [Re-order Outcomes](/articles/srm-platform-user-guide/configure-feedback-outcomes/a/h3_2073011654)

### Add a Feedback Outcome

To add an outcome:

On the **Settings **page, select **System Settings.**Click **Feedback Outcome**.On the **Configure Feedback Outcome page**, select the **Appointment **or **Call **tab to which you want to add an outcome.Click the **Add Outcome** button and **Enter Outcome** field appears. Enter the name of the outcome and click the **Save Label** icon or press **Enter**. The new outcome gets added to the list. ![Add feedback page](/resources/Storage/srm-platform-user-guide/Add_feedback.png)
Edit OutcomeTo edit the outcome:On the **Settings **page, select **System Settings.**Click **Feedback Outcome**.On the **Configure Feedback Outcome page**, select the **Appointment **or **Call **tab to which you want to add an outcome.Click the **Edit** icon next to the outcome that you want to edit.Edit the name of the outcome and click the **Save Label** icon or press **Enter**.![Edit the feedbacks](/resources/Storage/srm-platform-user-guide/edit_feedback.png)
Delete OutcomeTo delete an outcome:On the **Settings **page, select **System Settings.**Click **Feedback Outcome**.On the **Configure Feedback Outcome page**, select the **Appointment **or **Call **tab to which you want to add an outcome.Click the **Delete** icon next to the outcome you want to delete. ![delete icon for the feedback outcome](/resources/Storage/srm-platform-user-guide/delete_feedback.png)Re-order OutcomesTo re-arrange the Feedback Outcomes:On the **Settings **page, select **System Settings.**Click **Feedback Outcome**.On the **Configure Feedback Outcome page**, select the **Appointment **or **Call **tab to which you want to add an outcome.Click and hold the **Rearrange icon** of the outcome you want to move. Drag upwards or downwards to re-arrange and the order of the outcomes gets updated.
