# View Stats Dashboard

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/view-stats-dashboard>

This page displays the historical statistics of the events that are performed by the user using the SRM platform.

Depending on the reporting hierarchy, this page consists of two tabs:

- [My Stats](/articles/srm-platform-user-guide/view-my-stats)
- [Team Stats](/articles/srm-platform-user-guide/view-team-stats)

Dashboard Section can be viewed with three filters:

- Weekly: Select this to view the data week-wise.
- Monthly: Select this to view the data month-wise.
- Custom Date: Select any custom date range by changing the From and To date.
