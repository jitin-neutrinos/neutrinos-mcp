# Add a Deal

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/add-a-deal>

To add a new deal, perform the following steps:

Click the **Add **button on the [action panel](/articles/srm-platform-user-guide/srm-platform-ui/a/h4_898368986) and select **Deal**. The Add Deal page is displayed to the right.In the **Add Deal **page, enter the following data:**Name:** The name of the deal. This is a mandatory field.**Value**: Select the currency symbol from the drop-down and enter the monetary value associated with the deal.**Related Contact**: Enter the contact name with whom the deal needs to be associated with and select from the drop-down list. Click **Add**.
