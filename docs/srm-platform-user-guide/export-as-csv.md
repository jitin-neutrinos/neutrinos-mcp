# Export as CSV

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/export-as-csv>

To export the contact details in a CSV file:

1. On the **Contact List** page, select the checkbox of the contact that you want to export.
2. Click the** Export as CSV **icon. The file is downloaded to your local machine.

To export CSV file of a deal:

1. On the **Deals List** page, select the checkbox of the deal that you want to export.
2. Click the** Export as CSV **icon. The file is downloaded to your local machine.
