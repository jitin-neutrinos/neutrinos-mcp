# Overview

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/view-team-stats>

On this page, you can view the statistics of the team that reports to you.

This tab provides a quick insight into the following:

- [Overview](/articles/srm-platform-user-guide/view-team-stats/a/h3__773755849)
- [Deal Dropout Summary](/articles/srm-platform-user-guide/view-team-stats/a/h3_866156127)
- [Appointment Outcome](/articles/srm-platform-user-guide/view-team-stats/a/h3__1368682171)
- [Call Outcome](/articles/srm-platform-user-guide/view-team-stats/a/h3__1297841330)
- [Team Average](/articles/srm-platform-user-guide/view-team-stats/a/h3_1620820628)

### Overview

On this card, you can view the average statistics of your team with details such as:

- **New Contacts**: Displays the number of new contacts you have created.
- **New Deals**: Displays the number of deals you have created.
- **Calls Made**: Displays the number of voice calls made by you to the clients.
- **Appointments** **Made**: Displays the number of appointments scheduled.s
- **Deals Won**: Displays the number of deals won.
- **Deals Lost**: Displays the number of deals lost.

### Deal Dropout Summary

This card provides statistical insight into the average number of deals lost in the various stages of the deal pipeline by your team. It provides the medium to know at what stage deals are usually lost and how to improve the sales process.

The details inside the card depend on the deal pipeline stages configured by the administrator.

![deal dropout summary](/resources/Storage/srm-platform-user-guide/deal_drop_out.png)

### Appointment Outcome

This card provides average statistics of the outcomes that are captured from the appointments. It provides insight to the agent about the responses that are provided by the contacts about the meetings using which you can improve your approach on sales.

The details inside the card depend on the outcomes that are defined for the appointments by the administrators.

![appointment outcome stats](/resources/Storage/srm-platform-user-guide/appointment_outcome.png)

### Call Outcome

This card provides average statistics of the outcomes that are captured from the voice calls made by your team. It provides insight into the responses that are provided by the contacts about the calls using which you can improve your approach on sales.

The details inside the card depend on the outcomes that are defined for the calls by the administrators.

![call_outcome stats](/resources/Storage/srm-platform-user-guide/call_outcome.png)

### Team Average

This card provides the team's average count for each element inside the card. You can select a particular employee from your team through the filter icon and you can compare the individual performance of your team member against the team average.
