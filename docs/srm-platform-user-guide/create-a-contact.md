# Add a Contact

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/create-a-contact>

To add a new contact, perform the following steps:

Click the **Add **button on the [action panel](/articles/srm-platform-user-guide/srm-platform-ui/a/h4_898368986) and select **Contact**. The Add Contact page is displayed to the right.In the **Add Contact** page, enter the following data:**First Name**: The first name of the contact. This is a mandatory field.**Last Name**: The last name of the contact. **Mobile Number**: The mobile number of the contact. Select the country code and enter the mobile number. This is a mandatory field.**Email Address**: The email address of the contact. This is a conditional mandatory field.Click **Add**.

![Add contacts window](/resources/Storage/srm-platform-user-guide/add_contact.png)

The contact gets created and you will be navigated to the [Contact Details page](/articles/srm-platform-user-guide/manage-contacts/a/h3_539825653) to manage details of the contact.
