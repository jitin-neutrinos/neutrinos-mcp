# Manage Sections

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/manage-deal-module>

On the **Deals Module Page**, you define all the fields that you want to capture for a deal, segregate them into multiple sections, and add field dependencies (if any). See:

- [Manage Sections](/articles/srm-platform-user-guide/manage-deal-module/a/h3_1921241361)
- [Manage Fields](/articles/srm-platform-user-guide/manage-deal-module/a/h3_147134074)
- [Manage Field Dependencies](/articles/srm-platform-user-guide/manage-deal-module/a/h3_2007944301)

### Manage Sections

#### Add a new section

To add a new section:

On the Settings page, select **Deals Module.**Click the **Add Section** button. Enter a unique name of the section in the **Enter Section Name** field. For example, **Insurance Details.**Click **Save**.![new section](/resources/Storage/srm-platform-user-guide/new_deal_section.png)

#### Edit a section

To edit a section:On the **Settings **page, select **Deals Module**.Hover on the section name that you want to edit and click the **Edit Section Name** icon.Edit the name of the section and click **Save**.![edit section details for deals](/resources/Storage/srm-platform-user-guide/edit_section_deals.png)

Delete a sectionTo delete a section:On the **Settings** page, select **Deals Module**.Hover on the section name that you want to delete.Click the **Delete Section** icon. A pop-up appears asking to re-confirm your action. Click **Yes**. ![delete a field foe deals](/resources/Storage/srm-platform-user-guide/delete_field_deals.png)Re-order Sections To arrange the order of sections:On the **Settings **page, select **Deals Module**.Hover on the section name that you want to re-arrange.Use the **Move Up** and **Move Down **icons to re-arrange the order of sections. ![Information](/resources/Storage/srm-platform-user-guide/info.png)The **Basic Details **section cannot be re-ordered.
![rearrange the sections](/resources/Storage/srm-platform-user-guide/rearrange_icon_deals.png)

### Manage Fields

Add a New Field

To add a new field:

On the Settings page, select **Deals Module.**Click the **Add Field **button.Enter the following details:**Section**: Select the section name under which the field should be added. **Field Type: **Select the field type from the drop-down list. Depending on the field type selected, the required parameters will change.**Field Label: **Enter the label for the field.**Make this a mandatory field**: Check this field to make it mandatory. Click **Add.**

![Add field for the deals](/resources/Storage/srm-platform-user-guide/add_field_deals.png)
