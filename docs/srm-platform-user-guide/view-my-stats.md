This tab provides a quick insight into the following:

- [Overview](/articles/srm-platform-user-guide/view-my-stats/a/h3__773755849)
- [Deal Dropout Summary](/articles/srm-platform-user-guide/view-my-stats/a/h3_866156127)
- [Appointment Outcome](/articles/srm-platform-user-guide/view-my-stats/a/h3__1368682171)
- [Call Outcome](/articles/srm-platform-user-guide/view-my-stats/a/h3__1297841330)

### Overview

This card displays your overall statistics such as:

- **New Contacts**: Displays the number of new contacts you have created.
- **New Deals**: Displays the number of deals you have created.
- **Calls Made**: Displays the number of voice calls made by you to the clients.
- **Appointments** **Made**: Displays the number of appointments scheduled.s
- **Deals Won**: Displays the number of deals won.
- **Deals Lost**: Displays the number of deals lost.

### Deal Dropout Summary

This card provides statistical insight into the number of deals lost in the various stages of the deal pipeline. It provides the medium to know at what stage deals are usually lost and how to improve the sales process.

The details inside the card depend on the deal pipeline stages configured by the administrator.

### Appointment Outcome

This card provides statistics of the outcomes that are captured from the appointments. It provides insight to the agent about the responses that are provided by the contacts about the meetings using which you can improve your approach on sales.

The details inside the card depend on the outcomes that are defined for the appointments by the administrators.

### Call Outcome

This card provides statistics of the outcomes that are captured from the voice calls made. It provides insight into the responses that are provided by the contacts about the calls using which you can improve your approach on sales.

The details inside the card depend on the outcomes that are defined for the calls by the administrators.
