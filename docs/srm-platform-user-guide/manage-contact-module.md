# Manage Sections

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/manage-contact-module>

On the **Contacts Module** page, you define all the fields that you want to capture for a contact, segregate them into multiple sections, and add field dependencies (if any). See:

- [Manage Sections](/articles/srm-platform-user-guide/manage-contact-module/a/h3_1921241361)
- [Manage Fields](/articles/srm-platform-user-guide/manage-contact-module/a/h3_147134074)
- [Manage Field Dependencies](/articles/srm-platform-user-guide/manage-contact-module/a/h3__1262285589)

### Manage Sections

#### Add a New Section

To add a new section:

On the **Settings **page, select **Contacts Module**.Click the **Add Section** button. Enter a unique name of the section in the **Enter Section Name** field. For example, **Organization Details.**Click **Save**.

Edit a Section To edit a section:On the **Settings **page, select **Contacts Module**.Hover on the section name that you want to edit and click the **Edit Section Name** icon.Edit the name of the section and click **Save**. ![edit details of the section for contacts](/resources/Storage/srm-platform-user-guide/edit_section_contacts.png)Delete a Section To delete a section:On the **Settings** page, select **Contacts Module**.Hover on the section name that you want to delete.Click the **Delete Section** icon. A pop-up appears asking to re-confirm your action. Click **Yes**. ![delete section in the contacts](/resources/Storage/srm-platform-user-guide/delete_section_contacts.png)Re-order Sections To arrange the order of sections:On the **Settings **page, select **Contacts Module**.Hover on the section name that you want to re-arrange.Use the **Move Up** and **Move Down **icons to re-arrange the order of sections.



 ![Information](/resources/Storage/srm-platform-user-guide/info.png)

 The **Basic Details **section cannot be re-ordered.
