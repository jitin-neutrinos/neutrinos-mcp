# Add Task

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/work-with-tasks>

### Add Task

You can add a task by clicking the **Add Task** icon on any of the Contact and Deal pages. Or, by clicking the **Add **button on the [action panel.](/articles/srm-platform-user-guide/srm-platform-ui/a/h3_898368986)

On the **Add Task** page, enter the following details and click the **Add **button:**Title: **The title for the task. This is a mandatory field.**Related Contact**: The contact name that is related to this task. This field will be prefilled if you are adding the task from a particular contact or the deal details page.**Related Deal:** The deal name that is related to this task. This field will be prefilled if you are adding the task from a particular contact or the deal details page.**Location: **The address of the location at which the task is going to take place. **Description: **The description of the task.**Date&Time**: The date and time before which the task should be completed.**Task Complete: **The task completion status.![Add task page](/resources/Storage/srm-platform-user-guide/add_task.png)

### View task

You can view the created tasks from [Daily Summary](/articles/srm-platform-user-guide/daily-summary-functionalities) and [Contact Details](/articles/srm-platform-user-guide/srm-platform-ui/a/h4__1524852451) pages, or by viewing the **Calendar** from the [action panel](/articles/srm-platform-user-guide/srm-platform-ui/a/h3_898368986).

To view the tasks from the Daily Summary page, perform the following:

1. Open the Daily Summary page.
2. Select the task that you want to view from the Today's tasks or Future tasks card.
3. The View task page appears on the right.

To view the tasks from the calendar, perform the following:

1. Click the **Calendar **icon on the action panel.
2. Navigate to the day tab to view the tasks for the day. You can also select the Week and Month tabs to view the future tasks.
3. Click on the task and the **View task **page appears to the right.

To view the tasks from the contact details page, perform the following:

1. Open the contact details page of the contact.
2. Navigate to the **All Activities **section, and select** Tasks.** You can view all the tasks created by this contact.

### Edit task

To edit a task, perform the following steps:

Open the task from the **Daily Summary**, **Contact Details **page, or the **Calendar** from the action panel. The **View task** page is displayed to the right.Click the **Edit **icon and make changes. Click update and the changes are saved.To edit a task from the Contact Details page:Navigate to the **All Activities **section, and select** Tasks.**Click the **Edit icon. **Edit the task and click **Add**.![edit tasks](/resources/Storage/srm-platform-user-guide/edt_task.png)

### Delete task

To delete a task, perform the following steps:

Open the task from the **Daily Summary, **or the **Calendar** from the action panel. The **View task** page is displayed to the right.Click the **D****elete **icon. A pop-up appears to confirm the deletion. Click **Yes **and the task gets deleted.![delete task](/resources/Storage/srm-platform-user-guide/delete_task.png)
