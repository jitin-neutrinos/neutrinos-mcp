# Add a Note

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/work-with-notes>

You can add notes regarding a contact or a deal using the **Notes section** on the respective [Contact Details](/articles/srm-platform-user-guide/manage-contacts) and [Deal Details](/articles/srm-platform-user-guide/manage-deals) pages.

| ![Information](/resources/Storage/srm-platform-user-guide/info.png) | You can add notes about any contact irrespective of the contact owner. |
| --- | --- |

### Add a Note

To add a new note, perform the following steps:

1. Click the contact or deal to which you want to add a note.
2. Click the **Add Notes** icon and enter the description for the note.
3. Click the **Save **icon and the note is added.

Once the note is added, it is displayed under the **Notes section** with the Username, Date & Time of when the note was added, and the description.

After adding a note, you can:

- [Update a note](/articles/srm-platform-user-guide/work-with-notes/a/h3_144051593)
- [Pin/Unpin a note](/articles/srm-platform-user-guide/work-with-notes/a/h3_60676199)
- [Delete a note](/articles/srm-platform-user-guide/work-with-notes/a/h3_2057286362)

### Update a Note

To update a note:

1. Click the **Edit** icon next to the note you want to update.
2. Update the note and click the **Save **icon.

### Delete a Note

You can delete the notes that are added by you.

To delete a note, click the **Delete Note **icon next to the note that you want to delete.

### Pin or Unpin the Note

You can pin and unpin the notes that are added to the contacts and deals that are owned by you.

To pin unpin a note, click the** Pin and Unpin** icon next to the note.
