# Import Contacts

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/import-contacts>

To import contacts, perform the following steps:

1. Click the **Add** button on the [action panel](/articles/srm-platform-user-guide/srm-platform-ui/a/h4_898368986) and select **Import Contact**.
2. On the **Import Contact** page, download the **Sample CSV **file.
3. Open the downloaded sample CSV and enter the details of the contacts you want to import.
4. After entering the contact details, upload the CSV file to the Import Contacts page by dragging and dropping the file or uploading it from the local machine.
5. Click **Import**.
