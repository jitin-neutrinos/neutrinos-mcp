# Add Feedback to an Appointment

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/work-with-feedback>

You add feedback to an appointment or call on the [Contact Details](/articles/srm-platform-user-guide/manage-contacts/a/h3_539825653) page.

### Add Feedback to an Appointment

To add feedback to a completed appointment of a contact:

1. Select** Appointments **on the **All Activities **section.
2. Click the **Add Feedback **button under the appointment.
3. On the **Appointment Log** page, enter the following details:
  - Select Outcome: Select an appropriate outcome from the drop-down list.
  - Enter Feedback: Enter any additional feedback that you want to mention.
4. Click **Add**.

### Add Feedback to a Call

To add feedback to a completed call of a particular contact:

1. Navigate to the **All Activities **section, and select** Calls.**
2. Click the **Add Feedback **button under the call.
3. On the** Call Log** page, enter the following details:
  - **Select Outcome**: Select an appropriate outcome from the drop-down list.
  - **Enter Feedback**: Enter any additional feedback that you want to mention.
4. Click **Add**.

### Edit Feedback for Appointment

To edit the feedback of an appointment:

1. Navigate to the **All Activities **section, and select** Appointments.**
2. Click the **Edit icon **on the existing feedback.
3. Make changes and click **Add**.

### Edit Feedback for Call

To edit the feedback of a call:

1. Navigate to the **All Activities **section, and select** Calls.**
2. Click the **Edit icon **on the existing feedback.
3. Make changes and click **Add**.
