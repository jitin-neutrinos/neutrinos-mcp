# Filter Contacts and Deals

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/filter-contacts-and-deals>

**Apply Filters on your Contacts**

To apply filters on the **My Contacts** tab:

1. On the [Contacts List](/articles/srm-platform-user-guide/srm-platform-ui/a/h4_1409235390) page, click the** Set Filter** icon.
2. Select the filters based on which you want to search for a contact.
3. Click **Apply**.

**Apply Filters on Team Contacts **

To filters on the **Team Contacts** Tab:

1. On the **Contacts List** page, navigate to the **Team Contacts** tab.
2. Click the** Set Filter** icon and select the filters based on which you want to search contacts of your team.
3. Click **Apply**.

**Apply Filter on your Deals**

To filter My Contact:

1. On the Deals List page, click the** Set Filter** icon.
2. Select the filters based on which you want to search for a deal.
3. Click **Apply**.

**Filter Team Deals**

To filter My Team Deals:

1. On the **Deals List** page, navigate to the **Team Deals** tab.
2. Click the** Set Filter** icon and select the filters based on which you want to search for a deal that belongs to your team.
3. Click **Apply**.
