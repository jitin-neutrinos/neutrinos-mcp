# Add Document

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/work-with-documents>

### Add Document

To add a document:

1. Open the contact or a case to which you want to add a document.
2. Navigate to the **Documents **tab and click the **Add ****Document **icon.
3. Drag and Drop a document or upload it from the local machine.
4. Add Document Tags to the document and click **Add**.

### Download Document

To download a document:

1. Open the contact or a case from where you want to download a document.
2. Navigate to the **Documents **tab and click the **Download Document **icon of the document that you want to download.

### Delete document

To delete a document:

1. Open the contact or a case from which you want to delete a document.
2. Navigate to the **Documents **tab.
3. Click the **Delete Document **icon of the document that you want to delete.
4. A pop-up appears to confirm your action, click **Yes**.

### Document information

To view the information of a document:

1. Open the contact or a case from which you want to delete a document.
2. Navigate to the **Documents **tab.
3. Hover on the **Information **icon.

### Edit document tags

To edit the tags of a document:

1. Open the contact or a case from which you want to delete a document.
2. Navigate to the **Documents **tab and click the document whose tags you want to edit.
3. Add or remove tags and click **Update**.
