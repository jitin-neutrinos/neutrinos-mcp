# View Daily Summary

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/daily-summary-functionalities>

After successful login to the SRM platform, you are navigated to the **Daily Summary **page. This page displays the following cards that give you a quick overview of your tasks, appointments, and deals.

1. **Today's Appointments**: This card displays the appointments lined up for the day. You can view details such as Appointment Name (Title), date, and time.
2. **Today's Tasks**: This card displays the tasks that are lined up for the day. These tasks can be created for you by other agents or you can create tasks for yourself. Each task card displays the Task Name (Title) and the Date&Time as the deadline for the task. Make sure you mark the task as complete after you finish the task.
3. **Overdue Tasks:** Each task that is created will have a due date and time before which the task should be completed. If any task is not marked as complete, it is displayed on this card.
4. **Future Appointments**: This card displays the appointments that are lined up for the future. You can use the filter icon to view the appointments for the next 3 days or 5 days.
5. **Future Tasks**: This card displays the tasks that are lined up for the future. You can use the filter icon to view the tasks for the next 3 days or 5 days.
6. **Pending Feedback:** For every meeting that takes place, you should add feedback to capture the outcome. If the feedback is not logged, then that appointment is listed under the** Pending Feedback **card.
    ![pending feedback card](/resources/Storage/srm-platform-user-guide/pending_feedback_DS.png)
7. **Active Deal Stage Summary**: This card displays the total number of Deals that you own. You can view the active number of deals in the different stages of the deal pipeline.
    ![Actve deal stage summary card](/resources/Storage/srm-platform-user-guide/activedealsummaryDS.png)
8. **Deal Amount By Stages**: This card displays the monetary amount associated with each stage in the deal pipeline.
    ![deal amount card](/resources/Storage/srm-platform-user-guide/dealamount.png)
