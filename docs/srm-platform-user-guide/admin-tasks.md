# Admin Tasks

<https://documentation.neutrinos.com/articles/#!srm-platform-user-guide/admin-tasks>

If you have [administrator](/articles/srm-platform-user-guide/terminologies/a/h4__871841297) privileges, you will have access to the **Settings** page on the SRM platform. We recommend that you perform these tasks in the following order:

1. [Manage users and roles](/articles/srm-platform-user-guide/manage-users-and-roles) - Add the contacts and deals to the platform.
2. [Manage contacts and deals modules](/articles/srm-platform-user-guide/manage-modules)- Design contacts and deals modules by defining the sections and fields that have to be captured for each contact and deal.
3. [Configure system settings](/articles/srm-platform-user-guide/configure-system-settings) - Configure the platform to suit your organizational requirements.
