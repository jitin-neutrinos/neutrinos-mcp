# Navigating Interface

<https://documentation.neutrinos.com/articles/#!ai-hub/navigating-interface>

This topic provides an overview of the AI Hub platform interface, detailing its key components and navigation structure. The platform consists of several primary sections: Dashboard, Prediction, Extraction, Tokens, Assistant, Knowledge, Audit Logs, and Deployment. Each component serves a specific function to facilitate model building, data extraction, and prediction for business workflows.

Upon logging into the platform, users have a dashboard displaying key statistics related to document classification and data extraction over time. These statistics are visually represented for quick analysis. The left-side navigation bar provides access to various platform features.

The following image illustrates the AI Hub platform dashboard and navigation bar:




 ![ai-hub-navigating-interface](/resources/Storage/ai-hub/images/ai-hub-navigate-interface.png)

1. **Dashboard**: The dashboard provides a summary of active users, active models, document classification, extraction, model distribution, and the number of models trained with monthly statistics.
2. **Prediction**: Create and train a prediction model tailored to your data and business requirements. You can:
  - Create a new prediction model using data inputs from text formats (Excel, CSV) or document types (PDF, image files, and others).
3. **Extraction**: Extract relevant information from text or documents to generate insights. You can:
  - Extract relevant data from specified fields in text formats (CSV, Excel) or document formats (PDF, image files, and others).
4. **Tokens**: This section allows you to manage the tokens required for executing or testing APIs. You can:
  - Generate tokens for the **Production** or **Sandbox** environment by specifying an expiration time for each.
5. **Assistant**: You can set up an AI chatbot with a model configured to preprocess input and extract data. The chatbot can also respond to user questions. You can:
  - View a dashboard to gain insights into a specific assistant, including metrics such as accuracy, reviewed questions, pending reviews, and average conversation time.
  - Configure the AI bot with rules or prompts that determine how it should handle user queries.
  - Integrate a knowledge base with the AI bot to support accurate and context-aware responses to user queries.
  - Configure the AI bot’s visual appearance by selecting a color scheme, uploading an icon, and applying a theme.
  - Identify and review messages that need human verification to ensure the accuracy and reliability of the AI bot’s responses.
  - Advanced options include the assistant name, placeholder text for the user input field, allowed domains for the AI bot, predictability quotient, and data retention period (in days).
6. **Knowledge**: Add a data source to train the AI bot and enable it to answer user queries.
7. **Audit Logs**: This section provides access to various logs, including login/logout logs, training logs, deployment logs, inference logs, and logs related to token creation.
8. **Deployment**: Access a list of models that have been deployed post-training in the production and sandbox environments.
