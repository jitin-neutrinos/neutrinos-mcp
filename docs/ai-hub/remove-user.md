# Remove User

<https://documentation.neutrinos.com/articles/#!ai-hub/remove-user>

To remove a user, follow the steps below:

1. Use the left navigation panel to navigate to the Users page.
    ![ai-hub-users-landing-page](/resources/Storage/ai-hub/images/ai-hub-users-landing-page.png)
2. Navigate to the specific user whose profile or access permissions need to be modified.
    ![ai-hub-users-add-user-navigate-to-record](/resources/Storage/ai-hub/images/ai-hub-users-add-user-navigate-to-record.png)
3. In the Actions column, click the kebab icon for the required user record, and then select Edit from the list of available options.
    ![ai-hub-users-add-user-action-remove-user](/resources/Storage/ai-hub/images/ai-hub-users-add-user-action-remove-user.png)
4. In the pop-up window, enter the username exactly as provided during the user’s onboarding.
    ![ai-hub-users-add-user-action-remove-user-name](/resources/Storage/ai-hub/images/ai-hub-users-add-user-action-remove-user-name.png)
5. Click the Remove button to remove the user from the platform.
    ![ai-hub-users-add-user-action-remove-user-remove-button](/resources/Storage/ai-hub/images/ai-hub-users-add-user-action-remove-user-remove-button.png)
6. Once the user is removed, a 'User removed successfully' message is displayed.
