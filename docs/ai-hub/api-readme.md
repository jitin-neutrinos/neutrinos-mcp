# Example

<https://documentation.neutrinos.com/articles/#!ai-hub/api-readme>

## Example

```code
import { InferenceSDK } from 'idp-inference-sdk';

const sdk = new InferenceSDK({
  endpoint: 'https://api.aihub.com',
  timeout: 60000,
  trace_oltp_endpoint: 'https://trace.aihub.com',
  log_oltp_endpoint: 'https://log.aihub.com',
});

const result = await sdk.classification.text.predict({ input: { text: 'Example' } });
```
