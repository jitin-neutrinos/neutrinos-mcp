### ping()

> **ping**(): `Promise`<{ `status`: `string`; }>

Defined in: [sdk-client.ts:200](https://bitbucket.org/bhivedevs/idp-inference-sdk/src/master/src/sdk-client.ts#lines-200)

Sends a simple health-check request to verify that the API is reachable and responsive.

This is often used in CI/CD or startup environments to validate SDK connectivity.

#### Returns

`Promise`<{ `status`: `string`; }>

A promise resolving to a status object like `{ status: 'ok' }`.

#### Throws

If the API is unreachable or returns an error.

#### Example

```code
const status = await sdk.ping();
console.log(status); // { status: 'ok' }
```
