# Edit Connectors

<https://documentation.neutrinos.com/articles/#!ai-hub/edit-connectors>

To edit a connector configured on the platform, follow these steps:

1. Navigate to the Connectors page from the left navigation panel.
2. On the Connectors page, locate the connector that you want to edit or update. Click the specific connector.
3. The connector details are displayed based on the most recent configuration. Modify or update the connector as required.
    ![ai-hub-connectors-edit-connectors](/resources/Storage/ai-hub/images/ai-hub-connectors-edit-connectors.png)
4. After editing or updating the connector configuration, click Test Connection at the bottom of the page to validate the connector functionality. Once the validation is successful, click Update to save the updated configuration.
    ![ai-hub-connectors-update-connectors](/resources/Storage/ai-hub/images/ai-hub-connectors-update-connectors.png)

**Note**: When editing an API connector, you can also modify static values such as Params, Headers, and Body that are sent during the API call. After updating and verifying these values, click Update to save the changes.
