# Review Hub - Document Extraction Model

<https://documentation.neutrinos.com/articles/#!ai-hub/review-hub-document-extraction-model>

Human intervention is essential for reviewing user queries submitted to the trained model, as it helps monitor and improve the model’s performance. Feedback provided through the Review Hub contributes to enhancing the model's accuracy and effectiveness over time.

The information in the review hub is classified into five tabs: Pending, Verified, Skipped, Ignored, and Audit History. Each tab contains columns containing Document, Status, Entities, Update Date and Time, Reason for Tagging, and Action.



![ai-hub-extraction-document-review-hub-landing-page](/resources/Storage/ai-hub/images/ai-hub-extraction-document-review-hub-landing-page.png)

- **Pending**: Displays a list of model-generated extractions that are pending review.
- **Verified**: Displays a list of reviews verified through human intervention.
- **Skipped**: Displays a list of skipped reviews during the review process.
- **Ignored**: Displays a list of reviews that were excluded from the review process.
- **Audit History**: Displays the complete audit trail of the entire review process, including all entries from every tab — from Pending to Ignored.

The contents of each of the above-mentioned tabs are organized into columns with the following headings:

- **Document**: Lists all inputs provided to the extraction model for data extraction.
- **Status**: Lists the status of each extraction as categorized under the respective tabs. For example, Validation Pending under the Pending tab, Validated under Verified, Skipped under Skipped, and Not Considered under Ignored.
- **Entities**: Lists the sections specified in the document for extraction.
- **Updated Date and Time**: Displays the date and timestamp when the input was submitted to the model for extraction.
- **Reason for Tagging**: Lists the reason why a particular input is listed for review in the Review Hub. User input test documents are pooled for review if the configuration is set to Always under the Feedback Look configuration. This setting can be modified anytime under the Rules tab.
- **Actions**: The kebab menu under the Action column allows you to delete a specific review from the Review Hub.

To review the responses generated by the model in the Review Hub, follow the steps below:

1. From the Extraction page, navigate to the Document tab, click the required model, then select the version to review its responses. In the left panel, click Review Hub to open the page displaying all reviews categorized as Pending, Confirmed, Skipped, or Ignored, as illustrated in the GIF below:
   ![ai-hub-extraction-document-review-hub-navigate](/resources/Storage/ai-hub/images/ai-hub-extraction-document-review-hub-navigate.gif)
2. Click the input from the Document column to open the review page for the specific input as illustrated in the GIF below:
   ![ai-hub-extraction-document-review-hub-open-case](/resources/Storage/ai-hub/images/ai-hub-extraction-document-review-hub-open-case.gif)
3. Click the Confirm, Ignore, or Skip button as needed for a specific input to complete its review process:
   ![ai-hub-extraction-document-review-hub-confirm-click](/resources/Storage/ai-hub/images/ai-hub-extraction-document-review-hub-confirm-click.gif)
4. Once a review is submitted for an input document, it is classified under the Verified, Skipped, or Ignored tab based on the action taken.
