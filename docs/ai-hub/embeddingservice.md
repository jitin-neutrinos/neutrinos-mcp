# Class: EmbeddingService

Defined in: [services/assistant/embedding/embedding.service.ts:57](https://bitbucket.org/bhivedevs/idp-inference-sdk/src/master/src/services/assistant/embedding/embedding.service.ts#lines-57)

Provides APIs for embedding operations such as result listing, adding, updating, deleting, and deleting all embeddings.

The service handles knowledge source embedding workflows including:

- List embeddings for a knowledge source.
- Add embeddings for a knowledge source.
- Update embeddings for a knowledge source.
- Delete embeddings for a knowledge source.
- Delete all embeddings for a knowledge source.
