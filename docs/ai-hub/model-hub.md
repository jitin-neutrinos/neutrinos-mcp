# Model Hub

<https://documentation.neutrinos.com/articles/#!ai-hub/model-hub>

The Model Hub is a marketplace that provides multiple pre-built models that can be directly implemented. You can import any pre-built model available model from the Model Hub it into your tenant from the Model Hub.

![ai-hub-model-hub-landing-page](/resources/Storage/ai-hub/images/ai-hub-model-hub-landing-page1.png)


 The landing page of the model hub contains the following:

1. **Search Bar**: You can search for a model using the search bar. Additionally, you can apply pre-defined filters such as Prediction, Extraction, or Assistant to quickly narrow down the results. You can also search based on specific use cases such as Underwriting, Claims, Statements, Rules, Policy, and more.
2. **Model Types**: This section classifies the available models into three major categories — Extraction, Prediction, and Assistant.
3. **Suggested Models**: This section lists the available models based on use case types such as Invoice Agent, KTP, Prediction Document, and more. A See More button is available at the top right of the section, allowing you to browse all models in the Model Hub.
4. **Recently Added**: This section lists all models that were recently added to the platform.
5. **Most Used**: This section lists the models that are most frequently imported by users.
6. **Browse by Category**: This section organizes the available models into categories such as Underwriting, Claims, Statements, Rules, Policy, and more.

To use or import a pre-built model into your tenant, follow these steps:

1. In the left navigation panel, click Model Hub to open the Model Hub page.
    ![ai-hub-model-hub-landing-page](/resources/Storage/ai-hub/images/ai-hub-model-hub-landing-page.png)
2. Choose from the available models classified under different sections based on your requirements. For example, in this case, we have selected an Assistant Model from the Model Hub.
    ![ai-hub-model-hub-exttraction-example](/resources/Storage/ai-hub/images/ai-hub-model-hub-exttraction-example1.png)
3. Open the required model. The model page displays a brief description of the model and provides the option to add it to your tenant by selecting the required version.
    ![ai-hub-model-hub-model-selection](/resources/Storage/ai-hub/images/ai-hub-model-hub-model-selection1.png)
  - To add the model to your favourites, click the heart icon.
  - To copy the model link, click the pin icon.
4. Once the model is added, it appears in the respective category. For example, if you add an Assistant model from the Model Hub, it will be listed under Assistant models in your tenant.
    ![ai-hub-model-hub-adding-process](/resources/Storage/ai-hub/images/ai-hub-model-hub-adding-process1.gif)

| ![Note](/resources/Storage/ai-hub/project-trailproject/note.png) | Note: When you add models from the Model Hub, no training data or model-related data is shared. |
