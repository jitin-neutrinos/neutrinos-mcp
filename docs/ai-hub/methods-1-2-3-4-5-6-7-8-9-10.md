### modelList()

> **modelList**(`input`): `Promise`<[`IModelListResponse`](../interfaces/IModelListResponse.md)>

Defined in: [services/model-catalog/model-catalog.service.ts:123](https://bitbucket.org/bhivedevs/idp-inference-sdk/src/master/src/services/model-catalog/model-catalog.service.ts#lines-123)

Retrieves a list of models with pagination and sort options.

This method fetches a paginated list of models based on the provided criteria,
 such as training type, data type, and pagination parameters.

#### Parameters

##### input

[`IModelListDto`](../interfaces/IModelListDto.md)

The DTO containing pagination and sort options.

#### Returns

`Promise`<[`IModelListResponse`](../interfaces/IModelListResponse.md)>

A promise that resolves with a list of models.

#### Example

```code
const models = await modelCatalogService.modelList({
  token: '123',
  training_type: 'Classification',
  data_type: 'Text',
  page_number: 0,
  page_size: 10,
  sort: 'desc'
});
console.log(models); // Logs an array of model metadata
```
