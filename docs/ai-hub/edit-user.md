# Modify Access at Individual Level

<https://documentation.neutrinos.com/articles/#!ai-hub/edit-user>

To edit an existing user and update their access permissions, follow the steps below:

1. Use the left navigation panel to navigate to the Users page.
    ![ai-hub-users-landing-page](/resources/Storage/ai-hub/images/ai-hub-users-landing-page.png)
2. Navigate to the specific user whose profile or access permissions need to be modified.
    ![ai-hub-users-add-user-navigate-to-record](/resources/Storage/ai-hub/images/ai-hub-users-add-user-navigate-to-record.png)
3. In the Actions column, click the kebab icon for the required user record, and then select Edit from the list of available options.
    ![ai-hub-users-add-user-edit-option](/resources/Storage/ai-hub/images/ai-hub-users-add-user-edit-option.png)
4. In the pop-up screen, all permissions and roles currently assigned to the user are displayed.
    ![ai-hub-users-add-user-edit-option-existing-permission](/resources/Storage/ai-hub/images/ai-hub-users-add-user-edit-option-existing-permission.png)
5. Access permissions can be updated in two ways:
  - By modifying the roles assigned to the user: Access permissions are automatically updated based on the roles selected from the Roles dropdown.
      ![ai-hub-users-add-user-edit-option-existing-permission-modify1](/resources/Storage/ai-hub/images/ai-hub-users-add-user-edit-option-existing-permission-modify1.png)
  - By granting or revoking permissions at an individual component level using the Modify Access button on the screen.
      ![ai-hub-users-add-user-edit-option-existing-permission-modify2](/resources/Storage/ai-hub/images/ai-hub-users-add-user-edit-option-existing-permission-modify2.png)

## Modify Access at Individual Level

This feature allows modification of user access permissions at an individual component level while retaining the roles initially assigned to the user. Perform the following steps to modify access at the individual component level:

1. On the Users page, click the kebab icon for the required user and select Edit. In the pop-up screen, click the Modify Access button.
    ![ai-hub-users-add-user-edit-option-existing-permission-individual](/resources/Storage/ai-hub/images/ai-hub-users-add-user-edit-option-existing-permission-individual.png)
2. In the Manage Access pop-up screen, all platform components with configurable access permissions are listed. Use the toggle corresponding to each component to enable or disable permissions for that component.
3. The last column displays the permissions enabled for each component based on the user’s assigned role. You can modify these permissions individually by clicking the arrow icon next to each permission.
    The types of permissions available - such as View, Train, Create, Delete, Deploy, and Undeploy - vary by component type.
    ![ai-hub-users-add-user-edit-option-permission-individual-toggle](/resources/Storage/ai-hub/images/ai-hub-users-add-user-edit-option-permission-individual-toggle.png)
    Additionally, the arrow icon allows you to enable or disable multiple permissions for a component that supports multiple operations. Select the checkboxes corresponding to the operations that the user must be granted permission for, and deselect the checkboxes for operations that should not be permitted for the user.
    ![ai-hub-users-add-user-edit-option-permission-individual-checkbox](/resources/Storage/ai-hub/images/ai-hub-users-add-user-edit-option-permission-individual-checkbox.png)
4. After the access permissions are updated, the changes are saved automatically, and the system displays a confirmation message.
5. Click the back arrow icon at the top of the screen to navigate to the Edit User screen. Click Save at the bottom of the screen to confirm and apply the updated permission changes.

Alternatively, you can directly access the Manage Access page by clicking the kebab icon in the Actions column for a specific user and selecting Manage Access from the available options.



![ai-hub-users-add-user-edit-option-navigate-manage-access](/resources/Storage/ai-hub/images/ai-hub-users-add-user-edit-option-navigate-manage-access.png)
