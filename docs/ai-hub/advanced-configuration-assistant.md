## Advanced Option

To configure advanced settings, use the Advanced Options section.




 ![assistant-advanced-option-landing-page](/resources/Storage/ai-hub/images/assistant-advanced-option-landing-option1.png)

You can:

- Set a public name for the Assistant.
    ![assistant-advanced-option-assistant-name](/resources/Storage/ai-hub/images/assistant-advanced-option-assistant-name1.png)
- Define the placeholder text for the user input field.
    ![assistant-advanced-option-placeholder-text](/resources/Storage/ai-hub/images/assistant-advanced-option-placeholder-text1.png)
- Allowed Domains: Define the permissible domains from which the assistant is used. This can be an external web application. This setting establishes boundaries for the Assistant to ensure it retrieves data only from the specified domains.
    ![assistant-advanced-option-allowed-domain](/resources/Storage/ai-hub/images/assistant-advanced-option-allowed-domain1.png)
- Translate Language: Select this checkbox to enable automatic translation of the uploaded document's content. The document will be translated into the language selected from the dropdown list of available languages.
    ![assistant-advanced-option-translation](/resources/Storage/ai-hub/images/assistant-advanced-option-translation.png)
    From the dropdown list, select the target language into which the content should be translated, as shown in the image below.
    ![assistant-advanced-option-translation-dorpdown](/resources/Storage/ai-hub/images/assistant-advanced-option-translation1.png)

- Specify the percentage of creative freedom the Assistant can use when responding to general queries.
    ![assistant-advanced-option-creativity-quotient](/resources/Storage/ai-hub/images/assistant-advanced-option-creativity-quotient1.png)
- Enable PII Masking: Privacy of personal or organizational data is crucial when uploading documents to a Large Language Model (LLM) for extraction or interpretation. In Neutrinos AI Hub, data privacy is prioritized. When the Enable PII Masking option is selected, personal and organizational data is masked before being sent to the LLM. When PII Masking is enabled, by default, information such as names, organization names, email addresses, and similar personally identifiable information (PII) is masked.
    ![ai-hub-assistant-advanced-enable-pii-masking](/resources/Storage/ai-hub/images/ai-hub-assistant-advanced-enable-pii-masking1.png)
    Additionally, select the Data Dictionary and Default Masking values by specifying the locale. Based on the selected language (locale), the masking values are chosen from the dictionary to ensure that the generated masked data appears more regional and contextually appropriate. You can also define a custom list of terms to be masked by specifying the following:
  - Name – Identifier for the masking rule.
  - Regex Expression – Pattern used to detect the sensitive data.
  - Threshold Value – The confidence level required for masking to be applied.
  - Action – This column allows you to Test and Save the regex expression for masking PII values. You can verify whether the regex expression works as expected and then save it for future use. Additionally, you can delete an entry by clicking the Delete icon at the end of the corresponding row.
      ![ai-hub-assistant-pii-masking-gif](/resources/Storage/ai-hub/images/ai-hub-assistant-pii-masking-gif.gif)
- Enable Form Field Detection: When this option is selected, the Assistant detects form fields such as checkboxes, labels, text inputs, and similar elements, and treats them as value fields. If this option is not selected, these fields are recognized as part of the OCR text. By default, this checkbox is not selected.
    ![ai-hub-assistant-advanced-enable-form-field-detection](/resources/Storage/ai-hub/images/ai-hub-assistant-advanced-enable-form-field-detection.png)
- Set a custom discourse message: To set a custom discourse message, first enable the toggle in this section, then enter the message you want to display to the user. By default, the message is: "This is an automated chatbot response."
    ![assistant-advanced-option-display-discourse-message](/resources/Storage/ai-hub/images/assistant-advanced-option-display-discourse-message1.png)
- Remove data from the database: You can configure the data retention period to specify how long data is stored on the servers. Choose from predefined options—1 day, 5 days, 15 days, 25 days, or 30 days—or use the available slider to set a custom retention period between 1 and 30 days, based on your requirements. For more information, refer [Data Privacy and Retention](/articles/ai-hub/data-privacy-and-retention) topic.
    ![assistant-advanced-option-remove-data-after](/resources/Storage/ai-hub/images/assistant-advanced-option-remove-data-after111.png)

## Link Custom Model

The custom model configured on the platform can be linked to an assistant after the configuration is completed successfully. Follow the steps below:

1. Navigate to the Assistants page from the left navigation panel on the platform.
2. Select the required Assistant. Then, from the Versions tab in the Assistants navigation panel, click the specific assistant version to which the custom model must be linked.
3. Navigate to the Advanced tab in the Assistants navigation panel. Scroll to the bottom of the Advanced Options page and locate the Apply Image Processing section.
    ![ai-hub-custom-model-integrate-advanced-tab-section](/resources/Storage/ai-hub/images/ai-hub-custom-model-integrate-advanced-tab-section.png)
4. In this section, click the Chat Model dropdown and search for the custom model previously configured on the platform. Use the search bar within the dropdown to quickly locate and select the custom model. In this example, the OpenAI Try model configured earlier in this topic is selected.
    ![ai-hub-custom-model-integrate-advanced-tab-section-chat-model](/resources/Storage/ai-hub/images/ai-hub-custom-model-integrate-advanced-tab-section-chat-model.png)
5. After selecting the required custom model from the list, click Save and Publish at the bottom of the screen. This enables the assistant to process user queries using the selected chat model configured through the custom model.
   ![ai-hub-custom-model-integrate-advanced-tab-chat-model-save-publish](/resources/Storage/ai-hub/images/ai-hub-custom-model-integrate-advanced-tab-chat-model-save-publish.png)
