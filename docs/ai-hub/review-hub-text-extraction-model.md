# Review Process

<https://documentation.neutrinos.com/articles/#!ai-hub/review-hub-text-extraction-model>

Human intervention is essential for reviewing user queries submitted to the trained model, as it helps monitor and improve the model’s performance. Feedback provided through the Review Hub contributes to enhancing the model's accuracy and effectiveness over time.

The information in the review hub is presented in five tabs: Pending, Verified, Skipped, Ignored, and Audit History. Each tab contains columns containing Text, Entity, Update Date and Time, Reason for Tagging, and Action.



![ai-hub-extraction-te-review-hub-landing-page](/resources/Storage/ai-hub/images/ai-hub-extraction-te-review-hub-landing-page.png)

- **Pending**: Displays a list of model-generated extractions that are awaiting review.
- **Verified**: Displays a list of reviews verified through human intervention.
- **Skipped**: Displays a list of skipped reviews during the review process.
- **Ignored**: Displays a list of reviews that were excluded from the review process.
- **Audit History**: Displays the complete audit trail of the entire review process, including all entries from every tab — from Pending to Ignored.

The contents of each of the above-mentioned tabs are organized into columns with the following headings:

- **Text**: Lists all inputs submitted to the extraction model for information extraction.
- **Entity**: Lists the category assigned by the model after extracting information from the provided input.
- **Updated Date and Time**: Lists the date and time when the input was submitted to the model for extraction.
- **Reason for Tagging**: Lists the reason why a particular input is listed for review in the Review Hub. User inputs are pooled for review if the configuration is set to Always under the Feedback Look configuration. This setting can be modified anytime under the Rules tab.
- **Actions**: The kebab menu under the Action column allows you to delete a specific review from the Review Hub.

## Review Process

To review the responses generated by the model in the Review Hub, follow the steps below:

1. On the Extraction page, click the desired model, then select the version to review its responses. In the left panel, click Review Hub to open a page displaying all reviews, categorized as Pending, Confirmed, Skipped, or Ignored, as shown in the GIF below.
   ![ai-hub-extraction-text-review-hub-navigate](/resources/Storage/ai-hub/images/ai-hub-extraction-text-review-hub-navigate.gif)
2. Click the input from the Text column to open the review page for the specific input as illustrated in the GIF below:
   ![ai-hub-extraction-text-review-hub-review-confirm](/resources/Storage/ai-hub/images/ai-hub-extraction-text-review-hub-review-confirm.gif)
3. Click the Confirm, Ignore, or Skip button as needed for a specific input to complete its review process.
   ![ai-hub-extraction-text-review-hub-confirm-from-pending](/resources/Storage/ai-hub/images/ai-hub-extraction-text-review-hub-confirm-from-pending.gif)
4. Once a review is submitted for an input item, it is classified under the Verified, Skipped, or Ignored tab based on the action taken.
