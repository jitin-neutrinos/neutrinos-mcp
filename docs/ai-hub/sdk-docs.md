# SDK Docs

<https://documentation.neutrinos.com/articles/#!ai-hub/sdk-docs>

The AI Hub SDK provides developers with a unified, streamlined way to integrate AI Hub’s capabilities directly into their applications. It provides APIs, libraries, and utilities that simplify interaction with AI models, resource management, and the orchestration of AI-driven workflows.

This documentation outlines the SDK’s structure, setup instructions, usage patterns, and best practices to help you get started quickly and build robust AI-powered solutions.
