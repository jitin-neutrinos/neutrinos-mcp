# Add User

<https://documentation.neutrinos.com/articles/#!ai-hub/add-user>

To add a user to the platform, follow the steps below:

1. Use the left navigation panel to navigate to the Users page.
    ![ai-hub-users-landing-page](/resources/Storage/ai-hub/images/ai-hub-users-landing-page.png)
2. On the Users page, click **Add** in the top-right corner to create a new user.
    ![ai-hub-users-add-user-button](/resources/Storage/ai-hub/images/ai-hub-users-add-user-button.png)
3. In the pop-up window, provide the required user details, including Full Name and Email, and assign an appropriate role by selecting it from the Roles dropdown.
    ![ai-hub-users-add-user-pop-up](/resources/Storage/ai-hub/images/ai-hub-users-add-user-pop-up.png)
4. After entering the required details, click the Save button at the bottom of the screen to add the user to the platform.
    ![ai-hub-users-add-user-pop-up-save-button](/resources/Storage/ai-hub/images/ai-hub-users-add-user-pop-up-save-button.png)

| ![Note](/resources/Storage/ai-hub/project-trailproject/note.png) | Note: Only users with permission can add new users to the platform. If a user lacks the necessary permissions, the system displays an authorization error and a "Create User Failed" message. |
| --- | --- |
