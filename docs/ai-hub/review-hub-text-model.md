# Review Hub - Text Model

<https://documentation.neutrinos.com/articles/#!ai-hub/review-hub-text-model>

Human intervention is essential for reviewing predictions made by the trained model, as it helps monitor and improve the model’s performance. Feedback provided through the Review Hub contributes to enhancing the model's accuracy and effectiveness over time.

| ![Note](/resources/Storage/ai-hub/project-trailproject/note.png) | Note: Human review (human-in-the-loop) is applicable only when the configured rule is set to "Always" or when the model's confidence score falls below the defined threshold. If the rule is set to "Never", predictions made do not involve any review. |
| --- | --- |

The information in the review hub is classified into five tabs: Pending, Verified, Skipped, Ignored, and Audit History. Each tab contains columns containing Item names, Status, Category, Update Date and Time, Reason for Tagging, and Action.




 ![ai-hub-prediction-text-review-hub-landing](/resources/Storage/ai-hub/images/ai-hub-prediction-text-review-hub-landing.png)

- **Pending**: Displays a list of model-generated predictions that are pending review.
- **Verified**: Displays a list of reviews verified through human intervention.
- **Skipped**: Displays a list of skipped reviews during the review process.
- **Ignored**: Displays a list of reviews that were excluded from the review process.
- **Audit History**: Displays the complete audit trail of the entire review process, including all entries from every tab — from Pending to Ignored.

The contents of each of the above-mentioned tabs are organized into columns with the following headings:

- **Items**: Lists all inputs provided to the prediction model for generating the prediction.
- **Status**: Lists the status of each prediction as categorized under the respective tabs. For example, Validation Pending under the Pending tab, Validated under Verified, Skipped under Skipped, and Not Considered under Ignored.
- **Category**: Lists the category assigned by the model based on the input provided for prediction.
- **Updated Date and Time**: Lists the date and timestamp when the input was provided to the model for prediction.
- **Reason for Tagging**: Lists the reason why a particular input is listed for review in the Review Hub. User inputs are pooled for review if the configuration is set to Always under the Feedback Look configuration. This setting can be modified anytime under the Rules tab.
- **Actions**: The kebab menu under the Action column allows you to delete a specific review from the Review Hub.

To review the responses generated by the model in the Review Hub, follow the steps below:

1. From the Prediction page, click the required model, then select the version to review its responses. In the left panel, click Review Hub to open the page displaying all reviews categorized as Pending, Confirmed, Skipped, or Ignored, as illustrated in the GIF below:
    ![ai-hub-prediction-text-navigate-review-hub](/resources/Storage/ai-hub/images/ai-hub-prediction-text-navigate-review-hub.gif)
2. Click the input from the Items column to open the review page for the specific input as illustrated in the GIF below:
    ![ai-hub-prediction-text-review-hub-navigate](/resources/Storage/ai-hub/images/ai-hub-prediction-text-review-hub-navigate.gif)
3. Click the Confirm, Ignore, or Skip button as needed for a specific input to complete its review process.
    ![ai-hub-prediction-text-review-hub](/resources/Storage/ai-hub/images/ai-hub-prediction-text-review-hub.gif)
4. Once a review is submitted for an input item, it is classified under the Verified, Skipped, or Ignored tab based on the action taken.
