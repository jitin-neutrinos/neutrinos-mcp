# Delete Connectors

<https://documentation.neutrinos.com/articles/#!ai-hub/delete-connectors>

To delete a connector configured on the platform, follow the below steps:

1. Navigate to the Connectors page from the left navigation panel.
2. The Connectors page displays all configured connectors in a tabular format.
3. Locate the connector that you want to delete from the list. Under the Actions column, click the kebab icon, and then select Delete.
