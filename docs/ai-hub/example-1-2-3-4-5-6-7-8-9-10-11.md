## Example

```code
const sdk = new InferenceSDK(config);

const batch = await sdk.extraction.text.createBatch({
  token: '1234567890abcdef',
  callback_url: 'https://example.com/webhook',
  is_file: true,
  metadata: {
    source: 'transcripts',
    user: 'analyst-002'
  }
});

console.log('Batch created:', batch._id);
```
