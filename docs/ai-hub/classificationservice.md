# Class: ClassificationService

Defined in: [services/classification/classification.service.ts:93](https://bitbucket.org/bhivedevs/idp-inference-sdk/src/master/src/services/classification/classification.service.ts#lines-93)

Provides APIs for classification operations such as batch processing,
 result listing, feedback submission, and downloading outputs.

This service handles document classification workflows including:

- Uploading documents to batches
- Starting batch classification jobs
- Fetching batch and result metadata
- Submitting manual feedback
- Downloading test data and results
