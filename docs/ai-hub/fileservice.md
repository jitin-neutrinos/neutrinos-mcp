# Class: FileService

Defined in: [services/file/file.service.ts:75](https://bitbucket.org/bhivedevs/idp-inference-sdk/src/master/src/services/file/file.service.ts#lines-75)

Provides APIs for managing file uploads, listings, downloads, and deletions.

`FileService` acts as the main interface for file operations within the SDK.
 All files must be provided via local file paths and are transmitted as `multipart/form-data`.
