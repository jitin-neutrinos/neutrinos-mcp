# Validate Assistant

<https://documentation.neutrinos.com/articles/#!ai-hub/validate-assistant>

Every assistant created on the platform must be tested for accuracy to ensure the validity and reliability of its responses. This is a critical phase in the model lifecycle and can be performed using the Test Version option available on the platform. Follow the steps below to validate the assistant:

1. Navigate to the Assistant page using the left navigation panel. Select the desired assistant model from the list of available (created) assistants on the platform. Then, open the specific version of the model from the Versions page.
2. In the Dashboard page, click the Test Version button located at the top right corner. This opens the assistant in test mode, allowing you to validate whether it functions as expected based on the instructions provided.
    ![ai-hub-assistant-test-version](/resources/Storage/ai-hub/images/ai-hub-assistant-test-version.png)
3. In the assistant pop-up, upload an invoice document and click the upward arrow next to the conversation box to submit. Verify whether the assistant generates a response that aligns with the instructions configured during its creation. The working sample of the assistant is demonstrated in the GIF below:
    ![ai-hub-assistant-extract-invoice-details](/resources/Storage/ai-hub/images/ai-hub-assistant-extract-invoice-details.gif)
