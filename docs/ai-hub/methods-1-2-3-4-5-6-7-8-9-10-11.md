### insertToBatch()

> **insertToBatch**(`payload`): `Promise`<[`ITextExtractionInsertToBatchResponse`](../interfaces/ITextExtractionInsertToBatchResponse.md)[]>

Defined in: [services/extraction/text/extraction-text.service.ts:253](https://bitbucket.org/bhivedevs/idp-inference-sdk/src/master/src/services/extraction/text/extraction-text.service.ts#lines-253)

Inserts a batch of structured text inputs into a text NER batch.

Each input must contain a `text` field. Optionally, a `ground_truth` object can be provided.

#### Parameters

##### payload

[`ITextExtractionInsertToBatchDto`](../interfaces/ITextExtractionInsertToBatchDto.md)

Contains the batch ID and array of text input entries.

#### Returns

`Promise`<[`ITextExtractionInsertToBatchResponse`](../interfaces/ITextExtractionInsertToBatchResponse.md)[]>

A list of inserted input records with metadata.

#### Example

```code
await sdk.extraction.text.insertToBatch({
  token: '1234567890abcdef',
  batch_id: '64f123abc456def789012345',
  input: [
      {
          text: 'The shipping was delayed by 3 days.',
          ground_truth: {
              "Policy Type": [
                  {
                      label: 'delay_reason',
                      start: 4,
                      end: 28,
                  }
              ]
          },
      },
      {
          text: 'Please contact customer support.',
      },
  ],
});
```

### downloadData()

> **downloadData**(`input`): `Promise`<`Readable`>

Defined in: [services/extraction/text/extraction-text.service.ts:598](https://bitbucket.org/bhivedevs/idp-inference-sdk/src/master/src/services/extraction/text/extraction-text.service.ts#lines-598)

Downloads test data file for a text extraction batch that was created using file upload.

This method is only applicable to batches where `is_file: true` was set during creation,
 and files were uploaded using the `uploadDocumentToBatch` method.

#### Parameters

##### input

[`IExtractionTextTestDownloadDto`](../interfaces/IExtractionTextTestDownloadDto.md)

Object containing `test_id` of the uploaded document to download.

#### Returns

`Promise`<`Readable`>

Stream of the file content.

#### Example

```code
const response = await sdk.extraction.text.downloadData({
  token: '1234567890abcdef',
  test_id: '64b8f5f9c9f0a40abc123456'
});
response.pipe(fs.createWriteStream('input.csv'));
console.log('Downloaded file:', 'input.csv');
```

#### Remarks

This method will not work for batches populated using `insertToBatch`, as those are text-based and not file-based.
