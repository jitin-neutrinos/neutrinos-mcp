# Staged Deployment

<https://documentation.neutrinos.com/articles/#!trinity-publication/all-deployments>

The all deployment screen shows how an application is made available to target servers that must be deployed. Trinity provides three different options for deployment:

- Staged Deployment
- Current Deployment
- Previous Deployment

#### Staged Deployment

The staged deployment is an exact replica of your production (live) environment. It is the last step in the deployment process before you deploy your application.

#### Current Deployment

Current deployment refers to the most recent version of an application that has been deployed to production and is currently accessible to users.

#### Previous Deployment

Previous deployment refers to the previous version of an application that was deployed and is accessible by users.
