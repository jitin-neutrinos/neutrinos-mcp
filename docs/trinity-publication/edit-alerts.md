# Edit Alerts

<https://documentation.neutrinos.com/articles/#!trinity-publication/edit-alerts>

To edit any alert, regardless of its type, follow the steps below:

1. Click Alerts from the left navigation panel to open the Alerts page on the Trinity platform. By default, the Application Alerts page is displayed.
    ![trinity-alerts-edit-step](/resources/Storage/trinity-publication/images/trinity-alerts-edit-step11.png)
2. Navigate to the appropriate alert type—Application, Node, or Storage—that contains the specific alert you want to edit.
3. Hover over the configured alert, then click the Edit (pencil) icon next to the Delete icon in the corresponding row.
    ![trinity-alerts-edit-icon](/resources/Storage/trinity-publication/images/trinity-alerts-edit-icon1.png)
4. This opens the alert configuration page. The steps for editing an alert are the same as those for creating one. All previously entered values—regardless of the alert type—are pre-filled in the configuration form. Update the required fields as needed, and complete the steps to save the changes. The image below illustrates editing Application alerts:
    ![trinity-alerts-edit-steps-review](/resources/Storage/trinity-publication/images/trinity-alerts-edit-steps-review.png)
5. Finally, in the Review section, verify that all necessary changes have been made, then click the Update button at the bottom of the screen to complete the update process.
   ![trinity-alerts-edit-review-update](/resources/Storage/trinity-publication/images/trinity-alerts-edit-review-update1.png)
