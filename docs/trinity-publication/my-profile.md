# User Profile

<https://documentation.neutrinos.com/articles/#!trinity-publication/my-profile>

The user profile section located at the top right corner of the screen and serves as a access point for users to manage their personal information and account settings.

![](/resources/Storage/trinity-publication/my-profile/Myprofile.jpg)

The components within the user profile section are provided below.

**User Information**

This section contains the details related to the user and can be edited.

- First and Last Name - Displays the user's first and last name.
- Email ID: Displays the user's email address.

**Show Repo Credential**

The user repository credentials can be viewed by clicking on this section.

**Add Access Token**

The "Add Access Token" option within the user profile screen allows users to generate and manage access tokens for their account. IT Provides a secure way to access the user's account without needing to share the user's primary credentials (username and password).
