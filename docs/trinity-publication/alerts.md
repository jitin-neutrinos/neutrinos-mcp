# Alerts

<https://documentation.neutrinos.com/articles/#!trinity-publication/alerts>

Alerts are mechanisms used to notify users when an application fails to execute as expected or when issues arise with storage systems or nodes. These alerts help timely troubleshooting and resolution and ensure that the application resumes normal operation, nodes, and storage-related issues are addressed efficiently.

Alerts can be configured individually for Applications, Nodes, and Storage, each of which is described in detail in the sections below. By default, when Alerts is selected from the left navigation panel, the Application Alerts page is displayed.
