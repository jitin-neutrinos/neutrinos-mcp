# All Projects

<https://documentation.neutrinos.com/articles/#!trinity-publication/all-projects>

The "All Projects" screen offers a comprehensive view of the status and details of various projects. It is designed to facilitate efficient project management and monitoring, particularly for applications deployed across different environments. Here’s a breakdown of its key components and functionalities:

![](/resources/Storage/trinity-publication/all-projects/allprojs.png)

Field
Description
Search
Allows users to search for specific projects by typing project names.Create Project
Used to initiate the creation of a new project.
Projects
Lists the names of the projects.Linked Environments
Shows the environments associated with each project. These environments are usually different stages of such as deployed or staging.
Total Apps
Indicates the number of deployments within each project.
Created On
Displays the date each project was created, sorted in descending order by default.
Status
Shows the current operational status of the project, such as "Active," which means the project is running and available.
Delete icon
Hover around a specific project to view this icon. Use this to delete a project.Edit icon
Hover around a specific project to view this icon. Use this to delete a project. Use this to edit a project.
