# Logs (App Level)

<https://documentation.neutrinos.com/articles/#!trinity-publication/logs-app-level>

The app level logs will help you identify underperforming response times, unexpected behaviors, and other errors. You can easily diagnose and fix issues by using the app level logs.

To View the logs at the application level:

1. Select a Project > Click on an application.
2. Click on the Logs link.
   ![](/resources/Storage/trinity-publication/logs-app-level/Applogs.png)
   The app logs window is displayed.
   ![](/resources/Storage/trinity-publication/logs-app-level/applog.png)
3. View the logs.
