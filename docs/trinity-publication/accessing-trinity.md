# Logging in with Azure

<https://documentation.neutrinos.com/articles/#!trinity-publication/accessing-trinity>

Accessing the Trinity platform involves several steps, and the process may vary slightly depending on whether you are using the Azure portal or Identity server (IDS).

Here's how you access Trinity:

1. Click on the [Trinity URL](https://trinity-ids.neutrinos.co/interaction/mUzlhJ0r3yhhS5ps9xzZM) link and navigate to the login page.
2. Login using valid credentials.
3. Once logged in, you will be redirected to the All Projects page.

### Logging in with Azure

Pre-requisites:

- The user attempting to access Trinity must be a member of the Azure App Registry.
- User details should be in our database.

Click on the Azure login icon within the Trinity Login page.
The Microsoft login screen is displayed.Enter valid credentials and login.Once logged in, you will be redirected to the All Projects page.
