# Creating a Project

<https://documentation.neutrinos.com/articles/#!trinity-publication/creating-a-project>

A project within Trinity will encompass all the necessary components to bring a specific application to life online.

To create a new project:

1. Navigate to ***All Projects*** > Click on ***Create Projects***.
   ![](/resources/Storage/trinity-publication/creating-an-environment/Createproj.png)
2. The Create Project pop-up screen is displayed.
   ![](/resources/Storage/trinity-publication/creating-an-environment/Select.png)
3. Select the provider as Jenkins or Azure.
   Note: If the provider is selected as azure, enter the azure project id(this can be obtained from the cluster provider).
4. Enter the Project Name and click on Create.
5. Once the project creation is successful, users are directed to the Apps link.
