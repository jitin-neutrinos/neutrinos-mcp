# Versions

<https://documentation.neutrinos.com/articles/#!trinity-publication/versions>

In Trinity each deployment has at least 1 or more versions. It is possible to create multiple versions of a deployment. All versions in a deployment share the same input and output fields, but the base environment, memory allocation and other settings can be different.

To view the version details:

1. Navigate to Applications link within Trinity and click on the required app.
   This displays the app details window.
2. In the left navigation menu, click on the Version link.
   This displays the version screen.
   ![](/resources/Storage/trinity-publication/linked-environments/vers.png)
3. Click on the version name to view the version details.
   The version details screen is displayed.
   ![](/resources/Storage/trinity-publication/linked-environments/vd.png)
4. Click on the ![](/resources/Storage/trinity-publication/versions/enable.png) icon to view the Resource Allocation details.
   ![](/resources/Storage/trinity-publication/linked-environments/undeploy.png)
   **Note**: Clicking on the Undeployed button will undeploy the selected version.
