# Create a new build

<https://documentation.neutrinos.com/articles/#!trinity-publication/create-a-new-build>

If you have created a project using Jenkins, follow the steps given below to create a new build. If your project is created using Azure DevOps, navigate to the [Azure DevOps](/articles/trinity-publication/create-new-build-azure) section.

1. Navigate to the builds section and click on Create build.
   ![](/resources/Storage/trinity-publication/secrets/createnewbuild.png)
   This displays the Create Build pop-up window.
   ![](/resources/Storage/trinity-publication/secrets/Initiatebuild.png)
2. Enter the following details:
   - Select the build type.(In this case select build type as New).
   - Enter the Repository URL.
   - Enter the base URL.
3. Click on Create to complete the build setup.

**Note**: After completing the above mentioned steps, navigate to the [Deploying Applications](/articles/trinity-publication/deploying-applications) section to deploy an application.
