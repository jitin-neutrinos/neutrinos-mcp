# API Application

<https://documentation.neutrinos.com/articles/#!trinity-publication/api-application>

To create an API App:

1. Navigate to Applications link within Trinity and click on New Application.
   The Create Application page is displayed.
   ![](/resources/Storage/trinity-publication/creating-an-environment/APIapp_7.png)
2. Select the Application type as Api.
3. Application Name – Enter a unique name for the App
4. Repository URL – Enter the repository URL.
5. Click Create to create an API App.
   After creating an application, you will be redirected to the Applications screen. For more information, refer to the [Applications screen](/smart/project-trinity/applications-screen) section.
