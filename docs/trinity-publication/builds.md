# Builds

<https://documentation.neutrinos.com/articles/#!trinity-publication/builds>

A build is a packaged and versioned instance of an application that is ready to be deployed. To maintain a clear distinction between builds, trinity provides a unique id to each build, as no two builds of the same application can have the same Build ID.

![](/resources/Storage/trinity-publication/builds/builds.png)

There are two ways a build can be used to deploy applications:

- [Create a new build and deploy](/articles/trinity-publication/create-a-new-build)
- [Use an existing build and deploy](/articles/trinity-publication/use-an-existing-build)
