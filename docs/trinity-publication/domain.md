# Domain

<https://documentation.neutrinos.com/articles/#!trinity-publication/domain>

To Create a Domain:

1. Navigate to All Projects > Select a Project.
2. Click on Domains > New Domain.
   ![](/resources/Storage/trinity-publication/secrets/Domain_10.png)
   This displays the Create Domain pop-up window.
   ![](/resources/Storage/trinity-publication/secrets/Domain_mapping.png)
3. Enter the domain label and URL.
4. Select the domain type as New or Secret mapping.
5. For New Domain configure your environment and :
   - Upload a .crt or .pem file
   - Upload a .key file
   Or
6. Select Secret mapping and:
   - Select the appropriate environment and key from the drop-down list. The values defined at the cluster level will be displayed.
7. Click create to create a domain.
