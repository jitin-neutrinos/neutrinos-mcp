# Storage (Project level)

<https://documentation.neutrinos.com/articles/#!trinity-publication/storage>

To create a project level Storage:

1. Navigate to All Projects > Select a Project.
2. Click on the Storage link.
   This displays the ***Storage list*** screen.
   ![](/resources/Storage/trinity-publication/storage/Proj-new.jpg)
3. Click on ***Create Storage*** and enter the following details:
   - Name for the storage.
   - Select type of storage from the drop-down list.
   - Storage Path.
   - Select pvc from the drop-down list.
4. Click ***Create*** to set up a project storage.
