# Secrets (Project level)

<https://documentation.neutrinos.com/articles/#!trinity-publication/secrets>

Secrets are critical components in the operation of many applications and services, containing sensitive information necessary for authentication, authorization, and secure communication. The All Secrets screen displays the list of secrets created for a project.

![](/resources/Storage/trinity-publication/secrets/Secretslist.png)

**Note: **Hovering on a secret will provide you an option to edit/delete a secret.

To Create a Secret:

1. Navigate to All Projects > Select a Project.
2. Click on Secrets > Create Secret.
   ![](/resources/Storage/trinity-publication/settings/secretslist.png)
   This displays the Create Secret pop-up window.
   ![](/resources/Storage/trinity-publication/settings/createsecret-new.png)
3. Enter the following details:
   - Enter a label and description.
   - Select if it is a New Secret type or Secret Mapping.
   - For New Secret –Enter the Key and Value.
4. Click **Create** to create a secret.
