# Linked Environments

<https://documentation.neutrinos.com/articles/#!trinity-publication/linked-environments>

To Link an environment:

1. Navigate to All Projects > Select a Project.
2. Click on Linked Environments > Link New Environment.
   **Note: **Hovering on an existing linked environment will display the unlink icon. Use this icon to unlink an environment.
   ![](/resources/Storage/trinity-publication/linked-environments/azunlink.jpg)
   This displays the Link New Environment pop-up window.
   ![](/resources/Storage/trinity-publication/secrets/Linknew.png)
3. Click on the checkbox corresponding to a specific environment to select the environment you wish to link.
4. Click on the Link button to link the environment.
