# Storage (App level)

<https://documentation.neutrinos.com/articles/#!trinity-publication/storagel>

To create an app Storage:

1. Navigate to Applications link within Trinity and click on the required app.
2. Click on Storage link > Storage list screen > Create Storage.
   ![](/resources/Storage/trinity-publication/storagel/AppStorage1.png)
   The create storage pop-up window is displayed.
   ![](/resources/Storage/trinity-publication/storagel/storagel-2024-01-31.png)
3. Enter the following details:
   - Name for the storage.
   - Select Class Details from the drop-down list.
   - Storage Path.
4. Enter description.
5. Click on Create to add the details.
   Or
   Click on Cancel to clear the entered details.
