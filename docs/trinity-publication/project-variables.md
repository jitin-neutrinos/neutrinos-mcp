# Project Variables

<https://documentation.neutrinos.com/articles/#!trinity-publication/project-variables>

You define project variables as environmental constants when creating a Deployment Profile. These variables allow you to set and modify parameters and credentials without needing to redeploy the project, providing flexibility in managing your project environment.

To create a Project Variable:

1. Navigate to All Projects > Select a Project.
2. Click on the Variables link.
   ![](/resources/Storage/trinity-publication/project-variables/Proj-Vars.png)
   The Variables screen is displayed.
   ![](/resources/Storage/trinity-publication/creating-an-environment/var1.png)
3. Enter the following details:
   - Enter a display name.
   - Enter the value and description.(Select the checkbox to replicate value).
4. Click ![](/resources/Storage/trinity-publication/creating-an-environment/plus.png) to add a project variable.
