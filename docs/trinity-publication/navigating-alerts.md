# Navigating Alerts

<https://documentation.neutrinos.com/articles/#!trinity-publication/navigating-alerts>

The alert navigation interface is intuitively designed and organized into distinct sections, each corresponding to a specific type of alert available on the platform—such as Application, Node, and Storage alerts

This section explains how to navigate and interact with these alerts using the platform interface.




 By default, when a user clicks Alerts from the left navigation pane, the Application Alerts page is displayed. This page lists all alerts that have been triggered based on predefined conditions for specific applications.




 Regardless of the alert type, the interface is divided into two main sections

- Alerts: Displays alert logs on the UI
- Config: Allows users to create and manage alert configurations.

Further, regardless of the alert type, you can hover over an alert on the Config page to edit or delete it. You can also expand any alert to view its detailed configuration as illustrated in the GIF below
