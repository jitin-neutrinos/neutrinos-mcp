# Pods

<https://documentation.neutrinos.com/articles/#!trinity-publication/pods>

Pods within Trinity represent a single instance of a running process in a Kubernetes cluster and can contain one or more containers, such as Docker containers. Pods are essential for deploying and managing applications in a consistent and scalable manner.

![](/resources/Storage/trinity-publication/pods/Pods.jpg)

The pods details screen provides information related to the various pods available within a project.

The field descriptions are provided in the below table:

| Field | Description |
| --- | --- |
| App name | Provides information about the app name. |
| Version | The app version number. |
| Pod Name | Details about the pod name. |
| Status | Provides information about the pod status. |
| Restarts | The number of times the pod has restarted |
| Age | Information related to the number of days pod is running. |
| Logs | Click on the icon to view the log |
| Description | Click on the arrow to view the pod description. |
