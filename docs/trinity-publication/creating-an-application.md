# Creating an Application

<https://documentation.neutrinos.com/articles/#!trinity-publication/creating-an-application>

The Applications List page displays a list of created applications and a link to create a new application.

![](/resources/Storage/trinity-publication/creating-an-environment/Applications_6.png)

Trinity enables you to customize (deployment-related details) and modify the configuration. Two distinct types of applications can be created within Trinity:

- [API Application](/articles/trinity-publication/api-application)
- [UI Application](/articles/trinity-publication/ui-application)
