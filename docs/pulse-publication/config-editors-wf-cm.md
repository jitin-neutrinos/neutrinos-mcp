# Config Editors

<https://documentation.neutrinos.com/articles/#!pulse-publication/config-editors-wf-cm>

The Config Editor in Neutrinos Alpha Workflow Studio allows developers to define, modify, and manage configurations for Workbench components. It provides a UI-based approach to customizing Inboxes, Environment Variable, Headers, Language, Dashboards, Main Menu, and App Config dynamically.

This topic discusses the concepts and how to work with Config Editors in Workflow Studio.
