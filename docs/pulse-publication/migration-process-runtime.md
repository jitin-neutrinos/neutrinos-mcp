# Interface

<https://documentation.neutrinos.com/articles/#!pulse-publication/migration-process-runtime>

Process Migration is a Process Runtime capability that enables processes to be migrated from one deployed version of a process definition to another. It allows organizations to introduce process improvements, bug fixes, or regulatory changes while minimizing disruption to in-flight business processes.

During migration, the Process Runtime transfers the execution context of a process instance - including its process variables, active tasks, and runtime data - to a compatible target process definition version. The migration operation preserves the business transaction while aligning the process instance with the updated workflow model.
