# Add Object

<https://documentation.neutrinos.com/articles/#!pulse-publication/object-details>

The Object Manager serves as the central space for creating, managing, and maintaining reusable business data objects within the tenant or organisation. It provides a consolidated view of all available objects, enabling efficient search, filtering, and management of object definitions. This feature enables users to efficiently view and act on multiple data objects within an interface.

## Add Object

To create a new object on the platform, follow the steps below:

1. On the Object Manager page, click Create at the top of the page.
    ![up-hypha-objects-create-button-object](/resources/Storage/pulse-publication/images/up-hypha-objects-create-button-object.png)
2. In the Create Object dialog box, enter a name for the object, provide a brief description, and select an icon to represent the object.
    ![up-hypha-objects-create-dialog](/resources/Storage/pulse-publication/images/up-hypha-objects-create-dialog.png)
3. Click Create to complete the object creation process. After the object is successfully created, it is displayed on the Object Manager page.
    ![up-hypha-objects-created-object-manager](/resources/Storage/pulse-publication/images/up-hypha-objects-created-object-manager.png)
