# Global Search

<https://documentation.neutrinos.com/articles/#!pulse-publication/global-search>

The Global Search is a platform-wide search capability that enables users to quickly locate and navigate to application resources from a single, centralized interface. Rather than requiring users to manually browse through menus, modules, or navigation hierarchies, Global Search provides an efficient mechanism for discovering modules by entering keywords or partial names.

From within any project, you can access the Global Search bar located at the top of the page. The Global Search lets you search across all modules in the project with a keyword. By default, the search is performed across all available modules. If you know the module in which the required item exists, you can limit the search scope by selecting the appropriate module from the available options. The search returns all matching items based on the specified keyword in the selected module, or, if no module is selected, across all modules in the project.




 ![up-global-search-1](/resources/Storage/pulse-publication/images/up-global-search-1.png)

- **All Modules**: Displays a drop-down list of all the modules available on the platform. By default, the search is performed across all modules. If you know the module in which the required item is located, you can select that module from the list to narrow the search and obtain more relevant results.
    ![up-global-search-2](/resources/Storage/pulse-publication/images/up-global-search-2.png)
- **Search**: A text field used to enter the keyword or phrase for the search operation.
- **Recent Searches**: Displays the most recently searched keywords along with the parent modules to which they belong, allowing you to quickly revisit previous searches.

The search bar supports keyboard navigation. Use the Up and Down Arrow keys to navigate through the search results, press Enter to select a result, and press Esc to close the search. You can also open the search bar using the keyboard shortcut

Cmd + K

on macOS or

Ctrl + K

on Windows.

When you enter a keyword, either in full or in part, the search returns all matching items across the selected scope. If All Modules is selected, the results include matching items from all modules across the platform. Select the required item from the search results to navigate directly to it.
