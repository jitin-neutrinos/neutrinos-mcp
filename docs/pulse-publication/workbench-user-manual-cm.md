# Workbench User Manual

<https://documentation.neutrinos.com/articles/#!pulse-publication/workbench-user-manual-cm>

The **Workbench **in the Neutrinos Alpha Platform is typically a low-code/no-code environment that provides developers with a workspace to build and configure applications efficiently.

This section discusses various concepts related to Workbench Neutrinos Alpha Platform

| **Topic** | **Description** |
| --- | --- |
| [Inbox](/smart/project-alpha-platform/workbench-inbox) | A primary interface for managing tasks serving as a hub for all the tasks assigned to you, your group, and your team. |
| [Enquiry Inbox](/smart/project-alpha-platform/workbench-enquiry-inbox) | A primary interface to manage inquiries efficiently. |
| [Case Assignment and Task States](/articles/pulse-publication/case-assignments-and-task-states-wb-cm) | A brief about case assignment and states of tasks. |
| [Layouts, Categories and Forms](/articles/pulse-publication/layouts-categories-and-forms-wb-cm) | Layout for task pages. |
| [Global Pages](/articles/pulse-publication/global-pages-wb-cm) | A reusable layouts or components that can be used across tasks. |
| [Navigation Links](/articles/pulse-publication/navigate-links-wb-cm) | Navigate across the platform or to an external link using Main Menu or Headers in Workbench. |
| [Task Allocation](/articles/pulse-publication/task-allocation-wb-cm) | Distribute tasks effectively either manually or using Task Automation System. |
| [Workbench Glossary](/articles/pulse-publication/workbench-glossary-wb-cm) | Contains Key Terms used in Workbench |
