# Interface

<https://documentation.neutrinos.com/articles/#!pulse-publication/process-definition>

The Process Definitions submodule in Process Runtime provides a tabular view of all process definitions deployed to the platform.

## Interface

![up-process-runtime-process-definition-page](/resources/Storage/pulse-publication/images/up-process-runtime-process-definition-page.png)

1. **Name**: Displays the name of the deployed process definition.
2. **ID**: Displays the unique Process ID associated with the deployed process definition.
3. **Version**: Displays the latest deployed version of the process definition.
4. **Deployment**: Displays the deployment type of the process definition. The deployment type can be Default for processes deployed manually or Timer for processes deployed through a Timer Start node.
5. **Last Updated**: Displays the date and time when the process definition was last modified and deployed.
6. **Actions**: Click the kebab icon in this column to open a context menu with options to start a process instance, view the process, export the process, or undeploy the process. Alternatively, you can start the process from the Process Instance page. To learn more about starting a process from the Process Instances page, see the Start Process section in the Process Instances topic.

Additionally, you can use the Search bar to search for deployed process definitions. The Show by drop-down list allows you to specify the number of rows displayed in the table, while the pagination controls allow you to navigate between multiple pages of process definitions.
