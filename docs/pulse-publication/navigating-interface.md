# View Favourites

<https://documentation.neutrinos.com/articles/#!pulse-publication/navigating-interface>

This topic provides details on navigating the Pulse platform interface. The platform combines Process Management, Case Management, Rules Engine, Hypha, and Content & Data Management capabilities into a single ecosystem. It enables organizations to design, automate, orchestrate, and manage both structured and unstructured business operations while ensuring scalability, governance, and operational efficiency.

![up-landing-page](/resources/Storage/pulse-publication/images/up-landing-page1.png)

The image above illustrates the platform’s Landing Page dashboard interface, which serves as the centralized workspace presented to users after authentication. The dashboard provides streamlined access to projects, modules, recently accessed activities, and frequently used platform functions. It is designed to enhance navigation efficiency, improve operational visibility, and increase user productivity by consolidating key actions, contextual information, and project-related activities within a unified interface.

1. **Header Section**: The top navigation bar provides access to global platform controls and user-specific actions. This section contains the platform logo, displayed in the top-left corner, which represents the organizational identity and provides quick navigation to the Home dashboard. It also includes global navigation options such as Notifications, User Management, and Settings or Administration modules. Additionally, the header displays the currently logged-in user’s information, including the username and avatar, with access to profile management, account settings, and logout options.
2. **Welcome Section**: The Welcome section provides a personalized greeting to users upon login. It displays a dynamic welcome message based on the authenticated username, enhancing personalization, improving user engagement, and creating a more intuitive dashboard experience. For example, in the illustrative sample image, the welcome message reads “Welcome Davis.”
3. **Quick Actions Section**: The Quick Actions panel provides shortcut access to frequently used platform functionalities, as well as recently accessed workflows and projects. This section is designed to minimize navigation effort, accelerate user operations, and improve overall workflow efficiency by enabling faster access to commonly performed tasks.
4. **Create New Project**: The first card in the Quick Actions section allows users to create a new project. It provides one-click access to project creation, enabling users to initiate the project onboarding and configuration workflow quickly.
5. **Module Shortcut Panel**: The Module Shortcut panel provides direct navigation to commonly used platform modules, including Objects, User Management, Documentation, and What’s New.
  - Objects: Provides access to object modeling and entity configuration functionalities.
  - User Management: Enables management of users, roles, permissions, and access controls.
  - Documentation: Provides access to platform technical documentation and knowledge repositories.
  - What’s New: Displays recent platform updates, feature enhancements, and release information.
6. **Recent Activity / Resume Cards**: The dashboard displays recently accessed or active projects and workflows to help users quickly resume ongoing work. Each activity card includes project initials or icons, the project name, associated task or workflow information, the last activity timestamp, user collaboration indicators, and a resume action. This improves operational continuity, enhances collaboration visibility, and enables users to efficiently continue previously initiated activities with minimal navigation effort.
    ![up-landing-page-recent-activity-card](/resources/Storage/pulse-publication/images/up-landing-page-recent-activity-card.png)
7. **Projects & Modules Section**: The Projects & Modules area acts as the primary workspace repository where users can access all configured projects and modules available within the platform.
8. **Search Bar**: The Search Bar enables users to quickly locate projects, modules, workflows, or related platform resources. It supports keyword-based search functionality, improving navigation efficiency and allowing users to access required information with minimal effort.
9. **View Controls**: This section provides controls for managing project display and workspace preferences. It allows users to switch between Grid View and Table View layouts based on their preferred visualization. The section also provides access to bookmarked or favorite projects for quicker retrieval of frequently accessed workspaces.
    Additionally, users can initiate quick project creation directly from the project workspace section. Pagination controls are also provided, enabling users to define the number of visible records per page and supporting scalable navigation across large project repositories.
10. **Project Cards**: Each project is represented with a card-based layout that provides a concise, visually structured summary of project information. The card design enhances readability and improves navigation efficiency while maintaining visual clarity across the workspace.
    Each project card includes project initials or icons, a color-coded visual identifier, the project name (for example, APL-Group-NB), project owner information, and the latest activity timestamp. Additionally, the card provides quick action options, such as opening the project and marking it as a favorite for easier access. This card-based navigation structure improves project discoverability, provides at-a-glance operational visibility, and enhances the overall user experience by enabling efficient access to project-related information and actions.

## View Favourites

Projects and modules can be marked as favourites by selecting the star icon associated with them. Once marked, these items are added to the Favourites list for quick access. To view only the projects and modules marked as favourites, click the Favourite option in the Projects and Modules section of the Dashboard page. This filters the list to display only the favourite projects and modules. The following image illustrates the Dashboard page displaying only the favourite projects and modules.




 ![up-landing-page-favourite](/resources/Storage/pulse-publication/images/up-landing-page-favourite.png)

Additionally, if specific modules such as My Tasks Inbox, Settings, and Master Data are marked as favourites, they are displayed along with their associated project name and the navigation path representing the selected module, as illustrated in the image below.




 ![up-landing-page-favourite-module-path](/resources/Storage/pulse-publication/up-landing-page-favourite-module-path.png)

## Switch View

The Projects and Modules section can be viewed either as cards or in a list view. By default, the items are displayed as cards. To switch between the card view and list view, click the corresponding view option at the top of the Projects and Modules section, as illustrated in the image below:




 ![up-landing-page-switch-view-list](/resources/Storage/pulse-publication/images/up-landing-page-switch-view-list1.png)

Once the view is changed from card view to list view, the Projects and Modules section displays the project and module information in a format similar to the image illustrated below:




 ![up-landing-page-switch-view-list-list-view](/resources/Storage/pulse-publication/images/up-landing-page-switch-view-list-list-view1.png)




 The list view presents project and module information in a tabular format. The table includes the project or module name, owners, last opened timestamp, an Actions column containing a kebab icon for performing quick actions, and a star icon for marking the project or module as a favourite. Click the Favourite option at the top-right corner of the Projects and Modules section to filter the list and display only the projects and modules marked as favourites as illustrated in the image below:




 ![up-landing-page-switch-view-list-favourite-list-view](/resources/Storage/pulse-publication/images/up-landing-page-switch-view-list-favourite-list-view1.png)

 ![up-landing-page-create-project](/resources/Storage/pulse-publication/images/up-landing-page-create-project.png)


 In the Create New Project dialog box, enter the project name. Optionally, provide a description and select an icon for the project.

## Edit Project Listing

From the Projects listing on the landing page, you can perform common actions, such as editing the project name, changing the project icon, cloning the project, or deleting it.

1. In the Projects section, navigate to the Projects or Modules section, and then locate the project or module whose name or icon you want to edit.
2. Click the kebab (⋮) icon in the Action column for the required record. A contextual menu displays the available actions, including Edit, Favourite, Clone, and Delete.
    ![up-landing-page-edit-project-listing](/resources/Storage/pulse-publication/images/up-landing-page-edit-project-listing.png)
3. From the available options in the contextual menu, click Edit.
4. On the next page, update the project name, description, and associated icon as required. To change the icon, select the appropriate option from the Icon drop-down list.
    ![up-landing-page-edit-project-listing-edit-details](/resources/Storage/pulse-publication/images/up-landing-page-edit-project-listing-edit-details.png)
5. After updating the required details, click Update in the pop-up to apply the changes.

## User Admin

The Users page enables administrators to manage user accounts on the platform. To access this page, click the User Management thumbnail in the Quick Actions section on the landing page. **Note**: Access to the User Management section is restricted to Super Administrators and users who have been granted the required permissions.




 ![up-user-admin-access-from-landing-page](/resources/Storage/pulse-publication/images/up-user-admin-access-from-landing-page1.png)




 The Users page displays all users available on the platform. User information is presented in a tabular format, with each user record displayed as a row and its associated details organized across individual columns for easy viewing and management.




 ![up-users-listing-page-admin1](/resources/Storage/pulse-publication/images/up-users-listing-page-admin1.png)




 The table includes the following information for each user:

- **Username**: The unique name associated with the user account.
- **Email ID**: The email address provided during user creation.
- **Role**: The Role assigned to users.
- **Groups**: The groups to which the user belongs. A user can be associated with one or more groups.
- **Status**: The current availability status of the user, such as Available, On Leave, or other configured statuses.
- **Leave Until**: Displays the date until which the user is marked as unavailable when the status is set to On Leave.
- **Last Activity**: Indicates the most recent activity performed by the user on the platform.
- **Actions**: Contains a kebab menu (three-dot icon) that provides options to manage the user account, such as editing user details or deleting the user, subject to the administrator's permissions.

## Object Manager

The Object Manager page displays all objects that are available globally across the platform, regardless of the project to which they belong. To access the Object Manager page, on the platform landing page, click the Objects thumbnail in the Quick Actions section.




 ![up-landing-page-objects-access1](/resources/Storage/pulse-publication/images/up-landing-page-objects-access1.png)

The objects are displayed in a table, where each row represents an object, and each column displays specific details, such as the object name, description, creation date and time, last opened date and time, and the Actions column. The Actions column contains a kebab menu that allows you to edit or delete the corresponding object.




 ![up-landing-page-objects-page-options](/resources/Storage/pulse-publication/images/up-landing-page-objects-page-options1.png)

- **Name**: Displays the name assigned to the object during its creation.
- **Description**: Displays the description provided for the object during its creation.
- **Created Date**: Displays the date and time when the object was created on the platform.
- **Last Opened**: Displays the time elapsed since the last activity on the object.
- **Activity**: Contains a kebab menu that provides options to edit or delete the object.

In addition to these options, you can use the search bar to search for objects that are available on the platform for a specific tenant. You can switch between the List and Thumbnail views by clicking the Thumbnail View button in the upper-right corner of the page. To control the number of objects displayed on each page, use the Show drop-down list.

Further, you can also use the pagination controls to navigate between pages in the Object Manager. To know more about configuring and managing objects on the platform, refer [Object Details](/articles/pulse-publication/configure-object) topic.
