# Compare

<https://documentation.neutrinos.com/articles/#!pulse-publication/compare-ct>

Comparison is the process of analyzing differences between two versions of a code file within a branch, typically between two commits or pull requests. It enables users to understand what has changed, where the changes occurred, and how the versions differ, thereby supporting review, validation, and informed decision-making before or after changes are applied.

To compare changes within a branch between commits or pull requests, follow the below steps:

1. From the Commits landing page, use the left navigation panel to navigate to the Compare page.
   ![alpha-change-tracking-compare-navigate](/resources/Storage/pulse-publication/images/alpha-change-tracking-compare-navigate.png)
2. On the Compare page, select two branches—one as the source (From branch) and the other as the reference (To branch)—to compare the changes between them.
   ![alpha-change-tracking-compare-landing-page](/resources/Storage/pulse-publication/images/alpha-change-tracking-compare-landing-page.png)
3. After selecting the branches, click the Compare button to initiate the comparison. If the comparison identifies changes that require a pull request, a Create PR button is available. Clicking this button redirects you to the Pull Requests page, where you can raise a pull request for the selected changes. Based on the reviewer’s evaluation, the pull request can be approved and merged or declined.
   ![alpha-change-tracking-compare-comparison-create-pr](/resources/Storage/pulse-publication/images/alpha-change-tracking-compare-comparison-create-pr.png)
