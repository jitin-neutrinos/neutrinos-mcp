# Integration

<https://documentation.neutrinos.com/articles/#!pulse-publication/integration>

Upstream services can consume API results once the APIs are exposed. To enable the consumption of Rules, Rule Groups, Workflows, and Master Data, expose them as JSON from the Reels platform. These JSON files can then be imported into Swagger UI (or OpenAPI), where they can be executed, and the results consumed. This topic outlines how Rule, Rule Group, Workflows, and Master Data can be used in Swagger.
