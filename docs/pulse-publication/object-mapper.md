# Interface

<https://documentation.neutrinos.com/articles/#!pulse-publication/object-mapper>

The Object Project Mapper is a configuration component used to establish mappings between objects and projects. It enables data defined in an object to be referenced within a project by creating a mapping between the object and the corresponding project.

## Interface

The following image illustrates the Object Project Mapper landing page:

![hypha-studio-object-mapper-landing](/resources/Storage/pulse-publication/images/hypha-studio-object-mapper-landing.png)

1. **Navigation Panel**: The left navigation panel allows users to navigate across different components of the platform.
2. **Available Objects**: Displays the list of objects available on the platform.
3. **Selected Objects**: Displays the list of objects selected to be mapped to the specific project.

## Map Object

To map objects to a project, follow the steps below:

1. Navigate to the Object Project Mapper using the left navigation panel.
    ![hypha-studio-object-mapper-first](/resources/Storage/pulse-publication/images/hypha-studio-object-mapper-first.png)
2. Select the object to be mapped from the list of available objects on the platform.
    ![hypha-studio-object-mapper-object-select](/resources/Storage/pulse-publication/images/hypha-studio-object-mapper-object-select.png)
3. Select the required object, then click and drag it to the Selected Objects section on the right.
    ![hypha-studio-object-mapper-object-select-drag](/resources/Storage/pulse-publication/images/hypha-studio-object-mapper-object-select-drag.png)
4. The Selected Objects section displays all objects that are mapped to the project.
    ![hypha-studio-object-mapper-selected-objects](/resources/Storage/pulse-publication/images/hypha-studio-object-mapper-selected-objects.png)
5. Click the Save button at the bottom of the page to save all mapped objects to the project.

Additionally, objects can be removed from the Selected Objects section if they were added incorrectly. To remove an object, click the ‘x’ icon next to the object in the list.




 ![hypha-studio-object-mapper-selected-objects-delete](/resources/Storage/pulse-publication/images/hypha-studio-object-mapper-selected-objects-delete.png)
