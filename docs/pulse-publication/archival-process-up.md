# Archival

<https://documentation.neutrinos.com/articles/#!pulse-publication/archival-process-up>

Archiving enables organizations to offload historical or inactive data from production systems into a dedicated archival repository for long-term retention, compliance, and optimized performance. It is essential for maintaining system scalability, reducing costs, meeting regulatory requirements, and ensuring efficient lifecycle management of enterprise data.

This topic serves as a runbook for the archiving in the Neutrinos Alpha Platform. It explains how data, information, processes, cases, and other records can be archived when they are no longer actively required.
