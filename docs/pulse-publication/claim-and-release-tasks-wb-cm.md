# Claim Task

<https://documentation.neutrinos.com/articles/#!pulse-publication/claim-and-release-tasks-wb-cm>

In the Workbench, tasks available in the group tasks inbox are not assigned to any specific user. To work on these tasks, a user must claim a task to assign it to themselves, or an admin can reassign it to a designated user. This topic describes the step-by-step process for claiming a task, completing it, and then releasing it once the work is finished.

# Claim Task

This section outlines the process of claiming tasks from the Group Tasks inbox.

1. In the workbench, go to the Inbox page, click the **Tasks** dropdown and select **Group Tasks** to view the list of available group tasks.
    ![alpha-group-tasks-claim-navigate](/resources/Storage/pulse-publication/images/alpha-group-tasks-claim-navigate.png)
2. On the **Group Tasks** inbox page, click a specific task to open its task details page.
    ![alpha-group-tasks-claim-choose-task](/resources/Storage/pulse-publication/images/alpha-group-tasks-claim-choose-task.png)
3. On a specific task page, click the **Claim** button at the top of the page to assign the task to yourself. Once claimed, the task appears in the **My Tasks** inbox until you click the Release button. Releasing the task returns it to the Group Tasks list, making it available for other users to claim and work on.
    ![alpha-group-tasks-claim-process](/resources/Storage/pulse-publication/images/alpha-group-tasks-claim-process.gif)

| ![Note](/resources/Storage/pulse-publication/project-trailproject/note.png) | Note: If a user attempts to make changes in the Group Tasks section without first claiming a task, the platform prompts them to claim the task before making any modifications or proceeding with the work. |
| --- | --- |

# Release Task

This section outlines the process of releasing claimed tasks back to the Group Tasks inbox. After completing work on a claimed task, you can release it back to the Group Tasks list, making it available for other users to claim and work on if needed.

1. In the workbench, go to the Inbox page, click the **Tasks** dropdown and select **My Tasks** to view the list of My Tasks.
    ![alpha-group-tasks-claim-navigate-my-tasks](/resources/Storage/pulse-publication/images/alpha-group-tasks-claim-navigate-my-tasks.png)
2. Navigate to the specific claimed task and click it to open the task details page.
    ![alpha-group-tasks-claim-claimed-task](/resources/Storage/pulse-publication/images/alpha-group-tasks-claim-claimed-task.png)
3. On the task page, click the **Release** button at the top of the page to return the task to the **Group Tasks** list.
    ![alpha-group-tasks-release-process](/resources/Storage/pulse-publication/images/alpha-group-tasks-release-process.gif)
