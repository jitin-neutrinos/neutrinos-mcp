# Folder APIs

<https://documentation.neutrinos.com/articles/#!pulse-publication/folder-apis>

To integrate Media Collection Folder APIs, follow the steps below:

1. **Create Folder**
    The first step is to create a folder, which acts as a container for organizing and storing related media files on the platform.
    Use the OpenAPI 3.0 standards to define the schema, as illustrated in the sample below:
    Copy CodeCode{
    "projectId": "****",
    "folderName": "TestFolder1",
    "metaData": {
    "type": "object",
    "properties": {
    "fileName": {
    "type": "string"
    },
    "fileType": {
    "type": "string"
    }
    }
    },
    "description": "Folder description",
    "tags": [
    "Test1"
    ]
   }
    After a successful execution of the above JSON, the system returns a success message along with the folder ID. The output will appear similar to the sample shown below:
    Copy CodeJSON{
    "success": true,
    "data": {
    "id": "cf115a97-2f82-4ee7-800e-f72d4c9a504b",
    "projectId": "****",
    "folderName": "TestFolder1",
    "activeVersion": "1.0.0",
    "activeVersionId": "4e83907c-a995-4e29-9855-a13e0de16f06",
    "description": "Folder description",
    "metaData": {
    "type": "object",
    "properties": {
    "fileName": {
    "type": "string"
    },
    "fileType": {
    "type": "string"
    }
    },
    "required": [
    "fileName",
    "fileType"
    ]
    },
    "createdAt": "2026-01-08T13:58:44.982Z"
    },
    "timestamp": "2026-01-08T13:58:45.106Z"
   }
    **Note**: In this example, a centralized token generated from the platform is used and passed in the request header with the key token to authorize the API call. Alternatively, an IDS token can also be used.
  - **projectId**: Specifies the project ID associated with the media collection folder. This predefined field is automatically populated when the Swagger file is downloaded for the selected project.
  - **folderName**: Accepts a string value representing the name of the media collection folder. Specify the folder name as required.
  - **Metadata**: Specifies file metadata, including media collection folder properties such as file name and file type data types. These predefined fields are automatically populated when the Swagger file is downloaded from the platform.
  - **description**: Provides a brief description of the media collection folder to clarify its purpose and the type of files intended for storage.
  - **Tags**: This is an optional field that allows you to specify a tag for each version of the folder.
2. **Update Folder**: Updates an existing media collection folder using the folder ID generated by the Create Folder API. The following JSON example shows a sample update request.
    Copy CodeJSON{
    "id": "cf115a97-2f82-4ee7-800e-f72d4c9a504b",
    "folderName": "TestFolder2",
    "metaData": {
    "type": "object",
    "properties": {
    "fileName": {
    "type": "string"
    },
    "fileType": {
    "type": "string"
    }
    }
    },
    "description": "Updated the folder",
    "version": "1.0.0",
    "tags": [
    "Test2"
    ]
   }
    After the successful execution of the above JSON, a success message is displayed, and the updated JSON is returned as the output.
    Copy CodeJSON{
    "success": true,
    "data": {
    "id": "cf115a97-2f82-4ee7-800e-f72d4c9a504b",
    "folderName": "TestFolder2",
    "activeVersion": "1.0.0",
    "activeVersionId": "4e83907c-a995-4e29-9855-a13e0de16f06",
    "description": "Updated the folder",
    "metaData": {
    "type": "object",
    "required": [
    "fileName",
    "fileType"
    ],
    "properties": {
    "fileName": {
    "type": "string"
    },
    "fileType": {
    "type": "string"
    }
    }
    },
    "createdAt": "2026-01-09T04:53:18.162Z"
    },
    "timestamp": "2026-01-09T04:53:18.162Z"
   }
    **Note**: In this example, a centralized token generated from the platform is used and passed in the request header with the key token to authorize the API call. Alternatively, an IDS token can also be used.
  - **id**: Specifies the unique folder ID returned by the Create Folder API call, which identifies the media collection folder to be updated.
  - **foldeName**: Specifies the name of the folder to be updated and updates the associated folder details.

    Copy CodeJSON{

    "searchKey": ""
   }

   }

5. **Fetch by Name**: This API retrieves a specific folder from the platform using the folder name provided in the request body. The folder name must match the one specified during the creation of the folder through the Create Folder API. The following JSON shows a sample request for this API call.
    Copy CodeJSON{
    "folderName": "TestFolder2"
   }
    Upon successful execution of the above JSON, the output displays the folder that matches the name specified in the request body. Note: The folder name is case-sensitive, and the API retrieves only the folder that exactly matches the name provided in the request body.
6. **Remove Folder**: This API deletes a specific folder from the platform using the folder name provided in the request. The folder name must exactly match the name of an existing folder on the platform.
    Copy CodeJSON {
    "folderName": "TestFolder2"
    }
    Upon successful execution of the above JSON, the output displays a success message indicating that the folder with the corresponding name is removed successfully. The following JSON shows a sample response for this API call.
    Copy CodeJSON{
    "success": true,
    "message": "Folder removed successfully"
   }
    **Note**: In this example, a centralized token generated from the platform is used and passed in the request header with the key token to authorize the API call. Alternatively, an IDS token can also be used.
  - **folderName**: Specify the folder name in the request body to retrieve the corresponding folder. The name must match the one provided during folder creation. Note: The folder name is case-sensitive, and the API retrieves only the folder that exactly matches the name provided in the request body.
