# Interface - Archival & Retention

<https://documentation.neutrinos.com/articles/#!pulse-publication/logs-process-runtime>

This page displays the Archival and Retention logs and Audit logs for process instances on the platform.

## Interface - Archival & Retention

![up-process-runtime-process-archival-retention](/resources/Storage/pulse-publication/images/up-process-runtime-process-archival-retention.png)

- **Start Time**: Displays the date and time when the archival or retention operation for the process or case started.
- **Type**: Displays the type of operation performed on the platform. The operation can be either Archival or Retention.
- **Scope**: Displays the scope of the operation. The operation can be performed on either a Process or a Case.
- **ID**: Displays the ID assigned to the archival or retention operation.
- **Status**: Displays the current status of the archival or retention operation performed on the process or case.
- **Details**: Displays the details of the operation.
- **Duration**: Displays the time duration taken for the archival or retention operation.
- **Actions**: Displays a Restore option for processes that have been successfully archived.

## Interface - Audit

This tab displays the log list for the process instances

![up-process-runtime-process-logs](/resources/Storage/pulse-publication/images/up-process-runtime-process-logs.png)

- **Timestamp**: Displays the date and timestamp for the action that was performed on the process instance.
- **Category**: Displays the category of the action performed on the process instance.
- **Action**: Displays the type of action performed on the process instance.
- **Message**: Displays the message for the particular action performed for the process instance.
- **Actor**: Displays the user or system assigned to the process instance.
- **Process Instance ID**: Displays the process instance ID associated with the log entry.
- **Source**: Displays the source that initiated the process instance.
