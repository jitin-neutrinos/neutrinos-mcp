# Administration

<https://documentation.neutrinos.com/articles/#!pulse-publication/administration>

The Administration page serves as a configuration interface for managing access control and users within the platform. It enables administrators to define user identities, assign permissions, and organize users into logical groupings to support secure and scalable process execution.



![pulse-administration-default-landing-page](/resources/Storage/pulse-publication/images/pulse-administration-default-landing-page.png)

This module consists of three components:

- **Users**: The Users section allows administrators to create and manage individual user accounts that can access the platform. The administrators can:
  - Create, edit, and delete user accounts.
  - Configure user attributes such as name and email.
  - Assign one or more roles to define access permissions.
  - Associate users with one or more groups for organizational mapping.
  - Assign a user as the manager of the current user.
  - Associate other users as subordinates if the current user possesses a Manager role.
  - Associate relevant skills with the current user.
  - Additionally, configure bandwidth, remaining bandwidth, daily limits, remaining daily limits, and relevant task statuses and distributions for the current user.
- **Groups**: The Groups section enables administrators to organize users into logical collections, typically based on departments or teams. The administrators can:
  - Create and manage groups.
  - Add or remove users from groups.
  - Assign roles at the group level.
- **Roles**: The Roles section defines a set of permissions that control what actions a user can perform within the platform. The administrators can:
  - Create custom roles based on business requirements.
  - Define granular permissions and assign the role to the relevant projects that require it.
  - Modify or delete existing roles.
