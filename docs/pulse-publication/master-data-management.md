# Master Data Management

<https://documentation.neutrinos.com/articles/#!pulse-publication/master-data-management>

Data is essential for rule execution, whether it occurs before, during, or after applying rules. When the required data is spread across various systems and is largely static, non-dynamic, or non-transactional, centralized management becomes crucial. Centralized data enables various departments and entities within an organization to operate more effectively.

At its core, MDM is engineered for peak performance, harnessing memory caching and advanced query management to deliver fast data retrieval and processing. This setup not only boosts rule execution speed but also ensures the use of up-to-date data for decision-making across the organization. In addition to managing extensive data dictionaries, the MDM service enables complex queries while ensuring access control, allowing only authorized users to access the data.

Data can be input into the Reels platform through the MDM service in two distinct ways:

1. **Reels Studio Upload**: Users can log in and import data through Excel files, CSVs, or other supported formats.
2. **API Integration**: The MDM service can be configured to retrieve master data from external sources and import it into the Reels platform through API integrations.
