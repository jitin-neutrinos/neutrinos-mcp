# Tabbed View

<https://documentation.neutrinos.com/articles/#!pulse-publication/tabbed-view>

Within a project, you can open multiple tabs, each corresponding to a different module. For example, you can have one tab open for Rules, another for Case Management, and a third for Process Runtime, allowing you to work across multiple modules simultaneously.

To add a new tab, follow these steps:

1. Click the Add Tab (+) icon at the top of the page in any open module.
   ![up-navigation-multiple-tabs-1](/resources/Storage/pulse-publication/images/up-navigation-multiple-tabs-1.png)
2. From the list of available modules, select the module to open in a new tab.
   ![up-navigation-multiple-tabs-2](/resources/Storage/pulse-publication/images/up-navigation-multiple-tabs-2.png)
3. The new tab opens the selected module, allowing you to work in multiple modules simultaneously by keeping each module open in a separate tab.
   ![up-navigation-multiple-tabs-3](/resources/Storage/pulse-publication/images/up-navigation-multiple-tabs-3.png)
