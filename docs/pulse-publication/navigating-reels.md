# Interface

<https://documentation.neutrinos.com/articles/#!pulse-publication/navigating-reels>

From within the selected project, click Reels in the left navigation pane to open the Neutrinos Reels Engine. The Reels landing page is displayed. If no submodules are currently open, the main workspace displays a No open tabs message. Click any submodule in the left navigation pane to open its corresponding page in the workspace.

## Interface

![up-reels-landing-page](/resources/Storage/pulse-publication/images/up-reels-landing-page2.png)

1. The main navigation pane lists all the modules available for the selected project. Use it to navigate between modules such as Case Manager, Rules Engine, Process, Tokens, and others.
2. The left navigation pane lists all the submodules available within the selected module. The currently selected submodule is highlighted to indicate your current location within the module. You can navigate to the following submodules:
  - **Rules**: This section allows you to create and manage rules. You can:
    - Create new rules or rule groups.
    - Delete existing rules.
    - Edit a rule by clicking on the rule itself.
    - Search for rules using the search bar.
  - **Workflow**: This section allows you to create, manage, and monitor workflows. You can:
    - Create a new workflow.
    - Edit, clone, or delete a workflow.
    - View different workflow versions by clicking the expansion button on the right-hand side of the row.
    - Search for workflows using the search bar.
    - Import or export workflows.
    - Select and delete either a single or multiple workflows.
  - **Master Data**: This section enables you to manage the master data used by workflows and rules. You can:
    - Create new master data.
    - Edit existing master data.
    - Delete the master data.
    - View different versions of the master data.
    - Search for the master data using the search bar.
  - **Logs**: This section allows you to view and audit logs, including **Activity Logs**, **Audit Logs**, and **Rule Execution Logs**.
    - **Activity**: Displays the login times of individual users.
    - **Audit**: Displays the types of rules created by each user.
    - **Rules Execution**: Displays the different rules executed by each user.
  - **Content Repository**: This section allows you to manage templates for various use cases.
    - Create Templates
    - View templates created on the platform for various use cases
    - Manage templates available on the platform
  - **Media Collection**: This section is a centralized repository or grouped set of media assets such as images, videos, audio files, and documents that are uploaded, managed, and used with the reels platform to support application design and content display.
3. This option toggles the visibility of the left navigation pane, allowing you to increase the available workspace. Hiding the navigation pane provides more space to work on the canvas or view tables in full width.
4. This bar displays all the tabs that are currently open on the platform. Each tab represents an open module or submodule, allowing you to switch between different pages without losing your current context.
5. The active tab identifies the module you are currently working in.
6. The search bar lets you find items within the currently selected module. The search is limited to the active tab.
7. This option allows you to switch between the Rules and Rule Groups tabs. The selected tab displays the corresponding list of rules or rule groups available on the platform.
8. The Add button allows you to create a new rule or rule group.
9. The table displays the list of rules or rule groups, depending on the selected tab. When the Rules tab is selected, the table lists all the available rules. When the Rule Groups tab is selected, it lists all the available rule groups. The table includes the following information for each rule or rule group:
  - **Name**: Displays the name of the rule or rule group.
  - **ID**: Displays the unique identifier assigned to the rule or rule group.
  - **Version**: Displays the current version of the rule or rule group.
  - **Rule Type**: Displays the type of the rule.
  - **Author**: Displays the name of the user who created the rule or rule group.
  - **Available From**: Displays the date and time from which the rule or rule group is available.
  - **Last Updated**: Displays the date and time when the rule or rule group was last modified.
