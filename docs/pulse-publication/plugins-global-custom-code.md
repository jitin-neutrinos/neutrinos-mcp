# Plugins Global Custom Code

<https://documentation.neutrinos.com/articles/#!pulse-publication/plugins-global-custom-code>

In the Alpha platform, plugins for Global custom code are modular, reusable units that can be integrated into applications to extend their functionality. Plugins allow developers to encapsulate logic—such as utility functions, data formatting, and other behaviors—and make it available across multiple components and/or pages within a project. This promotes cleaner and more maintainable code by reducing redundancy.

In Alpha Global custom code, plugins are typically defined in the Marketplace and included in the context, making them accessible via the ap.<pluginName> namespace. Whether used for implementing business rules, handling validations, or streamlining repetitive tasks, plugins enhance development efficiency and support a modular application architecture.
