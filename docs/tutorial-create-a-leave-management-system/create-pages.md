# Overview for LMS App Pages

<https://documentation.neutrinos.com/articles/#!tutorial-create-a-leave-management-system/create-pages>

On the Neutrinos Platform, each **Page** is an application view. When you create an app on Neutrinos using a template, some pages get generated by default. These pages are called **default pages**.

### Overview for LMS App Pages

For the LMS app, you will be creating the following pages:

- **[home](/articles/tutorial-create-a-leave-management-system/home)(default)**: Gets created by default for LMS app as **neutrinos-login-template **was selected during app creation. This is the landing page after registered user login.
- **[login](/articles/tutorial-create-a-leave-management-system/login)(default)**: Gets created by default for LMS app as **neutrinos-login-template **was selected during app creation. It has a login feature implemented by default where users registered in Neutrinos Console will be authenticated.
- **[loader](/articles/tutorial-create-a-leave-management-system/loader)(default)**: Gets created by default for LMS app as **neutrinos-login-template **was selected during app creation. It displays the information about what is happening while the user waits after entering his or her credentials and clicking **Login**.
- **[myapprovals](/articles/tutorial-create-a-leave-management-system/myapprovals)**: Displays all the applied leave requests by the employee belonging to his department. This component will be only visible to the manager.
- **[userregistration](/articles/tutorial-create-a-leave-management-system/userregistration)**: If a user logs in for the first time, this page captures the required user metadata with default leaves that the user is eligible to avail.
- **[userdetail](/articles/tutorial-create-a-leave-management-system/userdetails)**: A tabbed view for displaying the user profile, and leave status.
- **[myprofile](/articles/tutorial-create-a-leave-management-system/myprofile)**: Displays details such as name and employee ID of the logged-in user.
- **[myleaves](/articles/tutorial-create-a-leave-management-system/myleaves/a/column-1-flex-layout-column)**: Displays all the leaves, applied and rejected.
- **[applyleave](/articles/tutorial-create-a-leave-management-system/applyleaves)**: Displays a form to fill while applying for leave.

**Creating Pages**

1. To create a page, click the **Add** icon and click the **P****age **option.

![Create Pages](/resources/Storage/tutorial-create-a-leave-management-system/createpageLMS.png)

2. In the Enter Page Name dialog box, enter the name of the page. For Example, enter **myapprovals**.

![Page Details(NAME)](/resources/Storage/tutorial-create-a-leave-management-system/pagedetailsLMS.png)

3. Click **Create Page. **

4. The **myapprovals** page is created successfully.

Similarly, create the following pages:

- **userregistration**
- **userdetail**
- **myprofile**
- **myleaves**
- **applyleave**

| ![Information](/resources/Storage/tutorial-create-a-leave-management-system/info.png) | The** home**, **login**, and **loader** pages are created automatically when you selected the **Neutrinos Login** template while creating the app. |
