# Design Pages

<https://documentation.neutrinos.com/articles/#!tutorial-create-a-leave-management-system/design-pages>

To design pages, click the **Pages** option and select the page that you want to design. The Page Designer for the selected page opens up. It comprises the Palette from where you can drag components such as a **Row**, **Table**, etc.

![sections of the page](/resources/Storage/tutorial-create-a-leave-management-system/pagedesignLMS.png)

Some components, such as rows and columns, have droppable regions. This means that you can add other components within these components.To design a page, drag components from the **Palette Section** and drop the components in the **Page ****Container.**

**Rows**

When you drop components in a row, they get stacked horizontally by default. You can add properties if you want additional behavior for various devices.

**Columns**

When you drop components in a column, they get stacked vertically by default. You can add properties if you want additional behavior for various devices.

---

**Properties**

You need to configure properties for each page. Note that there are properties associated with each component on a page. You can view the associated properties of a component by double-clicking it. In addition, you can also add custom properties for a component.

**Custom Properties**

A **custom property** is a property that is not available by default in the Attributes window, but is added as per the user requirement.

To add a custom property, go to the attributes window, scroll down and click on the custom properties. You can define a key-value pair or an attribute. By default, **Attribute** is selected.

**Attributes and Key/Value**

To create a custom **Attribute **property, you enter the key data. The Studio auto-completes the value data. However, for a custom **Key/Value** property, enter the key as well as the data value. Click **ADD** to add the custom property.

| **Component** | **What you need to Enter** |
| --- | --- |
| Attribute | Enter the Key Data |
| Key/Value | Enter the key and data value |
