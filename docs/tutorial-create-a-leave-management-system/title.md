# Create an App in Studio 6

![](/resources/Storage/tutorial-create-a-leave-management-system/gettyimages-1138262343-170x170.jpg)Tutorial: Learn How to Create a Simple App using Neutrinos PlatformBackground
In this tutorial, you will be creating a simple Leave Management System (LMS) app to learn how to work with the Neutrinos Platform.The LMS app is a HR application which is required for most organizations to track and digitize the leave management system. The Scope of the LMS app is to have two different user roles- **Manager** and **Employee**. Where,

An employee can register and view available leaves. Along with applying leaves, the employee can view the leave request status as approved, rejected, or pending.A manager in addition to performing employee tasks, gets to approve or reject the leave of the employee.You can also learn how to build the LMS app by watching this video series.
