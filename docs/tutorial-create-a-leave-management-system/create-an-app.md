# Create an App

<https://documentation.neutrinos.com/articles/#!tutorial-create-a-leave-management-system/create-an-app>

After you onboard users and groups, you create an app in the Neutrinos Studio. To download Neutrinos Studio, navigate to the **Home **section on [Neutrinos Console](https://console.neutrinos.co), select the platform of your choice, and download the software and install Neutrinos Studio to your local machine.

Once the Studio is launched, perform the following steps to create an app:

1. Log in to Neutrinos Studio
2. Click the **Create New App** icon on the Studio home page.
3. On the **Enter App Details** dialog box, enter the app metadata.
  - **App Name**: Enter the relevant application name. For example, Leave-Management-System.
  - **Add a preview image for your app**: Insert any image for your app.
  - **Version: **It displays the version of your app.
  - **Tenant**: Enter the tenant name provided by the Neutrinos administrator.
  - **Art URL**: Displays the default URL.
  - **Description**: Enter the app description. For example, Leave Application System.
4. To create an app, you can select a blank page or use any template suggested by the system. If you want to use any additional template you click ![](/resources/Storage/tutorial-create-a-leave-management-system/service-designer-user-s-guide/icon-legend-img0019.png) and download the template from the Neutrinos Store.
5. For the LMS app, you select the **neutrinos-login-template **as the default template while creating the app.
6. Click **Create**. The app will be created.

![LMS is created](/resources/Storage/tutorial-create-a-leave-management-system/createdLMS.png)

To start designing the app, click on the created app. The Application home page opens up.
