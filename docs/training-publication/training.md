- How to use the platform's integrated development environment to configure, and build full-stack applications
- How to deploy Web applications to GCP or any other deployment environments
- How to use studio components to build user interfaces
- How to use build environments to configure development, production and staging builds
- How to use data models
- How to use styles and global styling
- Best Practices to follow across all the capabilities of the platform
