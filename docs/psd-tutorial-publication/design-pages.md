# UI

<https://documentation.neutrinos.com/articles/#!psd-tutorial-publication/design-pages>

You design the pages of your application using the **Page Designer**. The Page designer comprises the **Page ****UI Designer** and **Page ****Flow Designer**.

![](/resources/Storage/psd-tutorial-publication/title-2021-08-25-1.png)

### UI

Also called the **Page UI Designer**. This is where you design the HTML view of the page. You can design the page UI by dragging and dropping [components](/articles/concepts-publication/component) to the [canvas](/articles/concepts-publication/services-designer-elements/a/h3__455959634).

### Flow

Also called the **Page Flow Designer**. This is where you design the [page flows](/articles/concepts-publication/page/a/h4_1492591665) by dragging and dropping [nodes](/articles/concepts-publication/services-designer-elements/a/h3__1499176760) on the canvas.

The page flow designer comprises a few elements that are common with the service designers on Neutrinos Studio. See [Services Designer Elements](/articles/concepts-publication/services-designer-elements) to learn more.
