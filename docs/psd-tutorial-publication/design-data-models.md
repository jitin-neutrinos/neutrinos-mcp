# Design Data Models

<https://documentation.neutrinos.com/articles/#!psd-tutorial-publication/design-data-models>

Create a [data model](/smart/project-sample-how-to-guide/designing-data-models) called** logobject**. This data model captures the data logged on the weather search page.

1. To create the [Data Model](/articles/project-concepts/legacy-data-model), click the **Models **menu from the side menu and select **Add.** The Data Model dialog box appears.
    ![Add data model](/resources/Storage/psd-tutorial-publication/project-tutorial-leave-management-system/2021-08-27_01h01_45.png)
2. Enter the following details and click **Add**.
    ![log data model](/resources/Storage/psd-tutorial-publication/log_dm.png)
3. After creating the data model, open the **Models **editor from the side menu and enter the following values in the respective fields to add the data attributes.
    ![open Models editor](/resources/Storage/psd-tutorial-publication/display%20datamodel.png)
    **Name**
    **Type**
    **Array[ ] **
    type
    string
    Not selected
    name
    string
    Not selected
