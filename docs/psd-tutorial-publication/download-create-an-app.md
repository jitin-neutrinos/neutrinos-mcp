# Create App

<https://documentation.neutrinos.com/articles/#!psd-tutorial-publication/download-create-an-app>

To create the app on [Neutrinos Studio](/smart/project-concepts/studio), perform the following steps:

1. Launch Neutrinos Studio and log in with your credentials.
    ![](/resources/Storage/psd-tutorial-publication/studio_open.png)
2. On the [Studio Home page](/smart/project-concepts/studio-home-page), click the **Create a Classic App** icon.
    ![The classic app](/resources/Storage/psd-tutorial-publication/classic%20app.png)
3. On the **Enter App Details** dialog box, enter the app metadata.
  - **App Name**: Enter the relevant application name. For example, **Weather App**.
  - **Add a preview image for your app**: Insert any image for your app. This is an optional step.
  - **Version: **Displays the version of your app.
  - **Tenant**: Enter the tenant name provided by the Neutrinos administrator. By default, the tenant name is **neutrinos**.
  - **Description**: Enter a description. For example, **Displays the weather details of a city**.
      ![Create app window](/resources/Storage/psd-tutorial-publication/weatherappcreate.png)
4. Click **Create**. The app will be created.

![](/resources/Storage/psd-tutorial-publication/app%20image.png)

To start designing the app, click the created app. The [Studio Application page](/smart/project-concepts/studio-application-page) opens up.
