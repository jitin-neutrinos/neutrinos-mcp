# Create a Web App

<https://documentation.neutrinos.com/articles/#!psd-tutorial-publication/title>

Create a Weather App on Neutrinos Studio 8.0
In this tutorial, you will be creating a **weather** app (using the latest version of Neutrinos Studio) to display the weather of a city that the user inputs at runtime. To get the weather data, this app will integrate with an external weather service provider called **Open Weather Map**.The end-app displaying the weather data of Tokyo city:![weather data of city Tokyo](/resources/Storage/psd-tutorial-publication/wea_tokyo.png)
