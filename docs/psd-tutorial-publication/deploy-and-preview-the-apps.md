# Deploy the App

<https://documentation.neutrinos.com/articles/#!psd-tutorial-publication/deploy-and-preview-the-apps>

**Deploy the App**

| ![Information](/resources/Storage/psd-tutorial-publication/project-tutorial-weather-app/info.png) | The **Deploy App** feature can be used by users having access to Neutrinos Console. If you have access to Neutrinos Console and are not able to use the 1-click Deploy feature, contact your organization admin or reach out to [Neutrinos Support](mailto:freetrial@neutrinos.co). |
| --- | --- |

To deploy the app on the cloud:

1. Save all the changes made to the app.
2. Enable 1-click deploy. This feature is disabled by default on Neutrinos Studio. See [Enable 1-click Deploy](/smart/project-sample-how-to-guide/deploying-an-application-on-cloud/a/h4__1051527422) to display the 1-click deploy icon (![1-click deploy icon](/resources/Storage/psd-tutorial-publication/project-tutorial-weather-app/understanding-the-application-home-page-2019-04-16-5.png)) on the Studio Application page.
3. Click ![1-click deploy icon](/resources/Storage/psd-tutorial-publication/project-tutorial-weather-app/understanding-the-application-home-page-2019-04-16-5.png) on the top-right corner of the Studio Application page.
    ![Deploy LMS app](/resources/Storage/psd-tutorial-publication/project-tutorial-weather-app/deploy.png)
4. Select the deployment targets for the build.
5. Click the **Deploy** button to schedule the build for deployment.
6. To check the status of your deployment, log in to [Neutrinos Console](https://console.neutrinos.co/). Navigate to the **apps** section and select your app card and view build status updates.
    ![Weather app deployed](/resources/Storage/psd-tutorial-publication/weather_deployed.png)
7. The app deployment process involves multiple steps that require a couple of minutes to complete. You can view individual step status in the app build details section.
    ![Weather app build status](/resources/Storage/psd-tutorial-publication/weather_build.png)
8. When your app build has been completed successfully, the build status is updated to **Success**.

| ![Information](/resources/Storage/psd-tutorial-publication/project-tutorial-weather-app/info.png) | In the case of Build Failure, download the build logs and check for app errors.    If you face any connectivity issues during the deployment steps, use the** Re-deploy **option on the app card to re-schedule a build for deployment.    You can also use the **Deploy app** option on Studio to redeploy app changes onto the cloud. |
| --- | --- |

**Preview the App**

After the build is successful, click![Portal icon](/resources/Storage/psd-tutorial-publication/project-tutorial-weather-app/portal_icon.png) to launch the web app or click the **Android/iOS** icon to download the respective builds of the app.
