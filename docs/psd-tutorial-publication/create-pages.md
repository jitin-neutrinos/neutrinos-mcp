### Overview for Weather App Pages

For the weather app, you will be creating the following [pages](/smart/project-concepts/page):

- **log**: To display the log of the weather search.
- **weathercard**: To display the weather of the city that the user has entered.
- **weathersearch**: To display a search field to enter the name of the city.

**Creating Pages**

1. To create a page, click the **Pages **menu from the editor pane.
2. Click the **Add page** icon in the page explorer and enter the name of the page. For example, **log.**
    ![](/resources/Storage/psd-tutorial-publication/title-2021-08-25.png)
3. Press **enter **and the page gets added.

Similarly, create the other two pages:

- **weathercard**
- **weathersearch**
