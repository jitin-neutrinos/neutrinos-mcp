# bh.system.dataModelService

<https://documentation.neutrinos.com/articles/#!client-services-designer-8/system-datamodelservice>

bh.system.dataModelService provides readily available observable methods that integrate with Neutrinos Art data model APIs if the application is migrated from previous versions of Studio which used Neutrinos Art. These observable methods can be used on the frontend to validate and persist instances of data models.
