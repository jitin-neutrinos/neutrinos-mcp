# How to use

<https://documentation.neutrinos.com/articles/#!client-services-designer-8/comments-node>

**Comments node** is used to write a description or comment for the client service flows.

### How to use

- Open the Services editor window.
- Click the** Plus **icon to add a new client-service or open an existing service in the service list.
- From the Nodes Palette, drag and drop a **Comment** node to the workspace.
- Drag and drop other nodes to create a flow. Make sure the flow starts with a **Start** node.
- After the flow is created, import the service to an application page. See [Import a service](/articles/service-designer-user-s-guide/service-designer-variables/a/h3_519852009) to learn more.

### Associated Attributes

- **Name**: The name for the comment node. This name will appear on the canvas when you save the node.
- **Comments Editor**: The rich text editor where you can add comments for the client service flows that you create. From the rich text editor you can use these properties:
  - **Show Heading**: To show the Heading drop-down option on the top of the editor.
  - **Show Bold**: To show the Bold option on the top of the editor.
  - **Show Italic**: To show the Italic option on the top of the editor.
  - **Show Undo**:To show the Undo option on the top of the editor.
  - **Show Redo**: To show the Redo option on the top of the editor.
  - **Show Paragraph**: To show the Paragraph option on the top of the editor.
  - **Show Bullet List:** To show the Bullet List option on the top of the editor.
  - **Show Number List:** To show the Number List option on the top of the editor.
  - **Show Block Quote**: To show the Block Quote option on the top of the editor.
  - **Show Link**: To show the Link option on the top of the editor.
  - **Show Uploading Image**: To show the Uploading Image icon on the top of the editor.
  - **Show Insert Table:** To show the Insert Table icon on the top of the editor.
