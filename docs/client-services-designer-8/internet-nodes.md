# Internet

<https://documentation.neutrinos.com/articles/#!client-services-designer-8/internet-nodes>

The **Internet** nodes are used to check the browser's access to the Internet. It comprises three nodes:

- [Is Online](/articles/client-services-designer-8/is-online-node)
- [On Online](/articles/client-services-designer-8/on-online-node)
- [On Offline](/articles/client-services-designer-8/on-offline-node)
