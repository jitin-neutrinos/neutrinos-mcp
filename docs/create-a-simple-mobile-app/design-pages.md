# Attributes Window

<https://documentation.neutrinos.com/articles/#!create-a-simple-mobile-app/design-pages>

To design a page, click the **Pages **option, and select the page that you want to design. The Page Designer for the selected page opens up. It comprises of:

- The palette list from where you can drag [components](/smart/project-concepts/component) such as a **Row**, **Table**, etc. to design the page
- The container which contains the dropped components
- On double-click of the component, the Attributes window of that component opens up to configure the behavior of that component.

Some components, such as rows and columns, have droppable regions. This means that you can add other components within these components. To design a page, drag components from the **Palette List** and drop the components in the **Page ****Container.**

### Attributes Window

Using the Attributes window, you can edit the default properties of a component that are auto-populated for you. In addition, you can also add custom properties for a component as per your requirement.

To add a custom property, go to the attributes window, scroll down and expand the Custom Properties drop-down list. You can define a key-value pair or an attribute. By default, **Attribute** is selected.

To create a custom **Attribute **property, you enter the key data. The Studio auto-completes the value data. However, for a custom **Key/Value** property, enter the key as well as the data value. Click **ADD** to add the custom property.

| **Component** | **What you need to Enter** |
| --- | --- |
| Attribute | Enter the Key Data |
| Key/Value | Enter the key and data value |
