# Create client services

<https://documentation.neutrinos.com/articles/#!create-a-simple-mobile-app/create-client-services>

You design client services by using the [Client Services Designer](/smart/project-concepts/client-services-designer).

To create Client services, perform the following steps:

1. On the left pane, click **Services** in the menu options and select **Client**.
    ![client service](/resources/Storage/create-a-simple-mobile-app/service-designer-user-s-guide/weather%20client.png)
2. The Client Services Designer opens up. Click the ![](/resources/Storage/create-a-simple-mobile-app/project-tutorial-weather-app/add.png) icon to add a new Client Service. Enter **location** in the popup window and click **Add**.

![create new client service](/resources/Storage/create-a-simple-mobile-app/service-designer-user-s-guide/newclientservice.png)

Similarly, create these other services:

- [usermanagement](/articles/create-a-simple-mobile-app/user-management-server)
- [weather](/articles/create-a-simple-mobile-app/weather-server)
- [ocr](/articles/create-a-simple-mobile-app/ocr)
