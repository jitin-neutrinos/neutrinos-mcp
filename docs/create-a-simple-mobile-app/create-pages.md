# Create Pages

<https://documentation.neutrinos.com/articles/#!create-a-simple-mobile-app/create-pages>

On the Neutrinos Platform, each **[Page](/smart/project-concepts/page)** is an application view. When you create an app on Neutrinos using a [template](/smart/project-concepts/app-templates), some pages get generated by default. These pages are called **default pages**.

For this app, you will be creating the following pages:

- **Home**: This page is the homepage for the app.
- **CaptureInfo**: This page captures information from the scanned PAN card which scans the First Name, Last Name, Date of Birth, and PAN number.
- **Greetings**: This page displays the current weather based on the geolocation with respect to the latitudinal and longitudinal coordinates.
- **UsersList**: This page displays the list of users whose PAN card details are scanned and saved in the database.

**Creating Pages**

1. To create a page, click the **Add New** icon and click the **P****age **option.

![Create Pages](/resources/Storage/create-a-simple-mobile-app/newpage.png)

2. In the Enter Page Name dialog box, enter the name of the page. For Example, enter **home**.

![Page Details(NAME)](/resources/Storage/create-a-simple-mobile-app/pageadding.png)

3. Click **Create Page. **

4. The home page is created successfully.

Similarly, create the following pages:

- **CaptureInfo**
- **Greetings**
- **UsersList**
