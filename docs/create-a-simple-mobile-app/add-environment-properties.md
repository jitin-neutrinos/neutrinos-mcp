# Add Environment Properties

<https://documentation.neutrinos.com/articles/#!create-a-simple-mobile-app/add-environment-properties>

Click [Environments](/smart/project-concepts/environment) on the menu list. The Environment editor opens up.

### 

You will be adding the following properties to the existing environments:

| **Property name and value** | **Client** | **Server** |
| --- | --- | --- |
| **ssdUR**L - https://bs-2406403.el.r.appspot.com/api/ | True | False |
| **apiid**-6076e953046196d0c851e53173393c0d | False | True |
| **weatherProviderURL** - https://api.openweathermap.org/data/2.5/weather | False | True |

Update the **ssdURL** value with the URL mentioned above in the table.

Add the **apiid** property and its value. Select **Server** and click **Add**.

Similarly, add the **weatherProviderURL** as a **server **property.

After adding, both the properties should be visible in the editor.
