# Build apk file

<https://documentation.neutrinos.com/articles/#!create-a-simple-mobile-app/build-apk-file>

After the initialization of the app, you build a **.apk** file to test the application on your mobile to see if the application is working fine.

To build a .apk file, perform the following:

1. Select **Android Build **from the task drop-down list and run the task.
    ![Information](/resources/Storage/create-a-simple-mobile-app/info.png)
    You can do an IOS build only if you have a paid subscription.
2. After the build is complete, the .apk file will be saved to your local machine. The path where the .apk file is saved will be displayed on the terminal.
3. Transfer the .apk file to your android or ios mobile device and install it.
4. After installing you can launch the app and see how it works.

![Information](/resources/Storage/create-a-simple-mobile-app/info.png)


 Make sure you have all the dependencies installed for the Android build to work properly. See [Install required Softwares](/articles/app-builder-s-user-guide/before-you-begin) to view the dependencies to be installed.
