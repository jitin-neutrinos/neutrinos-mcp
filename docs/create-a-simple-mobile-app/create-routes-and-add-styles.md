**Configuring Routes**

To create and configure a route, click the **Route** icon.

![Add routes](/resources/Storage/create-a-simple-mobile-app/hdfcroutes.png)

**Routes for this app**

Configure the routes in this fashion. The Home page is the first page that gets loaded when the app is launched. All other [pages](/smart/project-concepts/page) are sub-routes of the **Home** page. Use the ![](/resources/Storage/create-a-simple-mobile-app/routes__sub.png) icon to add sub-routes.
