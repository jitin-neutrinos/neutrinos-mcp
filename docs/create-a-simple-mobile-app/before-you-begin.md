If you do not have a Neutrinos account, perform the following steps before you get started with this tutorial:

1. [Read the Free Trial Terms](/articles/build-an-app-on-neutrinos-platform/before-you-begin/a/h3_1650184974)
2. [Install the Required Software](/articles/build-an-app-on-neutrinos-platform/before-you-begin/a/h3_1896459764)
3. [Signup with Neutrinos](/articles/build-an-app-on-neutrinos-platform/sign-up)
4. [Install Neutrinos Studio](/articles/build-an-app-on-neutrinos-platform/install-neutrinos-studio)
5. [Install MongoDB Database](https://docs.mongodb.com/manual/installation/#tutorial-installation) - Required to perform user management in this app.
