# Create the App

<https://documentation.neutrinos.com/articles/#!create-a-simple-mobile-app/create-the-app>

To create the TestApp on Neutrinos Studio, perform the following steps:

1. Launch [Neutrinos Studio](/smart/project-concepts/studio) and log in with your credentials.
    ![the classic app image](/resources/Storage/create-a-simple-mobile-app/classic%20app.png)
2. On the [Studio homepage](/smart/project-concepts/studio-home-page), click the **Create New App** icon.
3. On the Enter App Details, enter the following metadata for the app.
  - **App Name**: Enter the relevant application name. For example, **TestApp** or **MobileApp**.
  - **Add a preview image for your app**: Insert any image for your app. This is an optional step.
  - **Version: **Displays the version of your app.
  - **Tenant**: Enter the tenant name provided by the Neutrinos administrator. By default, the tenant name is **neutrinos**.
  - **Description**: Enter a description. For example, **To integrate with database and work with native mobile plugins**.

| ![Information](/resources/Storage/create-a-simple-mobile-app/info.png) | By default, the **blank** template is selected when creating an app. You can click the **+** icon and navigate to **[Neutrinos Store](/smart/project-concepts/neutrinos-store)** to download prebuilt, readily available templates for your app. |
| --- | --- |

Click** Create **and the app gets created.

![Creating the mobile app](/resources/Storage/create-a-simple-mobile-app/mobile%20create.png)

Click the created app. The [Studio Application page](/smart/project-concepts/studio-application-page) opens up for you to start designing your app.
