Build a Simple Mobile App in Studio 7


 ![](/resources/Storage/create-a-simple-mobile-app/mobile%20learning%20path.png)





 In this learning path, you will be building an Android app to learn how to:


 Use the native capabilities of the mobile


 Integrate with the MongoDB database


 Consume an external API



 At the end of this tutorial, the app that you build will look like this:

 ![APp screens](/resources/Storage/create-a-simple-mobile-app/pages.png)

 The **Home** screen uses your mobile's GPS to detect your location and displays the weather information of your city. You touch the **Scan** icon to open your Mobile's camera and scan the PAN card. After you scan the card, the details of the PAN card are read by the app using the Optical Character Recognition(OCR) plugin and are displayed to you on the **User Details** page. You can make changes if any and then click the **Submit **button to save your details. Once saved, the user details are displayed on the **Users List **page.
