# Create server services

<https://documentation.neutrinos.com/articles/#!create-a-simple-mobile-app/create-server-services>

You design server services by using the [Server Services Designer](/smart/project-concepts/server-services-designer).

To create server services, perform the following:

1. Click** Services** on the Menu list and select **Server**.
2. The **Server Services Designer** opens up. Click the plus icon to add a new server service. Enter **weather** and click** Add**.

Similarly, create the usermanagement service.
