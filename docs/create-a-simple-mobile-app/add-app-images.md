# Add App images and icons

<https://documentation.neutrinos.com/articles/#!create-a-simple-mobile-app/add-app-images>

Any images that you want to use in the frontend application should be uploaded to the [Assets editor](/smart/project-sample-how-to-guide/add-assets). You can upload images by using the drag and drop feature in the editor.

For this app, we will be using these images. Download the images to your local machine.

![](/resources/Storage/create-a-simple-mobile-app/clouds.jpg)

**neutrinoslogo.jpg**

**![](/resources/Storage/create-a-simple-mobile-app/neutrinoslogo.jpg)
**

Open the Assets editor by clicking **Assets** on the Menu list. Navigate to the** Web/Icons** folder and upload these images by clicking on the **Upload** button.
