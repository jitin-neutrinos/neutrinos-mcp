# Exporting a Product

<https://documentation.neutrinos.com/articles/#!reels-publication/exporting-a-product>

The Reels platform enables users to export an existing product.

To export a product:

1. In the Product list page, select the checkbox corresponding to a product.
   ![](/resources/Storage/reels-publication/versioning/checkbox.png)
   An export icon is displayed within the product list page.
   ![](/resources/Storage/reels-publication/versioning/Delete%26expo.png)
2. Click on the ![](/resources/Storage/reels-publication/versioning/exporticon.png) icon to export a product.
   The Export Products pop-up window is displayed.
   ![](/resources/Storage/reels-publication/versioning/ExportProducts.png)
3. Select the version from the drop-down list.
   To export all the versions, select all.
4. Click Export to complete the export process.
   The exported product will be downloaded in json format.
