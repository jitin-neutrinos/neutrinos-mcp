# Use Case

<https://documentation.neutrinos.com/articles/#!reels-publication/date-plus>

Date Plus operator provides the capability of adding a certain time duration to a date. This feature is used to define and enforce business rules in various applications, and they may include functions or operators for working within specified dates and times.

#### Use Case

- A customer purchases an auto insurance policy for their vehicle. The insurance system records the policy details (start date, coverage details and policy duration (e.g., one year).

Using the "date plus" functionality, the system calculates the policy's expiration date by adding one year to the policy start date. For instance, if the policy starts on January 1, the expiration date would be January 1 of the following year.

Considering the above use case as an example, follow the steps given below to use the Date Plus operator within Formula:

1. Select the Rule Type as Formula > click on the Rules data.
   The Formula pop-up window is displayed.
   ![](/resources/Storage/reels-publication/date-plus/Dateplus_1.png)
2. Select the operator as DatePlus and click on it.
   The DatePlus config pop-up is displayed.
   ![](/resources/Storage/reels-publication/date-plus/Timedate_plus.png)
    ![](/resources/Storage/reels-publication/noteicon.png)
    Once the Date Plus operator is selected, the other operators will be automatically disabled.
3. To select a custom date as input, click on the checkbox below the input field and enter date in dd/mm/yy format.
   or
   Select a date/time from the date picker.
   ![](/resources/Storage/reels-publication/date-plus/Date_picker.png)
4. Enter Interval within the interval field.
5. Enter the Addition Unit as per requirement. The values can be entered by selecting from the drop-down list.
   ![](/resources/Storage/reels-publication/date-plus/additionunit.png)
6. Click Save to save the formula.
