# Accessing the Reels Platform

<https://documentation.neutrinos.com/articles/#!reels-publication/access-reels-platform>

## Accessing the Reels Platform

1. Click on [Reels URL](https://ids.neutrinos.co/interaction/fIpeT3YVQZM4LEh99vLlR) link to go to the login page.
   ![](/resources/Storage/reels-publication/access-reels-platform/Reels_Login.png)
2. Login using valid credentials.
   Or
   Sign In with Google credentials.
3. Once logged in, you will be redirected to the Dashboard page.
   ![](/resources/Storage/reels-publication/access-reels-platform/Landing%20Page.png)

If you need help to access reels platform, send an email to [Neutrinos Support](mailto:support@neutrinos.co).
