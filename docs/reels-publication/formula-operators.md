# Formula Operators

<https://documentation.neutrinos.com/articles/#!reels-publication/formula-operators>

Use these operators and functions when building formulas. All functions are available everywhere that you can include a formula.

| Icon | Operator | Description |
| --- | --- | --- |
| ![](/resources/Storage/reels-publication/formula-operators/addition.png) | Add | Calculates the sum of two values. |
| ![](/resources/Storage/reels-publication/formula-operators/subtr.png) | Subtract | Calculates the difference of two values. |
| ![](/resources/Storage/reels-publication/formula-operators/multip.png) | Multiply | Multiplies its values. |
| ![](/resources/Storage/reels-publication/formula-operators/div.png) | Divide | Divides its values. |
| ![](/resources/Storage/reels-publication/formula-operators/perc.png) | Percentage | Calculates the percentage. |
| ![](/resources/Storage/reels-publication/formula-operators/paranth.png) | Open and Closed Parenthesis | Specifies that the expressions within the open parenthesis and close parenthesis are evaluated first. All other expressions are evaluated using standard operator precedence. |
| ![](/resources/Storage/reels-publication/formula-operators/expon.png) | Exponentiation | Raises a number to the power of a specified number. |
| ![](/resources/Storage/reels-publication/formula-operators/dateplus.png) | Date Plus | Allows you to add a specific time interval (days, months, weeks). |
| ![](/resources/Storage/reels-publication/formula-operators/dategap.png) | Date Gap | Allows you to add a specific day interval. |
