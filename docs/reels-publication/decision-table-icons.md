# Decision Table Icons

<https://documentation.neutrinos.com/articles/#!reels-publication/decision-table-icons>

Users can perform various tasks within the Decision Table Config screen using the icons. The description for each icon is provided in the following table:

| Icon | Action | Description |
| --- | --- | --- |
| ![](/resources/Storage/reels-publication/product-info/toggle.png) | Toggle button | enables you to freeze an entire row within a decision table. |
| ![](/resources/Storage/reels-publication/new-topic-4/Copy_icon.png) | Clone a row | Clicking on this will clone the selected row. |
| ![](/resources/Storage/reels-publication/product-info/Addnew.png) | Add a new row | Click to add a new row. |
| ![](/resources/Storage/reels-publication/product-info/todelete.png) | Delete a row | Click to delete a row. |
| ![](/resources/Storage/reels-publication/decision-table-icons/anything.png) | View and add operators | Click to view and add operators. |
