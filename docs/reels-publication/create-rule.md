# Create Rule

<https://documentation.neutrinos.com/articles/#!reels-publication/create-rule>

The create rule operation defines the type of rule that will be used to create the rule. The four types of Rules are:

- [Decision Table](/articles/reels-publication/decision-table)
- [Excel File](/articles/reels-publication/excel-file)
- [Formula](/articles/reels-publication/formula)
- [Master Data](/articles/reels-publication/product-constants) (upload conventional spreadsheet files)
