# Rule Grouping

<https://documentation.neutrinos.com/articles/#!reels-publication/rule-grouping>

The Rule grouping feature within the Reels platform is utilized for selecting a set of rules and publishing them to be accessed by other users. Once published, these rules become available for use by other users, promoting a streamlined and standardized approach to rule management within the system.

**To Combine rules and Publish them within a rule group**

1. Create a product with more than one rule flow.
   ![](/resources/Storage/reels-publication/rule-grouping/morethan.png)
2. Select the rules(hold ctrl and click on the rule) along with the connection link.
   The number of selected rules and links are displayed.
   ![](/resources/Storage/reels-publication/rule-grouping/Selectedrules.png)
3. Click on the Publish Rule Group button.
   The Rule Group pop-up window is displayed.
   ![](/resources/Storage/reels-publication/rule-grouping/Rulegroupwindow.png)
4. Enter the Rule name and Summary.
5. View and confirm that the following information is displayed:
   - Input and Output fields.
   - Product Constants (if they are used within the selected rules).
6. Click Save.
   A confirmation message indicating that the rule group has been published is displayed.
7. Verify that the published rule group is displayed within the rule list page.
   ![](/resources/Storage/reels-publication/rule-grouping/combined.png)
8. Click and view the details related to the published rule group.
   ![](/resources/Storage/reels-publication/rule-grouping/publishedrulegroup.png)
