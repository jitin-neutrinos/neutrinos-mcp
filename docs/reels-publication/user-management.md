# Teams

<https://documentation.neutrinos.com/articles/#!reels-publication/user-management>

The user management page allows you to add teams, users and manage users. You must be logged in as an Administrator to add, delete, or modify a user.

To add a user:

1. Login to Reels platform and click on User Management link.
   The User Management screen is displayed.
2. Click on Add User.
   ![](/resources/Storage/reels-publication/user-management/Add%20user.png)
   The new User pop-up window is displayed.
   ![](/resources/Storage/reels-publication/user-management/New%20user.png)
3. Enter the following details:
   - First Name
   - Last Name
   - Display Name
   - Email address
   - Contact Number
4. Click Submit to create a new user.

#### Teams

To Create a Team:

1. Login to Reels platform and click on User Management link.
   The User Management screen is displayed.
2. Click on Create Team.
   ![](/resources/Storage/reels-publication/user-management/Create%20Team.png)
   The new Team pop-up window is displayed.
   ![](/resources/Storage/reels-publication/user-management/newteam.png)
3. Enter the following details:
   - Name
   - Users
4. Click Submit to create a new team.
