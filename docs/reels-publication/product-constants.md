# Add a Product using Master Data

<https://documentation.neutrinos.com/articles/#!reels-publication/product-constants>

The Master Data link allows you to maintain and upload conventional spreadsheet files for the representation of business rules. This ensures uniformity, accuracy and accountability of the shared master data assets.

![](/resources/Storage/reels-publication/prod-const/New%20Masterdata.png)

### 

### Add a Product using Master Data

1. Navigate to Rule Management > Master Data.
2. Click on the Master Data tab.
   ![](/resources/Storage/reels-publication/prod-const/RMasterdata.png)
3. The New Master Data pop-up window is displayed.
   ![](/resources/Storage/reels-publication/prod-const/New%20Masterdata.png)
4. Browse and upload the Excel File.
   A sample Master data file is provided below for reference.
   [Sample Master Data](/resources/Storage/reels-publication/master%20test.xlsx)
5. Enter the Master Data Name and click Save.
   Note: The Columns specified within the master data spreadsheet is displayed within the pop-up window.
6. The uploaded Master data is now displayed within the Rule Management > Rule list page.
   ![](/resources/Storage/reels-publication/prod-const/listpage.png)
7. Navigate to Product list and select a product.
8. Edit a product and click on Rules flow tab.
9. Click on Import rule.
10. The list of master data files are displayed within the Import Rule list view.
   ![](/resources/Storage/reels-publication/prod-const/rulelistview.png)
11. Click on the ![](/resources/Storage/reels-publication/prod-const/Addnew.png) icon to add a master data.
12. Configure and save the rule.
13. After saving the rule config, click on Data Mapping and configure the Input.
   ![](/resources/Storage/reels-publication/prod-const/InputDataMapper.png)
14. Click Save.
15. The edit product screen is displayed.
16. View the product info details and ensure that the details are accurate.
17. Click on the Deploy toggle button and deploy your product.
   ![](/resources/Storage/reels-publication/prod-const/Deploy.png)
18. Navigate to Sandbox and validate the configured output.
