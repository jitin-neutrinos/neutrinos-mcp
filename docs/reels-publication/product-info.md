# Product Info

<https://documentation.neutrinos.com/articles/#!reels-publication/product-info>

The Product info screen is one location where you can add product info, monitor, and manage the deployed projects.

The page is separated into three sections. The first section provides information details (version number, deployment status, created and updated date) .

The second section provides deployment details(deployment id, token and URL) ,hyperlink to sandbox and Download swagger. The third section contains information related to the available fields and input values. The information within the third section will be displayed only after configuring the product.
