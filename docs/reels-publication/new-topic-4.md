# Icons Description

<https://documentation.neutrinos.com/articles/#!reels-publication/new-topic-4>

Users can navigate, modify, and personalize information related to a product using the action icons. The description for each icon is provided in the following table.

| Icon | Action | Description |
| --- | --- | --- |
| ![](/resources/Storage/reels-publication/new-topic-4/Edit_Icon.png) | Edit information | Allows you to edit information related to a product. Clicking on this will navigate to the Edit Product page. |
| ![](/resources/Storage/reels-publication/new-topic-4/Delete_icon.png) | Delete a Product | Enables you to delete a product. |
| ![](/resources/Storage/reels-publication/new-topic-4/Copy_icon.png) | Copy a Product | Clicking on this will copy the selected product. |
| ![](/resources/Storage/reels-publication/new-topic-4/enable.png) | View Product version | Clicking on this will display all the product versions. |
