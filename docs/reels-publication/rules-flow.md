# Rules Flow

<https://documentation.neutrinos.com/articles/#!reels-publication/rules-flow>

Using Rules Flow, you can manage the flow of rule execution. It involves the creation of rule flows and incorporation of various elements to regulate the execution of rules.

A ruleflow, arranges rules into a sequence of decisions by assembling them as a series of rule tasks, operating within a predetermined execution pattern. Each rule task is assessed to generate a decision or result. These individual decisions collectively culminate in a singular business decision, which is represented by the ruleflow.

Using the rules flow tab, you can:

- Create Rule
- Import Rule
