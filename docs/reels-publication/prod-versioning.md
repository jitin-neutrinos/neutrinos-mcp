# Product Versioning

<https://documentation.neutrinos.com/articles/#!reels-publication/prod-versioning>

What if you have an existing product in place that you know will need to change on a specific date? You can’t make that change now because the current one is working the way it’s supposed to work. And you really don’t want to wait until the eleventh hour to modify it. This is where versioning can save the day.Within the reels platform, you can select any product and create a version of it now so that it’s tested, verified and ready to be executed on the required date.

**How to Use Product Versioning**

1. Create a Product ( Refer to steps provided in
2. Navigate to Product list page and click on the ![](/resources/Storage/reels-publication/versioning/enable.png) icon corresponding to a product.
   ![](/resources/Storage/reels-publication/versioning/versioning.png)
   The version details is displayed.
   ![](/resources/Storage/reels-publication/versioning/versiondetails.png)
   **Note: **By default, the latest version of the product is displayed within the product list.
3. Click on the ![](/resources/Storage/reels-publication/versioning/elipsis.png) icon within the product version section.
   The edit product screen is displayed.
4. Make the required changes and click Save.
   A pop-up is displayed to confirm if you want to overwrite the current version or save as a new version.
   ![](/resources/Storage/reels-publication/versioning/prodversion.png)
5. Select the appropriate button.
6. The version number will be updated based on your selection.
