# Add a Product

<https://documentation.neutrinos.com/articles/#!reels-publication/adding-a-product>

You can view the Add Product page by navigating to *Products* > *Add Product*. The Add Product page displays three tabs which can be used to add a product and design rules flow. The available tabs are:

- [Product Info](/articles/reels-publication/product-info) - Use this tab to name your product and view product info details.
- [Rules Flow](/articles/reels-publication/rules-flow) - Use this tab to create/import rules.
- [Product Constants](/articles/project-reels/prod-const) - Use this product to add and configure constants.
