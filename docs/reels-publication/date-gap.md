# Use Case

<https://documentation.neutrinos.com/articles/#!reels-publication/date-gap>

Date Gap operator provides the capability of adding a certain time duration to a date. This feature is often used to define and enforce business rules in various applications, and they may include functions or operators for working within specified dates and times.

#### Use Case

A user enrolls in a health insurance plan, and the insurance system records policy details. If the policy is renewed after the expiration date, a potential gap between old and new policy is addressed using the "date gap" functionality.

Considering the above use case as an example, follow the steps given below to use the Date Gap operator within Formula:

To use the Date Gap operator within Formula:

1. Add a Product.
2. Select the Rule Type as Formula > click on the Rules data.
3. Select the operator as DateGap and click on it.
4. The DateGap config pop-up is displayed.
   ![](/resources/Storage/reels-publication/date-plus/Dategap_1.png)
5. To select a custom date as input, click on the checkbox below the input field and enter date in dd/mm/yy format.
   or
   Select a date/time from the date picker.
   ![](/resources/Storage/reels-publication/date-plus/Dategap_picker.png)
6. Enter the Gap Unit as per requirement. The values can be entered by selecting from the drop-down list.
   ![](/resources/Storage/reels-publication/date-plus/Gapunit_value.png)
7. Click Save to save the formula.
