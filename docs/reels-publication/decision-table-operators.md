# Decision Table Operators

<https://documentation.neutrinos.com/articles/#!reels-publication/decision-table-operators>

Every condition in the decision table can have a different operator. The available operators are:

![](/resources/Storage/reels-publication/product-info/Operators.png)

![](/resources/Storage/reels-publication/product-info/DateOperators.png)

![](/resources/Storage/reels-publication/product-list/Fnoperators.png)

Use these operators and functions when using decision tables.

**Basic**

| Icon | Operator | Description |
| --- | --- | --- |
| ![](/resources/Storage/reels-publication/decision-table-operators/Equals.png) | Equals to | Compares two operands and returns a value indicating whether they are equal. |
| ![](/resources/Storage/reels-publication/decision-table-operators/Isin.png) | IS IN | True if input value is in set. Members of the set can be separated by (pipe)\|, (semicolon); or (comma),. |
| ![](/resources/Storage/reels-publication/decision-table-icons/anything.png) | Any value can be added | No Validation. |
| ![](/resources/Storage/reels-publication/decision-table-icons/Notin.png) | NOT IN | True if input value is NOT IN set. Members of the set can be separated by (pipe)\|, (semicolon); or (comma),. |
| ![](/resources/Storage/reels-publication/decision-table-operators/Greatthan.png) | Greater Than | The greater than (>) operator returns true if the left operand is greater than the right operand, and false otherwise. |
| ![](/resources/Storage/reels-publication/decision-table-operators/greathanoreq.png) | Greater Than or Equal to | The greater than or equal (>=) operator returns true if the left operand is greater than or equal to the right operand, and false otherwise. |
| ![](/resources/Storage/reels-publication/decision-table-operators/lesserthan.png) | Lesser Than | The lesser than (<) operator returns true if the left operand is less than the right operand, and false otherwise. |
| ![](/resources/Storage/reels-publication/decision-table-operators/lessthanoreq.png) | Lesser Than or Equal to | The lesser than or equal (<=) operator returns true if the left operand is less than or equal to the right operand, and false otherwise. |
| ![](/resources/Storage/reels-publication/decision-table-operators/notequals.png) | Not Equals to | Compares two operands and returns true if they are not equal, and false if they are equal. |
| ![](/resources/Storage/reels-publication/decision-table-operators/between.png) | Between | Used to select values within a specified range. |
| ![](/resources/Storage/reels-publication/decision-table-operators/notbetween.png) | Not Between | Used to select values that are not within a specified range. |

**Dates**

| Icon | Operator | Description |
| --- | --- | --- |
| ![](/resources/Storage/reels-publication/decision-table-operators/Equals.png) | Equals to | True if input date is equals. Date format should be dd/mm/yy or valid ISO format. |
| ![](/resources/Storage/reels-publication/decision-table-operators/notequals.png) | Not Equals to | True if input date is not equal to. Date format should be dd/mm/yy or valid ISO format. |
| ![](/resources/Storage/reels-publication/decision-table-operators/Greatthan.png) | Greater Than | True if input date is Greater Than. Date format should be dd/mm/yy or valid ISO format. |
| ![](/resources/Storage/reels-publication/decision-table-operators/greathanoreq.png) | Greater Than or Equal to | True if input date is Greater Than or Equal to. Date format should be dd/mm/yy or valid ISO format. |
| ![](/resources/Storage/reels-publication/decision-table-operators/lesserthan.png) | Lesser Than | True if input date is Lesser Than. Date format should be dd/mm/yy or valid ISO format. |
| ![](/resources/Storage/reels-publication/decision-table-operators/lessthanoreq.png) | Lesser Than or Equal to | True if input date is Lesser Than or Equal to. Date format should be dd/mm/yy or valid ISO format. |
| ![](/resources/Storage/reels-publication/decision-table-operators/between.png) | Between | True if input date is Between the specified dates. Date format should be dd/mm/yy or valid ISO format. Members of the set can be separated by (pipe)\|, (semicolon); or (comma),. |
| ![](/resources/Storage/reels-publication/decision-table-operators/notbetween.png) | Not Between | True if input date is Not Between the specified dates. Date format should be dd/mm/yy or valid ISO format. Members of the set can be separated by (pipe)\|, (semicolon); or (comma),. |

**Functional Operators**

| Icon | Operator | Description |
| --- | --- | --- |
| ![](/resources/Storage/reels-publication/product-list/sum.png) | Sum | Sum of all the entered operands. Members of the set can be separated by (pipe)\|, (semicolon); or (comma),. |
| ![](/resources/Storage/reels-publication/decision-table-operators/mul.png) | Multiply | Multiplication of all the entered operands. Members of the set can be separated by (pipe)\|, (semicolon); or (comma),. |
