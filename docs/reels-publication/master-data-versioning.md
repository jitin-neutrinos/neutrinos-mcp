# Master Data Versioning

<https://documentation.neutrinos.com/articles/#!reels-publication/master-data-versioning>

Master Data versioning ensures that, a unique identifier is assigned to each versions of the master data to track changes and maintain compatibility. This ensures that the latest data is uploaded and a record or history of changes made over time is maintained.

To view different master data versions:

1. Navigate to Rule management > Rule list page.
   ![](/resources/Storage/reels-publication/product-constants/Masterdata_versioning.png)
2. click on the ![](/resources/Storage/reels-publication/versioning/enable.png) icon corresponding to a rule list.
   The version details is displayed.
   ![](/resources/Storage/reels-publication/product-constants/vnumber.png)
