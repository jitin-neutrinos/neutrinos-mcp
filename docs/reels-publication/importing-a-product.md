# Importing a Product

<https://documentation.neutrinos.com/articles/#!reels-publication/importing-a-product>

The Reels platform enables users to import a product in json format.

**Before you Begin**

- If you are importing a product for the first time, check if the json format is correct.
- Ensure that the file size does not exceed the set limit(5mb).

To import a product:

1. In the Product list page, click on the import button.
   ![](/resources/Storage/reels-publication/importing-a-product/Import.png)
   An import pop-up window is displayed.
2. Click browse file to import a product.
   ![](/resources/Storage/reels-publication/importing-a-product/Browse.png)
3. Select the file containing the product.
4. Click Import to complete the import process.
   The imported product will be displayed within the product list page.
   ![](/resources/Storage/reels-publication/importing-a-product/Pending.png)
