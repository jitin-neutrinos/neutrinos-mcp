# Integrate Content Repository

<https://documentation.neutrinos.com/articles/#!neutrinos-reels-publication/integrate-content-repository>

The Content Repository serves as a centralized repository for creating templates that act as blueprints for content used in broadcasts or emails. Its services can be accessed either through the user interface, as described in the Content Repository topic, or programmatically via the Content Repository APIs. For more information about the Content Repository UI options, refer to the [Content Repository](/articles/neutrinos-reels-publication/content-repository) topic.

The services provided by the Content Repository are categorized into three main types: Schemas, Records, and Handlebars, each offering a distinct set of functionalities.
