# Navigating Interface

<https://documentation.neutrinos.com/articles/#!neutrinos-reels-publication/navigating-interface>

This topic provides details on navigating the Reels platform interface. The platform comprises four key components: Rules, Rule Groups, Workflows, and Master Data. Each plays an important role in automating complex decision-making and managing data effectively. After logging into the Reels platform, users see a dashboard displaying its core components' statistics. Key statistics related to workflows, rules, rule groups, master data, and other relevant information are presented through visual representations. The left-side navigation bar provides access to various sections of the platform's features. The image below provides an overview of the Reels platform dashboard and navigation bar.

![](/resources/Storage/neutrinos-reels-publication/images/reels-navigation-panel1.png)

The navigation bar includes the following sections: **Dashboard, Rules, Workflows, Master Data, Tokens, and Logs.**

1. **Dashboard**: The dashboard provides a summary of workflows, rules, rule groups, and master data created by the user. It also displays execution statistics for Rules, Rule Groups, and Workflows over a specific period. Additionally, it shows user sign-ups within a given timeframe, along with overall platform statistics and execution summaries.
2. **Rules**: This section allows you to create and manage rules. You can:
  - Create new rules or rule groups.
  - Delete existing rules.
  - Edit a rule by clicking on the rule itself.
  - Search for rules using the search bar.
3. **Workflow**: This section allows you to create, manage, and monitor workflows. You can:
  - Create a new workflow.
  - Edit, clone, or delete a workflow.
  - View different workflow versions by clicking the expansion button on the right-hand side of the row.
  - Search for workflows using the search bar.
  - Import or export workflows.
  - Select and delete either a single or multiple workflows.
4. **Master Data**: This section enables you to manage the master data used by workflows and rules. You can:
  - Create new master data.
  - Edit existing master data.
  - Delete the master data.
  - View different versions of the master data.
  - Search for the master data using the search bar.
5. **Tokens**: This section allows you to manage the tokens required for executing or testing APIs. You can:
  - Generate tokens by specifying an expiration time for each created token.
6. **Logs**: This section allows you to view and audit logs, including **Activity Logs**, **Audit Logs**, and **Rule Execution Logs**.
  - **Activity**: Displays the login times of individual users.
  - **Audit**: Displays the types of rules created by each user.
  - **Rules Execution**: Displays the different rules executed by each user.
