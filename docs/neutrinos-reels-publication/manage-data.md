# Add Record

<https://documentation.neutrinos.com/articles/#!neutrinos-reels-publication/manage-data>

This topic explains how to add, update, filter records, and download the Master Data file.

## Add Record

To add record to the Master Data file, follow the steps below:

1. Click **Master Data** in the navigation bar to open the **Master Data** details page.
2. Click and select the Master Data file you created.
    ![master-data-details-selection](/resources/Storage/neutrinos-reels-publication/images/master-data-details-page-select.png)
3. Click the '**Add Records**' button in the top right of the Master Data file details page.
4. In the pop-up window, enter data in all fields (columns) of the Master Data file.
5. Click **Add** to save the new data to the file.

The GIF below illustrates how to add a new row to the Master Data file:

![master-data-add-data](/resources/Storage/neutrinos-reels-publication/images/master-data-add-data.gif)

## Update Record

To update the record in the Master Data file, follow the steps below:

1. Click **Master Data** in the navigation bar to open the **Master Data** details page.
2. Click and select the Master Data file you created.
    ![master-data-details-selection](/resources/Storage/neutrinos-reels-publication/images/master-data-details-page-select.png)
3. Navigate to the **Actions** column, and click the kebab icon for the row you want to update.
4. After updating the information in the row, click the **Save** button at the end of the row to apply the changes.

The GIF below illustrates how to update a row in the Master Data file:




 ![master-data-update-information](/resources/Storage/neutrinos-reels-publication/images/master-data-update-information.gif)

## Filter Records

To filter records, follow the steps below:

1. Click **Master Data** in the navigation bar to open the **Master Data** details page.
2. Click and select the Master Data file you created.
    ![master-data-details-selection](/resources/Storage/neutrinos-reels-publication/images/master-data-details-page-select.png)
3. Click the **More Filter** button to select the column for filtering the Master Data file. The operators used for filters are as follows:
  - Strings: equal to, not equal to, and ILIKE
  - Numeric: equal to, not equal to, less than, greater than, less than equal to, greater than equal to.
4. After creating the filter criteria, click the **Apply Filter** button to save the filter.

The GIF below illustrates how to create filter criteria to filter information of people above the age of 30:

![master-data-filter-option](/resources/Storage/neutrinos-reels-publication/images/master-data-filter-option.gif)

## Download Master Data

To download the Master Data file, follow the steps below:

1. Click **Master Data** in the navigation bar to open the **Master Data** details page.
2. Navigate to the Master Data file you created.
    ![master-data-details-selection](/resources/Storage/neutrinos-reels-publication/images/master-data-details-page-select.png)
3. Click the **kebab** icon in the **Actions** column.
4. Click the **Download Excel** option from the dropdown to download the master data file.

The image below illustrates how to download the Master Data file:

![master-data-download](/resources/Storage/neutrinos-reels-publication/images/master-data-download.png)
