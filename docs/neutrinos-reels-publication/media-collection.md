# Create Directory

<https://documentation.neutrinos.com/articles/#!neutrinos-reels-publication/media-collection>

Media Collection in Neutrinos Reels refers to a repository or grouped set of media assets — such as images, videos, audio files, and documents — that are uploaded, managed, and used within the Reels platform to support application design, content display.

It provides a structured folder hierarchy where media files are organized and stored for easy access and reuse across various components within Reels. This ensures consistent media usage, simplified content management, and efficient retrieval during content rendering.

![reels-media-collection-landing-page](/resources/Storage/neutrinos-reels-publication/images/reels-media-collection-landing-page.png)

The information displayed within the Media Collection is organized in a tabular layout, with content presented in a columnar format. Additionally, users can navigate across multiple pages using the pagination arrows and set the number of rows displayed per page through the pagination options available on the platform.

- **Name**: Displays the name of the directory created within the platform to store and organize the media files.
- **Author**: Displays the user ID of the person who created the folder or directory within the platform to store and organize the media files.
- **Version**: Displays the latest version of the directory available on the platform. This version may include or exclude files from previous versions, depending on the author’s choice when saving the new version.
- **Last Modified Date and Time**: Displays the date and timestamp of the most recent changes made to the directory.
- **Available From**: Displays the date and timestamp when the directory was created on the platform.
- **Actions**: The kebab icon in this column provides an option to delete it from the platform.
- **Caret Icon**: The caret icon at the end of each row allows you to expand the entry and view all available versions of the directory on the platform.

## Create Directory

To create a directory on the platform for storing media files, follow the steps below:

1. Click the Media Collections option on the left navigation bar to open the Media Collection page.
    ![reels-media-collection-landing-page](/resources/Storage/neutrinos-reels-publication/images/reels-media-collection-landing-page.png)
2. Click the Add Collections button located at the top-right corner of the page.
    ![reels-media-collection-add-new](/resources/Storage/neutrinos-reels-publication/images/reels-media-collection-add-new.png)
3. The next page displays all the information related to the Media Collection directory being created. The information is categorized into two sections - Details and Files.
    ![reels-media-collection-details-files](/resources/Storage/neutrinos-reels-publication/images/reels-media-collection-details-files.png)
  - The Details section lists all the information about the directory, including fields to add metadata for the files.
  - The Files section contains the actual media files that are uploaded and stored within the directory.
4. The Details section includes these fields:
    ![Note](/resources/Storage/neutrinos-reels-publication/project-trailproject/note.png)
    Note: Save the directory on the platform before adding content, as saving the directory is mandatory. You can also provide tags while saving the directory.
  - Name: Displays the name of the directory being created on the platform. You can also assign a tag name to the directory during creation.
  - Version: Initially displayed as a hyphen (–) when the directory is being created. Once the directory is saved and opened, this field displays the current version of the directory.
  - Last Updated: Displays the date and timestamp of the most recent changes made to the directory.
  - Created Date: Displays the date and timestamp when the directory was created on the platform.
  - Description: Allows you to add a brief description of the directory, including details about the type of files it stores. This helps identify the directory's purpose and provides users with context about the contents stored within it. After entering the description, click Save in the Description section to apply and save the changes to the platform.
  - Metadata Schema Editor: Allows you to define keys that can store metadata information for the files contained in the directory. These metadata fields facilitate categorisation, filtering, and retrieval of files based on specific attributes or categories defined by the metadata schema.
      Adding metadata keys is optional. You can define them as per your requirements or skip this step if metadata-based categorization is not needed. To make a metadata key a mandatory input field while uploading media, enable the toggle for the respective key in the Metadata Schema Editor.
5. After providing all the required details for creating the directory, click Add and Publish at the top-right corner of the page to save the directory structure to the platform, along with the specified details and metadata.
    ![reels-media-collection-directory-save](/resources/Storage/neutrinos-reels-publication/images/reels-media-collection-directory-save.png)

## Add Files

After creating a directory for uploading and storing files on the platform, the next step is to upload files to the directory created in the previous section. Follow the steps below to add files to the directory.

1. Click the Media Collections option on the left navigation bar to open the Media Collection page.
    ![reels-media-collection-landing-page](/resources/Storage/neutrinos-reels-publication/images/reels-media-collection-landing-page.png)
2. Locate the folder created on the platform using the name provided during directory creation, and click it to open. You can also search for the folder by entering its name in the search bar on the page.
    ![reels-media-collection-locate-folder](/resources/Storage/neutrinos-reels-publication/images/reels-media-collection-locate-folder.png)
3. After opening the directory, navigate to the Files section to upload files from your local computer. When no files have been added to the directory, a message appears stating: “No files added! Please add files.”
    ![reels-media-collection-no-files](/resources/Storage/neutrinos-reels-publication/images/reels-media-collection-no-files.png)
    After uploading the file(s), the details of the uploaded files are displayed in a tabular format, organizing the information into columns.
    ![reels-media-collection-table-format-display-info](/resources/Storage/neutrinos-reels-publication/images/reels-media-collection-table-format-display-info.png)
  - FileId: Displays the unique ID assigned to each file by the platform when it is uploaded to the directory.
  - FileName: Displays the name of the file as uploaded to the directory.
  - Format: Displays the file format. The platform supports images, PDFs, audio files, and videos, with a maximum file size of 5 MB.
  - Author: Displays the user ID of the person who uploaded the file to the platform.
  - Last Modified Date and Time: Displays the date and time when the file was last modified.
  - Available From: Displays the date and time when the file was uploaded to the platform.
  - Actions: Click the kebab icon in this column to view options for previewing, downloading, or deleting the file.
4. Click the Add File button in the center of the page (displayed only if no file(s) exist in the directory), or click the Add button at the top-right corner of the page.
    ![reels-media-collection-add-new-button](/resources/Storage/neutrinos-reels-publication/images/reels-media-collection-add-new-button.png)
5. On the next screen, you are prompted to add files to the platform. You can either browse and upload files from your local computer or drag and drop them directly onto the platform.
    ![reels-media-collection-add-files](/resources/Storage/neutrinos-reels-publication/images/reels-media-collection-add-files.png)
6. After uploading a file to the platform, click the Save button at the bottom of the page. If you want to upload multiple files, click the Save and Add New button to add another file to the platform.
    ![reels-media-collection-after-add-save](/resources/Storage/neutrinos-reels-publication/images/reels-media-collection-after-add-save.png)
7. If any metadata needs to be specified for the file, or if certain metadata was made mandatory when creating the directory, navigate to the Metadata section on the file upload page and enter the required details. Click Save once the information is provided.
    ![reels-media-collection-file-upload-metadata](/resources/Storage/neutrinos-reels-publication/images/reels-media-collection-file-upload-metadata.png)
