# User Task Node

<https://documentation.neutrinos.com/articles/#!neutrinos-reels-publication/user-tasks>

User tasks in process management refer to specific activities within a process that require human intervention or manual action. They represent the points in a workflow where a user (human actor) is responsible for performing a task before the process can proceed to the next step.

## User Task Node

A User Task is a type of task node in a process model that designates an activity to be performed manually by an assigned user or group of users. Unlike automated or system tasks that are executed by the system or an integration service, user tasks rely on human action to complete the workflow.

### Purpose

User tasks are used to:

1. Capture points in a process where human decision-making or data input is required.
2. Assign work items to specific users, roles, or departments.
3. Ensure human validation, approval, or review before the process continues.

## Attributes

![user-tasks-attribute-window](/resources/Storage/neutrinos-reels-publication/images/user-tasks-attribute-window.png)

| **Field** | **Description** |
| --- | --- |
| Name | Specify the name of the User Task node to be identified in the business process. |
| Documentation | Provide a brief description of the task that the node performs in the process. |
| Actors | Specify the user(s) who are authorized to work on this User Task in the process. |
| Groups | Specify the group(s) who are authorized to work on this User Task in the process. |
| Input | Specify the input(s) that correspond to process variables listed in the Details section of the process. |
| Output | Specify the output(s) that correspond to process variables listed in the Details section of the process. |

After entering all the required details for the User Task node, click **Save** at the bottom of the page to apply the changes.
