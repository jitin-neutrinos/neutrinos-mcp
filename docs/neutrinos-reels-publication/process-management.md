# Navigate to Process Management

<https://documentation.neutrinos.com/articles/#!neutrinos-reels-publication/process-management>

A business operates through a defined sequence of orchestrated activities. This sequence governs how the business runs from start to finish. Each business vertical or line of operation within an organization depends on this sequence of activities called "Processes". Reels provides a platform that helps with process management and workflow automation for businesses, facilitating the creation of a digital landscape for enterprise success.

A process is a structured workflow defined using BPMN 2.0. It has a clear start and end, with tasks, events, and gateways executed in a predefined order. Processes are best suited for repeatable and predictable business operations such as order approvals or invoice processing.

## Navigate to Process Management

From any screen on the platform, click Process in the left navigation panel to access the process management configurations available on the platform.




 ![pulse-navigation-process-page](/resources/Storage/neutrinos-reels-publication/images/pulse-navigation-process-page.png)

This opens the Process Management page, which displays all process configurations available on the platform.




 ![pulse-process-management-landing-page](/resources/Storage/neutrinos-reels-publication/images/pulse-process-management-landing-page.png)




 The details are presented in a table, showing the following information:

- **Name**: Name of the process configuration on the platform.
- **Description**: A brief description of the process configuration on the platform.
- **Author**: The user ID of the person who configured the process on the platform.
- **Last Update**: The date and time when the most recent changes were made to the process configuration.
- **Actions**: Contains a kebab icon. Clicking it allows users to either deploy or delete the configured process.
- The caret icon at the end of each row allows users to expand the configured process and view all available versions of the configuration on the platform.
