# Integrate Media Collection

<https://documentation.neutrinos.com/articles/#!neutrinos-reels-publication/integrate-media-collection>

Media Collection in Neutrinos Reels refers to a repository or a set of media assets - such as images, videos, audio files, and documents - that are uploaded, managed, and used within the Reels platform. Its services can be accessed either through the user interface, as described in the Media Collection topic, or programmatically via the Media APIs. For more information about the Media Collection UI options, refer to the [Media Collection](/articles/neutrinos-reels-publication/media-collection) topic.

The services provided by the Media Collection are categorized into two main types: Folders and Assets, each offering a distinct set of functionalities.
