### Plugins Builder

From Neutrinos Studio release 7.3.0, you can create a plugin using the **Plugins Builder**. The plugins builder allows you to create server or client nodes with ease.

Refer [Plugins Builder](http://docs1.neutrinos.co/articles/project-plugins-builder-guide) Documentation to learn more.

Refer to the [ChangeLog](/smart/project-change-log/release-7-3-0) to learn about the bug fixes.
