# Install on Mac

<https://documentation.neutrinos.com/articles/#!studio-guide-7/installation-on-mac>

To install Neutrinos Studio on Mac, perform the following steps:

1. Sign in to [Neutrinos Console](https://console.neutrinos.co/web/) with your username and password.
2. On the **Home** page of the Neutrinos Console, select **Mac **and click the** Download** button to download Neutrinos Studio. The executable file gets downloaded to your local machine.
3. Open the downloaded file to install it.
4. After installing, if you are not able to launch the Neutrinos Studio, perform the following
  1. Open security and privacy settings on your Mac machine.
  2. In the General section, make sure you have selected the **App Store and identified developers** in the **Allow apps downloaded from:** section. Click the **Open anyway** option.
  3. A warning prompt appears, click **Open** and the studio launches.
5. You will be directed to the Studio home page.

Refer [Apple Documentation](https://support.apple.com/en-in/HT202491) to know more.
