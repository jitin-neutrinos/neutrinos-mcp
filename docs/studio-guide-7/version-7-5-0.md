# Features

<https://documentation.neutrinos.com/articles/#!studio-guide-7/version-7-5-0>

Here is a list of new features and enhancements introduced in Neutrinos Studio version 7.5.0:

### Features

**UI only app**

From Neutrinos Studio release 7.5.0, you can create UI only app.

**IDS UI config editor**

You can configure the UI for the IDS page of the application that you are creating. You can access this editor in the Settings editor on the Neutrinos Studio.

### Enhancements

- Multiwindow support
- Angular material update.
- Seed App Angular Upgrade.
- Migration to Convert @agm/core to custom dependency.

Refer [Changelog](/smart/project-change-log/release-7-5-0) to learn about all the changes.
