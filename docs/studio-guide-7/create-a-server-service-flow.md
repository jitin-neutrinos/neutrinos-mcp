# Create a Server Service Flow

<https://documentation.neutrinos.com/articles/#!studio-guide-7/create-a-server-service-flow>

To create a server service, perform the following steps:

1. Click the **Services** on the [Studio Application page](/smart/project-concepts/studio-application-page) and select **Server**.
2. Click the **plus** icon on the explorer. Enter the name of the service that you want to create and click the **Add** button. The service gets added to the Services list.
3. Drag and drop nodes and wire them together to create server flows.

Once the server service is created, all the swagger documentation that you will create using the [HTTP In](/smart/project-server-side-service-designer/http-in) node can be accessed by clicking the **swagger documentation** link.
