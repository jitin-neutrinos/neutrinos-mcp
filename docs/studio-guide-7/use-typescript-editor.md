# Use TypeScript Editor

<https://documentation.neutrinos.com/articles/#!studio-guide-7/use-typescript-editor>

TypeScript Editor or the Ts editor contains the default app generated methods that are readily available for you to consume while designing an app. To view the **Ts** editor for your app page, click the page and then click **TS **on the bottom left of the screen.

For each page, you can customize or implement individual business logic by writing or modifying the TypeScript code.
