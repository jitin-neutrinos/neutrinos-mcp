# About Neutrinos

<https://documentation.neutrinos.com/articles/#!studio-guide-7/about-neutrinos>

Neutrinos is a multi-experience, Low- code application development platform which enables Enterprises, Startups, Independent Developers, and Citizen developers to build a wide range of complex enterprise-grade applications.

It is fully open-source and enables end-to-end code generation of applications. It is also platform agnostic and supports Windows, Mac, and Linux platforms.

It comprises the following components:

- [Studio](/articles/concepts-publication/studio)
- [Store](/articles/concepts-publication/neutrinos-store)
- [IDS](/articles/concepts-publication/identity-server)
- [Neutrinos Console](/articles/concepts-publication/neutrinos-console)
- [Server Services Designer](/articles/concepts-publication/server-services-designer)
- [Client Services Designer](/articles/concepts-publication/client-services-designer)
