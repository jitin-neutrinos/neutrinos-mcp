# Feature

<https://documentation.neutrinos.com/articles/#!studio-guide-7/version-7-9-0>

Here is a list of changes rolled out in version 7.9.0 of Neutrinos Studio:

### Feature

[Import and export services](/articles/studio-guide-7/import-and-export-services): Using this feature, you can import and export client and server services from one application to another. This feature helps reduce development time and facilitates the exchange of code between developers. It also facilitates the reusability of flows from one project /app to another.

---

### Enhancements

#### Search Functionality

The search functionality of the [HTML 5 component](/smart/project-components-documentation-copy/html) is enhanced. HTML 5 is an advanced component composing element types such as **div**, **paragraph**, **video**, etc. See the complete list of element types [here](/smart/project-components-documentation-copy/html/a/h3__1172380815).

The search functionality is enhanced to identify any HTML tags that this component supports. You can search tags such as h1, div, p, etc. and the search will display the HTML 5 component as a result in the [components palette](/smart/project-concepts/palette/a/h4_1518247481).

Also, the type will be auto-selected in the Element type field based on your search.

#### Signature Widget

The following properties are added to the attributes window of the Signature Widget:

- (imageDataChange)
- (imageDataUrl)

See the [documentation](/smart/project-components-documentation-copy/signature-widget) to learn more.

#### HTTP Request node

The Use Query String property is added to the [HTTP Request](/smart/project-server-side-service-designer/http-request-node) node on Server Services Designer. This property uses the querystring module to stringify and parse query strings in an HTTP request.
