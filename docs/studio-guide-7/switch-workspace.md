# Switch Workspace

<https://documentation.neutrinos.com/articles/#!studio-guide-7/switch-workspace>

## 

To change the [workspace](/articles/concepts-publication/studio-workspace), click ![Switch workspace icon](/resources/Storage/studio-guide-7/ws.png) on the Studio Home page and choose a different folder/directory.

To add and manage custom app dependencies on the workspace, see [Manage Global Plugins](/articles/studio-guide-7/manage-global-plugins).
