# Integrations

<https://documentation.neutrinos.com/articles/#!studio-guide-7/perform-integrations>

![](/resources/Storage/studio-guide-7/integrations.png)

With Neutrinos, integration to any external resource is easy. You can configure your integrations without the need to write custom code, significantly reducing time and effort and eliminating errors.

Neutrinos provides you with built-in capabilities to integrate with REST services and external databases. It also provides the capability for you to create your own REST APIs and expose them as part of your application.

All this can be achieved using the flow-based modeling in the [Server Services Designer](/articles/concepts-publication/services-designer).
