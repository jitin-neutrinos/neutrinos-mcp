# Import an App

<https://documentation.neutrinos.com/articles/#!studio-guide-7/import-an-app>

To import an app:

1. Click ![Import an app button](/resources/Storage/studio-guide-7/import.png)on the [Studio Home page](/articles/concepts-publication/studio-home-page).
2. Choose the location of the app in your local machine.
3. Select the [.nos file](/articles/studio-guide-7/export-a-nos-file/a/h3__1541192689) and click **Open**.

| ![Information](/resources/Storage/studio-guide-7/info.png) | When you import or export an application built on Neutrinos Studio, the application will have a NOS extension(.nos). |
| --- | --- |

If the app was created in an older version, click the **1-click migrate** button on the top-right of the app card to upgrade the app to the latest version.

![](/resources/Storage/studio-guide-7/upgrade%20app.png)

Perform manual steps (if any). See the [Migration guide](/smart/project-migration-guide/get-started) to learn more.
