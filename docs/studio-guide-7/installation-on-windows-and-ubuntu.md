# Install on Windows and Ubuntu

<https://documentation.neutrinos.com/articles/#!studio-guide-7/installation-on-windows-and-ubuntu>

To install Neutrinos Studio on windows, perform the following steps:

1. Sign in to [Neutrinos Console](https://console.neutrinos.co/) with your username and password.
2. On the **Home** page of the Neutrinos Console, windows is chosen by default. In the case of Ubuntu, select Ubuntu from the drop-down and click the** Download** button. The executable file gets downloaded to your local machine.![Comsole homepage](/resources/Storage/studio-guide-7/app-builder-s-user-guide/console_new.png)
3. Install the software. The steps may differ based on the operating system you are using. On windows, double click the executable file to open the installer and install the software.![neutrinos install page](/resources/Storage/studio-guide-7/project-learning-path/neuinstall.png)
4. Choose the destination folder and click **Install**.
5. Neutrinos Studio gets installed on your machine.
6. Launch the studio. You will be directed to the Studio home page. ![studio homepage](/resources/Storage/studio-guide-7/project-learning-path/studio%20homeage.png)
