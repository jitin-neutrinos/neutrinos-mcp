# Design Pages

<https://documentation.neutrinos.com/articles/#!tutorial-create-your-first-app/design-pages>

To design pages, click the **Pages **option and select the page that you want to design. The Page Designer for the selected page opens up. It comprises the Palette from where you can drag components such as a **Row**, **Table**, etc.

![sections of the page](/resources/Storage/tutorial-create-your-first-app/tutorial-create-a-leave-management-system/pagelayout.png)

Some components, such as rows and columns, have droppable regions. This means that you can add other components within these components. To design a page, drag components from the **Palette Section** and drop the components in the **Page ****Container.**

**Rows**

When you drop components in a row, they get stacked horizontally by default. You can add attributes if you want additional behavior for various devices.

**Columns**

When you drop components in a column, they get stacked vertically by default. You can add attributes if you want additional behavior for various devices.

---

**Attributes**

Double-click the component to open its respective Attributes window. Note that, by default, there are attributes associated with each component. Enter a value for the attribute you want to configure. You can also add custom attributes for a component.

**Custom attributes**

A **custom attribute** is an attribute that is not available by default in the Attributes window. It is added as per the user requirement.

To add a custom attribute, go to the attributes window, scroll down and click on the custom properties. You can define a key-value pair or an attribute. By default, **Attribute** is selected.

![Custom properties of LMS](/resources/Storage/tutorial-create-your-first-app/tutorial-create-a-leave-management-system/custompropLMS.png)

Certain custom attributes change their appearance in the attributes section once they are added. For example:

- **fxFill** will be displayed as **Layout Fill** label with a checkbox in front of it.
- **dir **will be displayed as a drop-down menu with **Direction **as its placeholder.

**Attributes and Key/Value**

To create a custom **Attribute **type, you enter the key data. The [Studio](/smart/project-concepts/studio) auto-completes the value data. However, for a custom **Key/Value** attribute, enter the key as well as the data value. Click **ADD** to add the custom attribute.

| **Component** | **What you need to Enter** |
| --- | --- |
| Attribute | Enter the Key value only |
| Key/Value | Enter the key and data value |
