# Create a Web App

<https://documentation.neutrinos.com/articles/#!tutorial-create-your-first-app/title>

![weather theme](/resources/Storage/tutorial-create-your-first-app/2020-03-09_00h16_12.png)Tutorial: Create a Weather App on Neutrinos Studio
In this tutorial, you will be creating a **weather** app using the latest release of Neutrinos Studio to display the weather of a city that the user will input on the runtime. This app will integrate with an external weather service provider named **Open Weather Map** to get the weather data.
