# Creating Data Models

<https://documentation.neutrinos.com/articles/#!tutorial-create-your-first-app/design-data-models>

### Creating Data Models

1. To create a [Data Model](/articles/project-concepts/legacy-data-model), click the **Models **menu from the menu list and select **Add.** Data Model dialog box appears.
    ![Add data model](/resources/Storage/tutorial-create-your-first-app/project-tutorial-leave-management-system/add%20datamodels.png)
2. To add a new data model, select **New** in the data model dialog box and configure the following:

![Step 2 to add datamodels](/resources/Storage/tutorial-create-your-first-app/newdata.png)

**logobject Data Model**

For the weather app, you need to create the** logobject **data model. This data model captures information about the log of the weather search.

![log data model](/resources/Storage/tutorial-create-your-first-app/log_dm.png)

After creating the data model, open the **Models **editor and enter the following values in the respective fields to add the data attributes.

![open Models editor](/resources/Storage/tutorial-create-your-first-app/display%20datamodel.png)

| **Name** | **Type** | **Array[ ] ** |
| --- | --- | --- |
| type | string | Not selected |
| message | string | Not selected |

![The data model attributes](/resources/Storage/tutorial-create-your-first-app/logobj1.png)
