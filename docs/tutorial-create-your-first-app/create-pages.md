### Overview for Weather App Pages

For the weather app, you will be creating the following [pages](/smart/project-concepts/page):

- **log**: Displays the log of the weather search.
- **weathercard**: Displays the weather of the city that the user has entered.
- **weathersearch**: Displays a search field to enter the name of the city.

**Creating Pages**

1. To create a page, click the **Pages **menu from the editor pane and click the **Add New** option.

![Create Pages](/resources/Storage/tutorial-create-your-first-app/tutorial-create-a-leave-management-system/addpage.png)

2. In the Enter Page Name dialog box, enter the name of the page. For Example, enter **log**.

![Page Details(NAME)](/resources/Storage/tutorial-create-your-first-app/addpagenewww.png)

3. Click **Create Page. **

4. The **log** page is created successfully.

Similarly, create the other two pages:

- **weathercard**
- **weathersearch**
