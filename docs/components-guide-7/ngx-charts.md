## NGX Charts

NGX Charts uses Angular to render and animate the SVG elements with all of it's binding and uses d3 for math functions, scales, axis and shape generators, etc. By having Angular do all of the renderings it opens us up to endless possibilities the Angular platform provides such as AoT, Universal, etc.

This section describes the **NGX Charts **components that are available on [Neutrinos Studio](/smart/project-concepts/studio).
