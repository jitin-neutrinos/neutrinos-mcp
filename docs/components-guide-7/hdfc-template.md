## HDFC Template

### Overview

This template is a Mobile application that uses the native capabilities of the mobile. It integrates with the [MongoDB](/smart/project-server-side-service-designer/mongodb-node) database, and consumes an external API.

### How to Use

1. On Neutrinos Store, open the **HDFC** template.
2. Click the **Download** icon and select **Open Neutrinos Studio** in the pop-up that appears. You will be navigated to the Neutrinos Studio.
3. On Neutrinos Studio, click **Yes** on the confirmation pop-up and the template gets installed.
4. Create a new app using this template and design the app further as per your requirement.
5. [Initialize and preview the mobile app](/articles/app-builder-s-user-guide/deploying-your-app).
