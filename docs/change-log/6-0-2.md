## 6.0.2

#### Date: (2019-07-20)

**Bug Fixes**

- Error is thrown when editing an Error condition in the **Input** component's Attributes window.
- When an error occurs, [object object] is displayed in the notification bar instead of the actual error message.
- Snackbar messages are not contained within the snack bar.
- The progress is displayed behind the dialog box when you download a template from Neutrinos Store.
- Mat-Error and Mat-hint template generation fail for older apps.
