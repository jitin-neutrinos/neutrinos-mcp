# Release 7.3.0

<https://documentation.neutrinos.com/articles/#!change-log/release-7-3-0>

#### Release 7.3.0

### Date: 11 November 2020

### Bug Fixes

- Added a Plugins Builder Designer to the Neutrinos Studio.
- Added change detection for all the Studio Editors.
- Hide Config node for the client and common types.
- Added a shortcut key [ctrl+b] to open the Plugin Builder.
- Clicking the text of the expandable menu opens the tab.
- Unable to delete a node in the Plugins Builder.
- Change detection does not fire when switched to a node designer.
- Creating a node with the name **new** will make code generation empty.
- Nodes with the same name should not be added.
- If package is deleted from plugin builder it should also be removed from workspace manage plugins.
