- Multiwindow support.
- Create UI-only apps on Neutrinos STudio.
- The tasklist is empty- No default value is selected.
- The IDS UI config editor.
- Angular material update.
- Codegen changes for generic start nodes.
- Use locally installed angular binary instead of requiring users to install angular globally.
- Seed App Angular Upgrade.
- Migration to Convert @agm/core to custom dependency.
