#### Element Styles

Element Styles are essential for managing the visual appearance and behavior of various components in a design. They encompass styles applied to text, buttons, and other user interface (UI) elements, ensuring consistency and enhancing the user experience. By standardizing the styling of these components, designers can maintain a cohesive look and feel across the entire application.

#### Fonts

The Fonts section, empowers users to manage and customize the typography used throughout their design. This feature is crucial for establishing a unique and cohesive brand identity, ensuring that all text elements are visually appealing and consistent. Here, users can fine-tune various font properties to align with their design vision and enhance readability.

The various customizations provided within the fonts section are described below:

**Font Selection drop-down**

It includes a dropdown menu that allows users to select from a variety of font families. In the screenshot provided, "IBM Plex Sans" is selected, indicating the active font family being customized.

**Style Name**

This column lists the predefined text styles, such as "Heading 1" and "Heading 2". Each style represents a specific text element in the design.

**Font Size**

Users can specify the size of the font for each style. For example, "Heading 1" is set to 56px, while "Heading 2" is set to 42px.

**Letter Spacing**

This setting allows users to adjust the space between characters. In this interface, both "Heading 1" and "Heading 2" have a letter spacing of 1px.

**Line Height**

This controls the vertical spacing between lines of text.

**Italic Toggle**

A switch that allows users to apply italic styling to the text. In this example, the italic option is turned off for both "Heading 1" and "Heading 2".

**Font Weight**

Users can select the weight of the font, such as normal, bold, or other variations. "Heading 1" is set to "Normal," while "Heading 2" is set to "Bold".

**Color**

This column lets users define the color of the text using HEX codes. Both headings are set to the color 101828, which is a shade of dark blue/black.

#### Style Variable

The Style Variables section provides users with the ability to define and manage key design attributes, such as colors and spacings, ensuring a consistent and cohesive visual experience across their projects. This is particularly useful for maintaining a uniform design system, enabling efficient updates and easy management of style related properties.

The Features available are described below:

- **Default Variables** - The Default Variables tab, focuses on managing the fundamental design attributes that apply across the entire project. This tab allows users to define key style elements such as colors, spacings, and other general design properties. It contains the following elements:![](/resources/Storage/alpha-workflow-publication/styles/StyleVars.jpg)
  - Background Surface Color - This is the main color applied to the background, serving as the foundational color behind all primary content and elements. It establishes the overall look and feel , providing a consistent backdrop that enhances readability and visual coherence.
  - Background Surface Control Inactive Color - This color is used to indicate controls or elements on the background surface that are currently inactive or disabled, helping to differentiate them from active or interactive elements.
  - Primary Color - This is the main color used for key interface elements such as buttons, links, and highlights.
  - Primary Hover Color - The color used when a user hovers over primary elements.
  - Primary Focus Color - The color indicating a focused state on primary elements.
  - Primary Inactive Color - The color for inactive primary elements.
  - Secondary Color - This color is utilized for less prominent elements within the interface, providing a complementary accent to the primary color.
  - Secondary Fill Color - The fill color for secondary elements.
  - Background Surface Hover Color - The background color when a user hovers over the surface.
  - Success Color - The color indicates success. It is commonly used to highlight successful operations, confirmations, ensuring users can easily recognize when actions have been completed successfully.
  - Border Color - The color used for borders around elements. It matches the inactive control background color, maintaining visual consistency.
  - Error Color - This color is used to signify errors or warnings. It typically draws immediate attention to critical issues that need to be addressed, enhancing user awareness and prompting corrective action.
  - Warning Color - This color is designated for warnings or cautionary messages. It is used to alert users to potential issues that require their attention, ensuring that important notices are prominently displayed and easily recognized.
- **Text Variables** - This tab is dedicated to managing typography-related settings, allowing users to define and customize the textual elements of their design. This section provides control over various aspects of typography to ensure that text is not only visually appealing but also consistent and readable throughout the project.
  - Text Color - This is the main color used for the most important text elements, ensuring high readability and visibility for primary content such as headlines, body text, and essential information.
  - Primary Text Color - This is the main color used for the most important text elements, ensuring high readability and visibility for primary content such as headlines, body text, and essential information.
  - Inactive Text Color - This color is applied to text elements that are currently inactive or disabled. It typically has a lower contrast compared to active text, indicating that the text is not interactive or is in a disabled state.
  - Highlight Text Color - This color is used to emphasize or highlight specific text within the interface. It draws attention to key information or important sections, making them stand out from the surrounding text.
     ![](/resources/Storage/alpha-workflow-publication/styles/Textvars.png)
- **Toggle Variables** - This section allows users to customize the appearance and behavior of toggles, such as switches and checkboxes, ensuring they are visually consistent and functionally effective across the application.
  - Toggle Background Color - This color is used for the background area of toggle switches when they are in their default, unselected state. It helps to define the inactive state of the toggle control.
  - Toggle Button Color - This color is applied to the button or handle of a toggle switch, indicating the part of the toggle that users interact with to switch between states.
  - Toggle Select Background Color - This color is used for the background area of toggle switches when they are in their selected or active state. It distinguishes the active state from the inactive state, providing clear visual feedback.
  - Toggle Select Button Color - This color is applied to the button or handle of a toggle switch when it is in the selected or active state. It visually indicates that the toggle is currently enabled or turned on.
     ![](/resources/Storage/alpha-workflow-publication/styles/togglevars.png)
- **Table Variables: ** Table Variables are a set of predefined values used to control the appearance and layout of tables. These variables allow for a consistent and efficient way to apply and manage styles across multiple tables.
  - Table Header Background Color - This color is used for the background of table headers. It helps to differentiate the header from the rest of the table, making column titles or labels stand out.
  - Table Header Text Color - This is the color applied to the text within table headers. It ensures that the header text is easily readable and distinct against the background of the table header.
  - Table Body Text Color - This color is used for the text within the body of the table. It is chosen to ensure readability and clarity for the data or content displayed in the table rows and columns.
  - Table Body Background Color - This color is applied to the background of the table body, which includes all rows and cells excluding the header. It provides a consistent backdrop for the table data.
     ![](/resources/Storage/alpha-workflow-publication/styles/tablevars.png)
- **Sidebar Variables**: Sidebar Variables are customizable settings used to control the visual and functional aspects of sidebars. They streamline the management of sidebar design, ensuring consistency and ease of updates across different parts of a project.
  - Sidebar Active Background - This color is used for the background of active or selected items within the sidebar. It highlights the currently selected section.
  - Sidebar Header Text - This is the color applied to the text within sidebar headers. It ensures that the header text stands out clearly, providing effective labels for different sections.
  - Sidebar Text - This color is used for the general text within the sidebar. It is chosen to ensure readability and visual consistency for all non-header text elements in the sidebar, such as menu items and links.

![](/resources/Storage/alpha-workflow-publication/styles/sidebarvariable.png)

**Logo**

This section is dedicated to displaying the logo of the application. Users can upload their application logo, that showcases the brand identity prominently, ensuring that it is easily recognizable and associate the logo with the application.

**Loader**

This section enables users to add a loading image, which is displayed during loading times.
