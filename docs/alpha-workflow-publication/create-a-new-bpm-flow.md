Business Process Model and Notation (BPMN) is the global standard for process modeling. Combining BPMN, an easy-to-adopt visual modeling language, where you can automate your business processes.

Processes are the algorithms that dictate how an organization operates through independent tasks. The Alpha workflow engine executes BPMN-defined processes, ensuring they can be quickly orchestrated within a diagram.

### Accessing Business Central

1. Once a Schema is created using visual editor, click on ***Process*** > ***Create a New BPM Flow***.
2. Access the [Business Centra](https://alpha.neutrinos-apps.com/business-central/kie-wb.jsp)l login page.
3. Enter valid Credentials and login.

### BPMN elements

Before creating a diagram, let us explore the components on the left side of the screen.

#### Events

Events are occurring, business-relevant states. In BPMN 2.0, events can either start a process, occur, or be caused during a process, or end a process. Events that have occurred are conditions created by an external trigger. These can be start or intermediate events. Triggered events are conditions generated by the process itself, these are intermediate or end events.

**Start building an application:** Draw a BPMN process diagram

In this use case, you will build a claims management solution. Making sure that claims are handled by the appropriate employee(s) can be key to customer satisfaction. It is also a good fit for a process-based application that uses automation.

Here is an overview of process execution

- The process will be started by a customer who submits a claim, which is a simple text description in our example.

- Next, an employee will review the claim and approve or reject it.

- Once this task is done the process will be completed.

#### Create the process diagram

In the Business Central, select a space and click on Add Project > Create a Task.This will open the BPMN diagram screen.The new diagram should include:One pool: one process definitionOne lane inside the pool: lane default name is Employee laneA start event: the starting point of process executionA user task: a task (or step) that needs to be performed by a user

Add a gateway to determine if the claims can be processed or not.Change the gateway type (and name it as claims processed) from parallel to exclusive (the one with the x sign). Add another end event.
