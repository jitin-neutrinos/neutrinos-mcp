# Global Pages

<https://documentation.neutrinos.com/articles/#!alpha-workflow-publication/global-pages>

Global pages are integral components within Workflow Studio, designed to enhance consistency and efficiency across multiple workflows. These pages serve as reusable templates that provide standardized user interface elements and functionality, ensuring a uniform experience throughout the system.

Global pages typically include common components such as navigation menus, headers, footers, forms, and other essential interface elements. By using global pages, organizations can maintain a cohesive look and feel, streamline workflow creation, and simplify maintenance.

Benefits

**Consistency Across Workflows**: Global pages ensure that all workflows share a uniform design and functionality, promoting a seamless user experience.**Efficiency in Development**: By creating a single page that can be used across various tasks and workflows, development time is significantly reduced.**Simplified Maintenance**: Updates to global pages automatically reflect across all workflows that utilize them, making it easier to implement changes and improvements.**Standardized Components**: Common elements such as navigation menus, headers, footers, and forms are included in global pages, ensuring that these components are consistent regardless of the specific workflow.

To Create a Global Page:

1. On the left panel click on Pages link.
   The global page is displayed.
    ![](/resources/Storage/alpha-workflow-publication/styles/globalpages.png)
   Refer to [Creating a Page](/articles/alpha-workflow-publication/process/a/h4_129037091) for more information on how to use the available components and create a page.
2. Once you are done creating a page, click on Process link and > icon.
   The create page is displayed.
3. Click on create new page and select existing.
4. From the existing page drop-down list, select the global page that you have created.
   ![](/resources/Storage/alpha-workflow-publication/styles/globpage.png)
5. Use the global page to create a workflow.
