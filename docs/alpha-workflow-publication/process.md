# Creating a Page

<https://documentation.neutrinos.com/articles/#!alpha-workflow-publication/process>

The BPM is where we make our process better, designing new ones and assigning and executing automations. Your business may have identified processes that need to be done repeatedly. The processes can be broken up into individual tasks and then mapped into a flow.

With Workflow Studio you can easily add workflow and BPM capabilities to your application, by allowing you or your end-user to create workflow definitions and running them.

Main tasks you can do with Workflow Studio are:

- Design workflow definitions visually in a diagram.
- Run the workflow definitions.
- Manage tasks generated by the workflows.

Benefits of BPM:

- Increases repeatability of processes - Workflow Studio will make sure they are always done in the same order, based on the same decision-making process.

- Reduces reliance on key staff members to ensure correct processing.

- Releases those key staff to complete other work.

To create a BPM Flow:

1. Once you have created a schema and initialized a project, click on Process.
   ![](/resources/Storage/alpha-workflow-publication/process/CreateWorkflow.jpg)
2. Create a New BPM Flow by clicking on the ***Create*** button. (Refer to [Creating a bpm flow](/articles/alpha-workflow-publication/create-a-new-bpm-flow) for in-depth information).
3. Upload the BPM Flow that you have created in a zipfile.
4. The Human tasks mentioned in your BPM Flow will now be displayed within the Human Tasks page.
   ![](/resources/Storage/alpha-workflow-publication/process/Human%20Tasks.jpg)

The next step is to create a page for the mentioned human task. The steps for doing so are outlined in the following sections:

- Creating a Page
- Assigning Tasks

The create page feature is organized in a vertical layout, with a search bar at the top, followed by layout options, and then a categorized list of input components. The interface contains several components and options for creating or designing a form. Here is a detailed description of the various elements:

#### Layout Options

**Content Blocks**

Content blocks are structural elements that help in organizing the layout of the page. Content blocks provide structure to a page layout, making it easier to organize and arrange content in a visually appealing manner.

Content blocks contain the following elements:

- **Panel** - A container component that can hold various other elements. It is used to group a set of related UI components.
- **Columns** (1,2 and 3) - Commonly used in forms, comparison sections, or content that needs to be presented.

#### Input

The input section comprises various interactive elements that users can interact with to provide input or make selections. These are fundamental components for creating forms and interactive parts of an application. Here are the available components:

1. **Button ** - Act as an interactive UI element designed to be clicked by users to initiate an action or command. It is a fundamental component in user interface design, often visually distinct to encourage user interaction. Buttons serve as triggers for a wide range of functionalities and tasks within an application. They provide a straightforward way for users to engage with the interface, making decisions, submitting information, or navigating to different parts of the application.
2. **Checkbox**: A Checkbox is a small square interactive UI element that allows users to make binary choices — selecting or deselecting an option. It is typically accompanied by a label that describes the choice being made. Checkboxes are used to enable users to select multiple options independently within a set of choices.
3. **Date Picker**: A Date Picker is a graphical interface element that allows users to select a date from a calendar view or input a date directly. It simplifies the process of date entry and ensures that dates are formatted correctly, enhancing both usability and data accuracy.
4. **Dropdown**: A Dropdown is an interactive UI component that presents a list of options in a collapsible menu. Users can click to expand the dropdown and select one item from the list. This component is essential for managing space efficiently and providing users with a clean way to choose from multiple options without cluttering the interface. The main function of a Dropdown is to offer a compact and user-friendly method for selecting a single option from a predefined list.
5. **Dynamic Input**: A Dynamic Input is an adaptable UI component that can change its behavior, appearance, or available options in response to user interactions or predefined conditions. Unlike static input fields, which remain constant, dynamic inputs can evolve based on context, providing a more flexibility and personalized user experience. The primary purpose of a Dynamic Input is to create interactive and context-sensitive forms or interfaces. By adapting in real-time to user actions or specific criteria, dynamic inputs enhance usability and streamline the data entry process, making applications more responsive and intuitive.
6. **Radio Button**: A Radio Button is a circular interactive UI element used to allow users to select one option from a predefined group of mutually exclusive choices. Only one radio button in the group can be selected at any given time, making them ideal for presenting a list of options where only a single selection is permissible. The main purpose of Radio Button is to enforce a single choice within a set of options, ensuring that users can select only one item from the group. This makes them perfect for scenarios where a distinct, singular choice is required, such as selecting a payment method.
7. **Table**: A Table is a structured arrangement of data, organized in rows and columns, facilitating easy comparison and analysis. Tables are used to present information in a systematic way, making it easier to view, interpret, and understand data relationships and patterns.
8. **Text Area**: A Text Area is a multi-line input field used for entering larger amounts of text. It is commonly used for collecting comments, descriptions, or any other extended text-based information from users. Unlike standard text input fields, text areas can expand both vertically and horizontally to accommodate longer content.
9. **Input Field**: An Input Field is a user interface element that provides a basic, single-line text box for entering and editing short text. It is widely used in forms and interactive applications to capture specific pieces of information from users, such as names, email addresses, or search queries.

Each component is designed for intuitive drag-and-drop functionality, allowing users to effortlessly build custom forms or pages by placing elements exactly where they need them.
