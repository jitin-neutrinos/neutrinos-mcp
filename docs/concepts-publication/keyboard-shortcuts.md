# Studio Keyboard Shortcuts

<https://documentation.neutrinos.com/articles/#!concepts-publication/keyboard-shortcuts>

These are the keyboard shortcuts that you can use on the Studio Application page.

| **Task** | **Shortcut** | **Ubuntu** | **Mac** |
| --- | --- | --- | --- |
| Save current tab | Ctrl+s | Ctrl+s | Cmd+s |
| Close current tab | Ctrl+w | Ctrl+w | Cmd+w |
| Toggle between Htmland TS editors | Ctrl+0 | Ctrl+0 | Cmd+0 |
| Undo | Ctrl+z | Ctrl+z | Cmd+z |
| Redo | Ctrl+y | Ctrl+Shift+z | Cmd+y |
| Cut | Ctrl+x | Ctrl+x | Cmd+x |
| Paste | Ctrl+v | Ctrl+v | Cmd+v |
| Paste and Match style | Ctrl+Shift+V | Ctrl+Shift+v | Cmd+Shift+v |
| Select all | Ctrl+A | Ctrl+a | Cmd+A |
| Shift opened tabs | Ctrl+Tab | Ctrl+Tab | Cmd+Tab |
| Open Plugins Manager | Ctrl+Shift+p | Ctrl+Shift+p | Cmd+Shift+p |
| Search nodes | Ctrl+p | Ctrl+p | Cmd+p |
