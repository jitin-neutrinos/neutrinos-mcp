# Top Menu

<https://documentation.neutrinos.com/articles/#!concepts-publication/studio-home-page>

When you sign in to Neutrinos Studio, you see the Neutrinos Studio Home page with a default workspace. You use this page to create apps, switch workspaces, manage plugins, use app templates, and import apps.

It contains the following elements:

### Top Menu

**Edit: **The Edit menu allows you to perform specific actions on the Studio Application page.

- **Save Current Tab:** Save the current tab.
- **Close Current Tab**: Close the current tab.
- **Toggle Html<> Ts**: Used to switch between the HTML and Ts editor.
- **Undo:** Undo last change.
- **Cut:** Cut the selected component.
- **Copy: **Copy selected component.
- **Paste:** Paste the copied component.
- **Paste and Match Style:** Paste the copied component to match the style of the existing component.
- **Select All**: Select all the components.

**Plugins: **The Plugins menu allows you to download and manage [global plugins](/articles/concepts-publication/plugin/a/h4_324098977).

- **[Plugins Builder](/articles/concepts-publication/plugins-builder)**
- **Manage Plugins:** Allows you to manage global plugins and app templates.
- **Go to store:** Links to [Neutrinos Store](/articles/concepts-publication/neutrinos-store).

**Window: **The Window menu allows you to open additional windows.

- **New Window: **Opens Neutrinos Studio in a new window.
- **New Plugin Builder: **Opens the Plugin Builder of Neutrinos Studio in a new window.

**Help: **The Help menu provides help documents. It provides the following options:

- **Learn More:** Links to Neutrinos Knowledge center which hosts the product documentation.
- **About: **Displays the version of Neutrinos Studio installed on your machine.

### Create App Icons

Click the respective icon to create a classic app, a UI-only app, or an API-only app.

### App Cards

Any app that you create on Neutrinos Studio is visible as an app card on the Home page. You can open the app in a new window, edit app details, delete the app, and export the app as a .nos file by clicking the** ...** icon on the bottom-right corner of the app card.

### Other Icons

1. Click the **Switch workspace** icon to switch your workspace.
2. Click the **Import App** icon to select the .nos file of the app that you want to import.
3. Click the **User** icon to view the logged-in user details and to log out.
