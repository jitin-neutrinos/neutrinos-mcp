# Identity Server (IDS)

<https://documentation.neutrinos.com/articles/#!concepts-publication/identity-server>

Neutrinos Identity Server (IDS) is a standards-compliant OAuth 2.0 authorization standalone and a certified OpenID Connect provider. The OAuth 2.0 protocol provides API security via scoped access tokens, and Neutrinos IDS provides user authentication and single sign-on (SSO) functionality by maintaining all user’s information. It also grants user tokens to control authorization and authentication, giving you centralized control.

The OAuth connection uses TLS 1.2 and the connection is encrypted and authenticated using AES 128 and RSA key exchange mechanism.


 After creating an app in Neutrinos Studio, you can configure Identity services for your application using the OAuth Strategies provided and supported by Neutrinos.

By default, IDS is delivered with the Neutrinos branding and color scheme. This branding can be customized to align with organizational requirements. For more information about available theming options and instructions on updating or modifying the IDS theme, refer to the [Theming](/smart/project-identity-server/theming) section.
