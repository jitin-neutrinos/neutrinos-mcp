# Services Designer Editor

<https://documentation.neutrinos.com/articles/#!concepts-publication/services-designer-editor>

The Services Designer editor is used in [Client Services Designer](/articles/concepts-publication/client-services-designer) and [Server Services Designer](/articles/concepts-publication/server-services-designer).

This editor comprises the following elements:

- **Action pane**: The action pane allows you to navigate back to the application home page, Live view the [service flow](/articles/concepts-publication/services-designer-elements/a/h3__2138058983) that you create, save the service, and deploy the app.
- **Services list**: The services list contains all the services that you have created for your app.
  - If you have accessed the service designer editor on the **S****erver Services Designer**, you will see [global nodes](/smart/project-server-side-service-designer/global-nodes) listed in the nodes palette and a default [middleware sequence](/articles/concepts-publication/middleware-sequence) in the canvas.
- **Nodes Palette**: The nodes palette contains all the nodes that are available for you to design your flow. You are provided with a few [Global nodes](/articles/server-side-service-designer-publication/global-nodes) that you can apply to all the flows that you will create in SSD. You are also provided with other nodes that are categorized into sections that appear after you create a service. Use the search bar on the top of the palette to search for a node.
- [Canvas](/articles/concepts-publication/canvas)
- **Attributes window**: The attributes window provides a list of properties that you can configure for the selected node. Drag and drop a node to the canvas, and double-click the node to open its attributes window. For example, this is the Attributes window of the **Call Service** node.
