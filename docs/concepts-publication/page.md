# Page

<https://documentation.neutrinos.com/articles/#!concepts-publication/page>

### Page

A page is the basic building block of an application. It is the basic end-user interface of an application that is used to display information to the end-user, allow end-users to create and edit information, and enable end-users to trigger additional processing.

Every application consists of one or more pages.

#### Page Layout

The arrangement of visual elements on a page is called the page Layout. You decide the layout of the page using [Row](/smart/project-components-documentation-copy/flex-layout-row) and [Column](/smart/project-components-documentation-copy/flex-layout-column) components.

#### Page View

On Neutrinos Studio, the HTML part of a page is called a **View**. A view can be reused on other pages of the same application. Because views are reusable, each view instance can share its user interface with other view instances.

#### Page Flow

Page Flow defines the functionality of the page. You design page flows using the [page flow designer](/articles/concepts-publication/page-designer/a/h3_520216706).

#### Page UI

The Page UI is the HTML template of the page. You design the user interface of the page using the [page UI designer](/articles/concepts-publication/page-designer/a/h3__1090805748).
