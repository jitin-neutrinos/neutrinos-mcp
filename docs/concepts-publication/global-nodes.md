# Global Nodes

<https://documentation.neutrinos.com/articles/#!concepts-publication/global-nodes>

Global nodes are pre-defined middleware sequences that are created for your ease of use. These nodes will run on every HTTP request made to the server. You can configure global nodes to work with** global middleware **and** route middleware **sequences. If added to the **global middleware sequence**, this node gets executed for all the HTTP requests that the server receives. If added to the **route middleware sequence**, this node gets executed for that particular HTTP request.

Global nodes include:

- [Global session node](/smart/project-server-side-service-designer/global-session-node)
- [CORS node](/smart/project-server-side-service-designer/cors-node)
- [Global MongoDB session node](/smart/project-server-side-service-designer/global-mongodb-session-node)
