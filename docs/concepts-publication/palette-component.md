# Palette Component

<https://documentation.neutrinos.com/articles/#!concepts-publication/palette-component>

By default, the Neutrinos Platform provides you with a large set of components that you can use to develop your apps from the Studio Application page. These components are called **palette components **and are available to be used from the components palette list.

![components palette list](/resources/Storage/concepts-publication/palette%20list.png)

* Components palette list*

Palette components are categorized into the following sections:

- **Layouts:** Use components in this section to define the arrangement of visual components within a page.
- **Charts: **Use components in this section to give a graphical interpretation of data. There are two varieties of chart frameworks available for you to use:
  - **Ng Charts: **Chart components based on the [chart.js](https://www.chartjs.org/) framework.
  - **Ngx Charts:** Chart components based on the [d3js chart](https://d3js.org/) framework
- **Form Controls:** Contains components that enable users to take actions or capture information on the page
- **Navigation:** Contains components that enable control of app flow and navigation
- **Others:** Contains HTML components that enable a user to design custom HTML components within a page.
