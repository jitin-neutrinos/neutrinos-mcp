# App Templates

<https://documentation.neutrinos.com/articles/#!concepts-publication/app-templates>

Templates are applications containing various UI or functional components. They are pre-built, mini-application with a few core functionalities already implemented for you. They save time and allow you to reuse the existing functionality.

You can easily customize and add to the template's design and code to create an app according to your requirements.

The Neutrinos Store hosts many such app templates. See [Templates hosted on Neutrinos Store](https://store.neutrinos.co/web/catalog/templates) to view the existing templates. When you are creating an app, the UI allows you to navigate to Neutrinos Store and download any template that you want to use as part of your app.

To create an app template, see [Create an app template](/smart/project-create-a-widget/create-an-app-template).
