# Free Trial Terms

<https://documentation.neutrinos.com/articles/#!concepts-publication/free-trial-terms>

If you are using the free trial version of Neutrinos Platform, these are the important terms regarding the version and usage:

- The registered organisation admins can onboard any number of users for platform evaluation using Neutrinos Console.
- A total of 5 apps can be created and deployed on the cloud.
- A user can design and deploy Web and Mobile apps (Android only). The iOS build is not available.
- [Neutrinos Support](mailto:support@neutrinos.co) will assist in On-boarding a Client's organization (organisation admins of the organization) on receiving the free trial request.
- Node Version Manager (NVM) is not supported.
- Upload and download of documents in the app will not be supported.
- Apps deployed on the cloud cannot be deleted by the user.
- Only one build can be scheduled at a time for a given app.
- In User Management, any group name starting with Neutrinos is reserved for only the Neutrinos organization.
- New deployments will override all previous deployments irrespective of the type of build in the free trial.
- Modelr is not available for the free trial.
- Firebase push notifications are not supported.
