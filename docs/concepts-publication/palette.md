# Components Palette

<https://documentation.neutrinos.com/articles/#!concepts-publication/palette>

Neutrinos Studio provides two palettes that are accessible from the [Studio Application page](/articles/concepts-publication/studio-application-page).

#### Components Palette

You can use the components palette to drag and drop [palette components](/articles/concepts-publication/palette-component), [store components](/articles/concepts-publication/store-component), and [page views](/articles/concepts-publication/view) to the canvas and design the UI of a page.

#### Nodes Palette

You can use the nodes palette to drag and drop nodes to the canvas and design flows. Though the nodes differ in each designer, the nodes palette is common across the [page flow designer](/articles/concepts-publication/page-designer/a/h3_520216706), [Client Services Designer](/articles/concepts-publication/client-services-designer), and [Server Services Designer](/articles/concepts-publication/server-services-designer).
