# Neutrinos Platform

<https://documentation.neutrinos.com/articles/#!concepts-publication/neutrinos-platform>

Neutrinos Platform is a multi-experience, low-code, rapid application development platform that provides the capability for you to build Enterprise-grade applications. It is fully open-source and enables end-to-end code generation of applications. It is also platform agnostic and supports Windows, Mac, and Linux platforms.Platform architecture:![Neutrinos platform architecture](/resources/Storage/concepts-publication/concepts-publication/platform%20architecture.png)
It comprises the following components:

- [Studio](/articles/concepts-publication/studio)
- [Store](/articles/concepts-publication/neutrinos-store)
- [IDS](/articles/concepts-publication/identity-server)
- [Neutrinos Console](/articles/concepts-publication/neutrinos-console)
- [Server Services Designer](/articles/concepts-publication/server-services-designer)
- [Client Services Designer](/articles/concepts-publication/client-services-designer)
