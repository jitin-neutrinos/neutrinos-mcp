# Data Definition Language

<https://documentation.neutrinos.com/articles/#!concepts-publication/data-definition-language>

Data definition languages are the scripts used to create or re-create database schema objects.

With Neutrinos Data Model editor, you can easily download the data definition language (DDL) statements for a [Database Model](/articles/concepts-publication/database-model).

To generate DDL of a [database Model](/articles/concepts-publication/database-model):

1. Navigate to data model explorer.
2. Right-click on the Data Model > Click Download DDL.
