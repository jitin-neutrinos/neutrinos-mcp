# Studio Workspace

<https://documentation.neutrinos.com/articles/#!concepts-publication/studio-workspace>

A workspace is a repository that contains files for one or more application projects. Where an application project is the set of files that comprise a standalone application or a shareable library.

You create a new workspace when you choose the folder in which you want to install Neutrinos Studio.

After which the workspace remains the same every time you launch the Studio. All the apps in the workspace will be loaded when Neutrinos Studio is launched.

The concept of a workspace enables you to:

- Configure settings that only apply to applications on that workspace.
- Persist task and debugger launch configurations that are only valid in the context of that workspace.
- Store and restore UI state associated with that workspace (for example, the files that are opened).
- Selectively enable or disable extensions only for that workspace.
