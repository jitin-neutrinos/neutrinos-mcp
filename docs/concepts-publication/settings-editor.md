# Settings Editor

<https://documentation.neutrinos.com/articles/#!concepts-publication/settings-editor>

The **Settings** editor is used to configure the following in your application:

- [Identity Server](/smart/project-sample-how-to-guide/configure-your-ids)
- [Process Manager](/smart/project-sample-how-to-guide/configure-pm2)
- [Logger Settings](/smart/project-sample-how-to-guide/configure-logger)
- [Progressive Web App](/smart/project-sample-how-to-guide/convert-to-progressive-web-app)

Click **Settings** on the editor pane of the [Studio Application page](/articles/concepts-publication/studio-application-page/a/h3__348108846) to access the editor.
