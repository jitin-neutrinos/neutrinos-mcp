# Client Services Designer

<https://documentation.neutrinos.com/articles/#!concepts-publication/client-services-designer>

**Client Service Designer (CSD)** is a flow designer that you use to create [client services](/articles/concepts-publication/services/a/h3__1934523797) and design your business logic. With CSD, you can create and configure client services with ease by dragging and dropping client nodes and creating flows.

CSD can comprise of services with one or more flows, and each flow can comprise [client nodes](/smart/project-service-designer-user-s-guide/palette) to perform an operation.
