# Proxy Server

<https://documentation.neutrinos.com/articles/#!concepts-publication/proxy-server>

A proxy is a server that is adjusted between a client and one or more other servers. The proxy intercepts all requests from that client and decides to which server the request needs to be forwarded. As soon as the server has responded, the proxy will return the response to the client.

Proxy servers are an integral part of any organizational environment. They should improve corporate and institutional security, anonymize and balance web traffic, accelerate and save network transfer speed, and control worker web utilization.
