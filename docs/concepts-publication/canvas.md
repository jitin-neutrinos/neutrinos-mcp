# Canvas

<https://documentation.neutrinos.com/articles/#!concepts-publication/canvas>

Canvas


 It is the main editor where you design the application. You:
 Drag and drop nodes from the [nodes palette](/articles/concepts-publication/palette/a/h4__1538579060) and wire them together to design flows.
 ![design flows on canvas](/resources/Storage/concepts-publication/canvas_flow.png)



 Drag and drop [components](/articles/concepts-publication/component) from the [component palette](/articles/concepts-publication/palette/a/h4_1518247481) and design the page UI.
 ![design UI on canvas](/resources/Storage/concepts-publication/canvas_ui.png)








 Header of the CanvasWhen you access the canvas to design flows, the header of the canvas contains buttons to:Toggle grid - which is a series of intersecting straight lines used to structure flows. [Import and export services](/smart/project-sample-how-to-guide/import-and-export-services)Zoom in and out the canvas area, as well as to reset to the default zoom level. Toggle minimap - where the minimap provides a scaled-down view of the entire canvas, highlighting the area currently visible. That area can be dragged around the navigator to quickly jump to other parts of the workspace. It is also useful for finding nodes that have been lost to the further edges of the canvas.

 ![header of the canvas](/resources/Storage/concepts-publication/canvas%20header.png)
