# Types of Data Models

<https://documentation.neutrinos.com/articles/#!concepts-publication/legacy-data-model>

A data model determines the logical structure of data. It determines the manner in which data can be stored, organized, and manipulated. That is, it identifies the data, the data attributes, and the relationships or associations with other data.

Designing data models using the Data Model editor on Neutrinos Studio will give you the advantage of using the Data Model API's directly from the HTML templates on events. This is possible as all the Data Model operations ( such as get(), put(), getId(), etc.) gets auto-generated during the page creation and are available within themselves.

### Types of Data Models

You can design two types of data models in your application:

**Simple Data Model**: This comprises simple attributes that are of primitive types such as string, integer, Date, Boolean and any. **Complex Data Model**: This uses complex and abstract modeling to capture nested or repetitive data, such as JSON data of an address, person, or client.
