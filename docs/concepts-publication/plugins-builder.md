# Plugins Builder

<https://documentation.neutrinos.com/articles/#!concepts-publication/plugins-builder>

The Plugins Builder provides you with a user interface to create your own [plugins](/articles/concepts-publication/plugin). You can access it by clicking **Plugins > Plugin Builder** on the Studio Application page.

Using this builder you can create nodes that can be consumed from the [Page designer](/articles/concepts-publication/page-designer), [Client Services Designer](/articles/concepts-publication/client-services-designer), and [Server Services Designer](/articles/concepts-publication/server-services-designer).
