# Plugins

<https://documentation.neutrinos.com/articles/#!concepts-publication/plugin>

### Plugins

A plugin is a reusable object that speeds up application creation and delivery. It can be either an application or a module that provides additional features. After you create a plugin, there are three possible outcomes:

- It can modularize your code to be reused within your application
- It can be reused in more than one applications

Using Plugins, developers can build high-quality app components, templates, angular and node packages, and nodes and share them with others, boosting application development time.

On Neutrinos Studio, a Plugin is a collection of packages. The package can contain a:

- [Component](/articles/concepts-publication/component)
- [Angular package](/articles/concepts-publication/angular-package)
- [Node](/articles/concepts-publication/node)
- [App template](/articles/concepts-publication/app-templates)

You can also create a combination of components, nodes, and Angular packages as a plugin.

#### Global Plugins

Plugins that are downloaded on the Neutrinos Studio Home page are called** global plugins**. These plugins can be used across apps created on Neutrinos Studio.

#### App Plugins

Plugins that are downloaded in an app are specific to that app and are called **App Plugins**. They can be managed from the Studio Application page.
