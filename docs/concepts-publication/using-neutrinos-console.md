# Home

<https://documentation.neutrinos.com/articles/#!concepts-publication/using-neutrinos-console>

Navigate to [https://console.neutrinos.co/](https://console.neutrinos.co/) and sign-in to Neutrinos Console with your credentials.

![](/resources/Storage/concepts-publication/console_new.png)

The Console provides you with these menus to perform specific tasks:

### Home

You download the Neutrinos Studio from the Home page. Click **Download for Windows** to download the windows version of the studio, or select the platform of your choice to download the respective package.

### Apps

Any app that is deployed by a user is visible to other users, provided they are part of the same organization, from the **Apps** page of Neutrinos Console. Each card on the Apps page displays the following information about the app:

- App name
- Description
- App created time
- App last successful build time
- Last build status

Using the card, you can:

Download the .apk file for Android devices (If the Android build was scheduled and successfully completed previously)Access the Web build link (If Web build was scheduled and successfully completed previously) Redeploy the app (if the app is deployed at least once)Click on a card and select any of the apps builds to view the complete build information. Use the **Refresh** icon at bottom of each panel to refresh the build timeline. To download the build logs, click the **Download Log File **icon.Users![console users](/resources/Storage/concepts-publication/console_users.png)
