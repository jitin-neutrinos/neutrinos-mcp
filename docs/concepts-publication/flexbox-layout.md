# Flex container

<https://documentation.neutrinos.com/articles/#!concepts-publication/flexbox-layout>

The **Flexbox Layout** or **Flex Layout **is a module that aims at providing a more efficient way to layout, align, and distribute space among **flex items** in a **flex container**, even when their size is unknown and/or dynamic (thus the word “flex”).

#### Flex container

An area of a document laid out using a flexbox.

#### Flex Item

The component placed inside the flex container.

![Flex container](/resources/Storage/concepts-publication/flex%20container.png)

The main idea behind the flex layout is to give the container the ability to alter its items' width/height (and order) to best fill the available space (mostly to accommodate all kinds of display devices and screen sizes). A flex container expands items to fill available free space or shrinks them to prevent overflow.

When working with flexbox you should think in terms of two axes — the **main axis** and the c**ross axis.**

#### Main Axis

It is the primary axis along which flex items are laid out. The main axis for a row runs from left to right and the main axis for a column runs from top to bottom.

#### Cross Axis

The axis perpendicular to the main axis is called the cross axis. The cross-axis for a row runs from top to bottom and the cross axis for a column runs from left to right.
