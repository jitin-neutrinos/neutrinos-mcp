# Process manager

<https://documentation.neutrinos.com/articles/#!concepts-publication/process-manager>

When you run your application in the production environment, it is helpful to use a process manager to:

- Restart the app automatically if it crashes.
- Gain insights into runtime performance and resource consumption.
- Modify settings dynamically to improve performance.
- Control clustering.

A process manager is like an application server for applications that facilitates deployment, provides high availability, and enables you to manage the application at runtime. It manages your application states so that you can start, stop, restart, and delete processes.
