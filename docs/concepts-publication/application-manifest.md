# Application Manifest

<https://documentation.neutrinos.com/articles/#!concepts-publication/application-manifest>

The web application manifest is a JSON file that tells the browser about your [Progressive Web App](/articles/concepts-publication/progressive-web-app)(PWA) and how it should behave when installed on the user's desktop or mobile device. A typical manifest file includes the app name, the icons the app should use, and the URL that should be opened when the app is launched.

Manifest files are supported in Chrome, Edge, Firefox, UC Browser, Opera, and the Samsung browser. Safari has partial support.
