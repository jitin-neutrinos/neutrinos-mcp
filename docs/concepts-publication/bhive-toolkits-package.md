# bhive-toolkits package

<https://documentation.neutrinos.com/articles/#!concepts-publication/bhive-toolkits-package>

**@jathworx/bhive-toolkits** is an npm package that contains various classes to make a complete plugin for Neutrinos Studio. This package is installed as a default dependency for the workspace plugins. After opening Neutrinos Studio, you can access this package in the **$Home/.neutrinos/plugins/marketplace-components/node_modules/@jatahworx** folder.
