# Server Services Designer

<https://documentation.neutrinos.com/articles/#!concepts-publication/server-services-designer>

**Server Service Designer (SSD)** is a flow designer that you use to create [server services](/articles/concepts-publication/services/a/h3_1880384879) and design your business logic. With SSD, you can create and configure server services with ease by dragging and dropping service nodes and creating flows.

Server services are comprised of one or more flows, and each flow is comprised of nodes that perform an operation. For example, here we have a service named **ids** which has a flow to log the user out. The flow is comprised of nodes that perform operations and helps achieve the end result that you want your server flow to perform when executed.

Learn about the SSD [Properties](/articles/server-side-service-designer-publication/properties-in-server-services) before creating a server service.
