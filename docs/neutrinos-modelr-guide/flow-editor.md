# Flow Editor

<https://documentation.neutrinos.com/articles/#!neutrinos-modelr-guide/flow-editor>

## Flow Editor

The main workspace is where flows are developed by dragging nodes from the palette and wiring them together. The workspace has a row of tabs along the top; one for each flow and any subflows that have been opened.

### View Tools

The footer of the workspace contains buttons to zoom in and out as well as to reset to the default zoom level. It also contains a toggle button for the view navigator.

![Workspace footer with view navigator](/resources/Storage/neutrinos-modelr-guide/view_navigator.png)

The view navigator provides a scaled-down view of the entire workspace, highlighting the area currently visible. That area can be dragged around the navigator to quickly jump to other parts of the workspace. It is also useful for finding nodes that have been ‘lost’ to the further edges of the workspace.

### Customizing the View

The workspace view can be customized via the **View** tab of the User Settings dialog.

![View tab](/resources/Storage/neutrinos-modelr-guide/view_tab.png)
