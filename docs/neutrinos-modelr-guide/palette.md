# Palette

<https://documentation.neutrinos.com/articles/#!neutrinos-modelr-guide/palette>

## Palette

The palette contains all the nodes that are installed and available to use.

They are organized into a number of categories, with inputs, outputs, and functions at the top. If there are any subflows, they appear in a category at the top of the palette.

Categories can be expanded or collapsed by clicking its header. Above the palette is an input that can be used to filter the list of nodes.

### Palette Manager

![Palette Manager](/resources/Storage/neutrinos-modelr-guide/palette%20manager.png)

The Palette Manager can be used to install new nodes into the palette. It can be accessed By clicking menu and selecting **Manage Palette **dialog.

The Palette Manager has two tabs:

- **Nodes** list the modules that are currently installed in the runtime
- **Install** lists the available modules that can be installed

### Managing Nodes

Each entry in the Nodes list shows the name and version of the module along with a list of the individual node types the module provides. Options are provided to remove, disable or upgrade each module. If a node is currently in use within the flow, it cannot be removed or disabled.

### Installing Nodes

The Install tab can be used to search for available modules and install them.

To search for a module, enter its name in the search bar. The search results show the details of the modules, including when it was last updated and a link to its documentation. It can be installed by clicking the **install **button.
