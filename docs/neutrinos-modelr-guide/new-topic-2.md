## Learn About Neutrinos Modelr

Neutrinos Modelr allows you to visually model your application services to link to a variety of backend systems such as Enterprise Service Bus (ESB), Cloud Services, databases, etc. It provides a large number of widgets to external systems such as Salesforce, IBM Watson, BPM Engines, etc., as well as connectivity to the Internet of Things(IoT) devices.

Neutrinos Modelr is built on Node.js, taking full advantage of its event-driven, non-blocking model. This makes it ideal to run at the edge of the network on low-cost hardware such as the Raspberry Pi as well as in the cloud.

Using Neutrinos Modelr:

- You can model services over protocols such as HTTP/S and MQTT/S, with runtime environments supported on hardware devices such as Raspberry Pi and BeagleBone Black.
- You can build micro-services or develop applications such as a suite of independently deployable, small, modular services that can run and communicate through a well-defined, lightweight mechanism.
- You can integrate with external services such as social media, cognitive (Watson, Azure) and other third-party services.
- You can integrate with internal services such as email, sms, the organizational database core system of records and the ESB.

By default, Neutrinos Modelr has Dev and Prod Environments. The Dev environment comes bundled with Neutrinos Studio, and the runtime environment comes bundled with Neutrinos Art.
