## Modelr Home Page

To open Modelr, click ![Modelr icon](/resources/Storage/neutrinos-modelr-guide/modelr.png) on the Studio Application page. The Modelr home page opens up for you.

![](/resources/Storage/neutrinos-modelr-guide/modelr1.png)

The page has several sections:

![Sections in the B Modelr page](/resources/Storage/neutrinos-modelr-guide/modeler_home.png)

- **Palette**: The palette contains all the nodes that are installed and available to use. Nodes are grouped based on its category. Each node is of a specific type and performs a specific task. You can search for nodes by expanding each section, or by using the search functionality on the top of the palette.
- **Flow Editor**: The flow editor provides you with a canvas to create flows by connecting two or more nodes.
- **Sidebar**:
  - **Info ![](/resources/Storage/neutrinos-modelr-guide/inf.png)**: This tab provides information about the node.
  - **Debug** ![](/resources/Storage/neutrinos-modelr-guide/debug.png): This tab allows you to debug a flow. Add a **Debug** node to the flow and inspect this tab to view and debug error messages.
  - **Config**: This tab provides a list of all config nodes, organized by their scope.
  - **Context**: This tab displays the contents of the context data store.
- **Header:**
  - **Menu** ![Menu icon](/resources/Storage/neutrinos-modelr-guide/menu.png): This drop-down list provides view options, Import and export features, adding/renaming and deleting flows and sub-flows, and manage palette options.
  - **Deploy** ![Deploy button](/resources/Storage/neutrinos-modelr-guide/deploy.png): After creating a flow, you deploy it by clicking the **Deploy** button. It provides you with the following options:
    - **Full Deploy**: Deploys everything in the workspace
    - **Modified Flows**: Only deploys flows that contain changed nodes
    - **Modified Nodes**: Only deploys nodes that have changed
    - **Restart Flows**: Restarts the current deployed flows
