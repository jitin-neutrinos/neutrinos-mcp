**How do I log in to NeuSRM?**

To access the login page of the application, enter the URL "srm.neutrinos.co" in the browser. Once on the login page, one can login via either of the three login mechanisms as opted by the organisation:

- Neutrinos IDS managed username and password
- Google AD Account
- Azure AD Account

To login, one needs to input the username and password and upon successful validation the user is re-directed to the application's home page.

**What is a Contact?**

**A contact in the NeuSRM is referred to as a 'qualified lead'. A contact is typically an individual you do business with and representative of the transactions in your account.**

**How do I create a new contact?**

To create a new contact, perform the following:

Click '**Add' button** on the Home-screen and select '**Contact'**.

In the Add Contacts side-nav panel, enter the following data:

**First Name**: The first name of the contact. This is a mandatory field.

**Last Name**: The last name of the contact.

**Mobile Numbe**r: The mobile number of the contact. Select the country code and enter the mobile number. This is a conditional mandatory field.

**Email Address**: The email address of the new contact. This is a conditional mandatory field.

After entering all the data, click **Add**, and the contact gets added.

**How do I bulk import contacts?**

- To bulk import contacts, perform the following steps:
  - Click on the '**Add'** button and select '**Import Contacts'**.
  - From the Import Contacts window, download the **S****ample CSV**.
  - In the downloaded sample CSV, enter details of the contacts you want to import.
  - After entering the contact details, upload the excel sheet in the same Import Contacts either by dragging and dropping the file or by browsing the file from local machine.
  - Click '**Import' button** and the file is sent for processing.

- To view the 'Status' of the file, click on 'Import Contact' module from the side-menu and track the progress of the file.
- Once the file is 'Processed' successfully, the user can assign the contacts either to self or to any other user reporting under him/her.

Process of import contact.

Once the user uploads the .csv file via 'Import Contacts' option in 'Add' section, the file is sent to the system for processing. Whilst the system starts validation checks on the uploaded the file, the status of the file is displayed as 'Processing'. If the format of the file isn't valid, the status is updated to 'Invalid File' and the user cannot perform any further action apart from downloading the file to view the status of each record.

Upon successfully validating the file the status of the file is updated to 'Pending Assignment', also the system displays the total 'Valid' and 'Invalid' count of records that the user is trying to import. For the invalid records, the user can create another file with corrections and re-upload the file for processing.

In 'Pending Assignment' status, the user can perform below actions on the file:

- Download the file to view the reason of valid and invalid records
- Cancel Assignment
- Assign to users

To 'Assign' the valid records to self or to any other user within the system, the user can click on 'Assign to user' option against the file record and select the user and the count of records to be assigned to the user via a side-nav panel. The user needs to click on 'Assign' button to successfully execute the action.

If the user didn't assign all the valid records from the file, then 'Assign to User' option will still be available with the status still as 'Pending Assignment' else the option will disappear and the status of the file will be updated to 'Assignment Complete'.

Once the assignment of all valid records is done, the user will only be allowed to download the file and will not be able to cancel the assignment or assign to more users.

How to join the video call?

Once a video call is scheduled, both the agent and the contact will receive a meeting invite from the system on their registered/added email id.

To join the meeting/video conference session, an agent or a contact needs to perform below steps:

- Login/access the email id registered/added in NeuSRM account.
- Click on the email/meeting invite received.
- Click on 'join now' link.
- Neutrinos meet platform opens up allowing the agent or the contact to successfully join in to the meeting.
