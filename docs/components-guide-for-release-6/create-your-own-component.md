## Create and Publish a Component

By default, Neutrinos Studio provides you a list of palette components for you to design your app pages. See [Default Palette Components](https://docs.neutrinos.co/components-6-0-0/) to learn more.

Apart from the existing components, if you want to create your own component, perform these steps:

1. [Create a Studio Package](/articles/components-guide-for-release-6/create-a-studio-package)
2. [Create a Component](/articles/components-guide-for-release-6/create-a-component)or [Create an advanced component](/articles/components-guide-for-release-6/create-an-advanced-component)
3. [Package the Component](/articles/components-guide-for-release-6/create-a-package)
4. [Import and test the component in Neutrinos Studio](/articles/components-guide-for-release-6/test-a-component-in-studio)
5. [Publish to MarketPlace](/articles/components-guide-for-release-6/publish-to-marketplace)
