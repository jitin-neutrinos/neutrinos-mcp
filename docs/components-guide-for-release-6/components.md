# Components

<https://documentation.neutrinos.com/articles/#!components-guide-for-release-6/components>

Components are basic building blocks of an app page. It is one of the most important aspects of low-code platforms, which enable the reusability of code and speeds up application creation and delivery.

Neutrinos Studio comprises a range of components that implement common interaction patterns according to the Angular Material Design specification.
