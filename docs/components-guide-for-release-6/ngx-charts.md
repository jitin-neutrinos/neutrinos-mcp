## NGX Charts

NGX Charts uses Angular to render and animate the SVG elements with all of it's binding and uses d3 for math functions, scales, axis and shape generators, etc. By having Angular do all of the rendering it opens us up to endless possibilities the Angular platform provides such as AoT, Universal, etc.
