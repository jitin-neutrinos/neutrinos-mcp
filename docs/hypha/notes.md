# Example Scenario

<https://documentation.neutrinos.com/articles/#!hypha/notes>

Notes are lightweight, free-form text entries that users can attach to any individual record within an object. They serve as an easy way to capture contextual information that may not be represented through the object’s structured fields.

Notes help users document insights, decisions, or updates related to a specific record. They improve collaboration and provide historical context without altering the record’s core data model.

## Example Scenario

If a Sales Lead record requires follow-up, a user can add a note such as "Customer requested a call next Monday to discuss pricing." This comment remains attached to the record and is visible to anyone accessing that Lead.

## Add Notes

To add a note to a specific record within an object, follow the steps below:

- Navigate to the object, open the required record, and go to the Note tab from the record’s details page.
- The Notes tab displays all notes associated with the record, helping users gain clarity and additional context about the record. If no notes are available, the tab displays a message explaining the purpose of notes and how they can support better context sharing and communication among collaborators.
    ![hypha-object-related-objects-notes-landing-page](/resources/Storage/hypha/images/hypha-object-related-objects-notes-landing-page.png)
- Add notes for the object record using the editor available in the **Notes** tab, and then click Add to save the note.
    ![hypha-object-related-objects-notes-add-note](/resources/Storage/hypha/images/hypha-object-related-objects-notes-add-note.png)
- To modify an existing note for a record, update the note content and click the Edit option available from the kebab (three-dot) menu.
   ![hypha-object-related-objects-notes-edit-note](/resources/Storage/hypha/images/hypha-object-related-objects-notes-edit-note.png)
   After modifying the note, click the Update button, as illustrated in the image below.
    ![hypha-object-related-objects-notes-update](/resources/Storage/hypha/images/hypha-object-related-objects-notes-update.png)
- All notes added to a record are displayed in a conversational format, allowing you to track the sequence in which the notes were added.
    ![hypha-object-related-objects-notes-landing-page](/resources/Storage/hypha/images/hypha-object-related-objects-notes-landing-page.png)

## Delete Notes

To delete a note, follow the steps below:

- Navigate to the object, open the required record, and go to the Note tab from the record’s details page.
- Select the note you want to delete and click the kebab (⋮) icon next to it. From the kebab menu, select Delete to open the confirmation prompt.
   ![hypha-object-related-objects-notes-delete-note](/resources/Storage/hypha/images/hypha-object-related-objects-notes-delete-note.png)
- Click Yes to confirm the deletion of the note.
    ![hypha-object-related-objects-notes-delete](/resources/Storage/hypha/images/hypha-object-related-objects-notes-delete.png)
