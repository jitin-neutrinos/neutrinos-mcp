# Delete Operation

<https://documentation.neutrinos.com/articles/#!hypha/delete-operation>

The Bulk Delete feature in Hypha allows users to delete multiple values from a table in a single action. This functionality is useful when cleaning up data, removing obsolete entries, or managing large volumes of information efficiently. Instead of deleting each record individually, users can select several records at once and perform a unified delete operation.

To delete multiple records on the object page, select the required records in any tab by checking the boxes next to each one. After selecting the desired set of records, click the Delete button at the top of the page to remove them.




 ![hypha-objects-bulk-delete](/resources/Storage/hypha/images/hypha-objects-bulk-delete.png)

Once the delete operation is successful, the records are moved to the Recycle Bin, and a confirmation toast message is displayed to the user.




 ![hypha-objects-bulk-delete-success](/resources/Storage/hypha/images/hypha-objects-bulk-delete-success.png)
