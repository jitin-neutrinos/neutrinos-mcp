# Object Details

<https://documentation.neutrinos.com/articles/#!hypha/object-details>

The Object Details page in Hypha provides a comprehensive view of a selected object record. It displays all relevant information and metadata associated with that record, offering users a consolidated overview in a single screen. This page helps users understand the record’s field values, related objects, and any operational configurations—such as associated pipelines defined within the environment.

The Object Listing page displays all records associated with the selected object. It provides a tabular view of each record and shows the values for all fields defined within that object’s schema.




 ![hypha-objects-new-record-landing-page](/resources/Storage/hypha/images/hypha-objects-new-record-landing-page.png)

To view the details of a specific record from the Object Listing page, click the record you want to open. The Object Details page displays in-depth information about the selected record, including its field values, the pipeline it is associated with, and its current status. For example, if the object is Leads, the record status may be Contacted, Qualified, Proposal Sent, Negotiation, Closed, and so on.

The information for every record within an object is organized into dedicated tabs such as Details, Related Objects, Documents, Notes, and Activity:

- Details: Shows all field values and core information of the record.
- Related Objects: Displays associations with other objects linked to the record.
- Documents: Lists the documents attached or uploaded to the record.
- Notes and Activity: Provides notes added to the record and logs user activities or interactions related to it.
- Tasks: Provides the list of tasks that represent discrete units of work associated with an object record. These tasks are designed to drive process execution, enable collaboration, and support operational follow-ups.

Record details can be edited by updating the fields on the Details page. Additionally, the status of a record can be updated using the Stage drop-down menu at the top of the Object Details page. From this menu, select the appropriate stage to reflect the record’s current position in its pipeline.
