# Modules

<https://documentation.neutrinos.com/articles/#!hypha/modules>

In Hypha, a module is a logical, self-contained unit that groups related functionality, configurations, and data models to address a specific business capability or use case. Modules help organize the platform into manageable building blocks, making solutions easier to design, develop, deploy, and maintain.
