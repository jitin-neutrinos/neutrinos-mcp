# Role of Fields

<https://documentation.neutrinos.com/articles/#!hypha/fields>

The term fields typically refers to individual data elements or attributes within a dataset, much like columns in a table. However, depending on the layer of the Hypha architecture you're referring to—metadata, data models, or actual data—it can have slightly different nuances.

# Role of Fields

| **Layer  ** | **  Role** |
| --- | --- |
| Data Ingestion | Fields are extracted from source systems and mapped to a unified schema. |
| Metadata Management | Fields are described, classified, and linked using metadata for data discovery. |
| Data Governance | Fields are tagged for lineage, sensitivity (e.g., PII), and access control. |
