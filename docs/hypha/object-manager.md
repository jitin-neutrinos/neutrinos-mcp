# Interface

<https://documentation.neutrinos.com/articles/#!hypha/object-manager>

Log in to Studio using your credentials. After successfully logging in, navigate to Objects from the left navigation panel. The Objects page displays a list of all objects available on the platform. From this page, you can view the existing objects associated with your organization and create new objects as required.




 ![hypha-studio-object-manager-landing](/resources/Storage/hypha/images/hypha-studio-object-manager-landing.png)

## Interface

![hypha-studio-object-manager-interface](/resources/Storage/hypha/images/hypha-studio-object-manager-interface.png)

1. Navigation Panel: The left navigation panel enables you to move between the various components of the platform.
  - The Projects tab allows you to view and open all projects available on the platform. From this section, you can also create new projects.
  - The Custom Code tab allows you to view and open all global custom code available on the platform. From this section, you can also add new custom code.
  - The Objects tab allows you to view all objects available on the platform. From this section, you can create new objects and add them to existing projects.
2. The table lists all objects available on the platform. It includes the following columns, each displaying the corresponding information:
  - Name: Displays the name of the corresponding object.
  - Description: Displays a brief description of the corresponding object.
  - Created Date: Displays the creation timestamp of the corresponding object.
  - Last Updated: Displays the timestamp of the most recent modification to the corresponding object.
  - Actions: Provides a kebab icon to access additional operations, such as edit and delete.

## Create Object

To create an object on the platform, follow these steps:

1. From the left navigation panel, select Objects.
    ![hypha-studio-object-manager-navigate](/resources/Storage/hypha/images/hypha-studio-object-manager-navigate.png)
2. In the Object Manager, click the Create button at the top of the page.
    ![hypha-studio-object-manager-create-button](/resources/Storage/hypha/images/hypha-studio-object-manager-create-button.png)
3. In the pop-up window, enter the object name, provide a description, and select an icon for the object.
    ![hypha-studio-object-manager-new-object-details](/resources/Storage/hypha/images/hypha-studio-object-manager-new-object-details.png)

**Note**: If no objects are present, an empty list is displayed, prompting the user to create an object, as illustrated in the image below.



![hypha-studio-object-manager-empty-list](/resources/Storage/hypha/images/hypha-studio-object-manager-empty-list.png)
