# Related Objects

<https://documentation.neutrinos.com/articles/#!hypha/related-objects>

The Related tab on a record’s details page displays all objects associated with that specific record. To view these related object details, open the record from the required object’s listing page and navigate to the Related tab. This section provides a consolidated view of all relationships the record has with other objects defined in the schema.
