# Interface

<https://documentation.neutrinos.com/articles/#!hypha/workspace>

A workspace is a logical container that provides an isolated and organized environment for managing and operating data-related assets. It serves as a boundary for grouping resources based on a specific project or organizational unit. The workspace or project interface is illustrated in the image below.




 ![hypha-workspace-landing-page](/resources/Storage/hypha/images/hypha-workspace-landing-page.png)

## Interface

- The workspace name is displayed at the top of the page, indicating the currently active workspace.
- The workspace lists all projects that the user has access to. The list can be displayed as thumbnails, or list view.
- If a user has access to multiple projects, they can use the search bar at the top of the page to locate a specific project within the workspace.
- Click the Refresh button next to the search bar to reload the workspace.
- You can toggle between project display modes—thumbnail view and list view—by clicking the four-tile icon or the list icon located next to the Refresh button at the top of the page. The image below illustrates the workspace layout when the list view is selected.
    ![hypha-workspace-landing-page-list-view](/resources/Storage/hypha/images/hypha-workspace-landing-page-list-view.png)
