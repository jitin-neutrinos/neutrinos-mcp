# View Tasks

<https://documentation.neutrinos.com/articles/#!hypha/tasks>

tasks represent discrete units of work that are associated with an object record and are intended to drive process execution, collaboration, and operational follow-ups. Tasks enable users and systems to track, assign, and complete activities required to move an object record through its defined lifecycle.

Each task is contextually linked to an object record (for example, a Lead, Policy, Case, or Claim), ensuring that all actions performed are traceable and auditable within the scope of that record.

## View Tasks

To view the tasks associated with a specific object record, follow these steps:

1. On the **Object Records** page, click the required record to view its details.
2. On the **Object Details** page, click **Tasks** in the left navigation panel. This action filters and displays all pending tasks associated with the selected object record, as illustrated in the image below.
