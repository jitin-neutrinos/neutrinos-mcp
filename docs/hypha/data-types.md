# Data Types

<https://documentation.neutrinos.com/articles/#!hypha/data-types>

Data types refer to the nature and format of the data being managed, processed, or integrated across the ecosystem. The data types refer to the fundamental types of data that can be defined within a data model or schema used to describe and manage data objects.

These data types are often used to define fields or attributes in structured or semi-structured data and are foundational to enabling interoperability across systems.

| **Data Type** | **Description** | **Example** |
| --- | --- | --- |
| String | Textual Data | "Hello World" |
| Integers | Whole Numbers | 42 |
| Float/Double | Decimal Numbers | 3.14159 |
| Boolean | True/ False values | true, false |
| Date | ISO Date (YYYY-MM-DDTHH:mm:ss.sssZ) | 2025-09-03T17:15:00.000Z |
