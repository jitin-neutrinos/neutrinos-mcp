# Add a Node Package

<https://documentation.neutrinos.com/articles/#!project-plugins-builder-guide/create-a-node-package>

To add a node package:

1. Open Plugins Builder and click the **Add Node Package +** button.
2. Enter a **Package name** and click **Add**. The new package gets added to the package list.
3. From **Choose node package** drop-down list, select the package that you added. Click on the editors to provide respective details.

![Select package](/resources/Storage/project-plugins-builder-guide/Selectpackage.png)

After a package is created, you can provide package details, add npm dependencies and create nodes.
