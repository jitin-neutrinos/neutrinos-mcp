# Publish the Node Package

<https://documentation.neutrinos.com/articles/#!project-plugins-builder-guide/publish-the-node-package>

After creating the node, the next step is to test the node that you have created.

Click the **Publish this package** button on the Plugin Builder to publish the package locally. This will install the published package as a plugin at the workspace (global) level in the **$Home/neutrinos-plugins** directory.

To test the plugin:

1. Open an app.
2. In the Studio Application page, click **Plugins** on the top navigation. Add the plugin to the app. For example:
    ![](/resources/Storage/project-plugins-builder-guide/add%20plugin.png)
3. Open the respective Designer and create a service flow to test the node's appearance and functionality.
