# Export for Production Publish

<https://documentation.neutrinos.com/articles/#!project-plugins-builder-guide/export-for-production-publish>

After testing the functionality of the node, use the **Export to Production Publish** button to export your node package as a .zip file to your local machine.

Submit the .zip file to Neutrinos by raising a support ticket on [support@neutrinos.co](mailto:support@neutrinos.co). The Neutrinos team will review the plugin and upload it to [Neutrinos Store](/smart/project-concepts/neutrinos-store).
