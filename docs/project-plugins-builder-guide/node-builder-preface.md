 **Release 8**




 This guide describes how to create a node/connector by using the [Plugins Builder](/smart/project-concepts/plugins-builder) on Neutrinos Studio. It is intended for application developers and backend developers who are building their applications on the Neutrinos Platform. To use this guide, you must have a general understanding of Angular, JQuery, and JavaScript.
