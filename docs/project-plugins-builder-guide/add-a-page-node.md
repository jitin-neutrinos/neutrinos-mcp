# Add a Page Node

<https://documentation.neutrinos.com/articles/#!project-plugins-builder-guide/add-a-page-node>

| ![Information](/resources/Storage/project-plugins-builder-guide/info.png) | Before you add a node, learn about the [types of nodes](/smart/project-concepts/node/a/h3__1155479691) in Neutrinos Studio. |
| --- | --- |

To add a page node:

1. Expand **Nodes** and click the plus icon next to the **page **option.  ![Add a page node](/resources/Storage/project-plugins-builder-guide/page_pb1.png)
2. Enter the name of the node that you want to create and press the **Enter **button. Make sure you name the node based on its functionality. The node gets added under the pages section. Expand the node to view the editors that you can use to customize the node. ![Adding a node name](/resources/Storage/project-plugins-builder-guide/page_pb2.png)
3. Enter the [node details](/articles/project-plugins-builder-guide/node-details).
4. Define the [node attributes](/articles/project-plugins-builder-guide/node-attributes).
5. Add the [node dependencies](/articles/project-plugins-builder-guide/node-dependencies).
6. Define the [code generation](/articles/project-plugins-builder-guide/code-generation) logic.
7. Add the required [node utility](/articles/project-plugins-builder-guide/node-utils) files.
8. [Export to Production Publish](/articles/project-plugins-builder-guide/export-for-production-publish) to test the node in the Services designer.
9. [Publish](/articles/project-plugins-builder-guide/publish-the-node-package) the Package.
