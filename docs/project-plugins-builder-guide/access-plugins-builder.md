# Accessing Plugins Builder

<https://documentation.neutrinos.com/articles/#!project-plugins-builder-guide/access-plugins-builder>

To access the [Plugins Builder](/smart/project-concepts/plugins-builder) on Neutrinos Studio, perform the following steps:

1. Launch Neutrinos Studio.

2. On the Studio home page or the Studio Application page, click **Plugins **on the top navigation, and select **Plugins Builder**. You can also use the shortcut key **Ctrl****+b** to open the Plugins Builder.
