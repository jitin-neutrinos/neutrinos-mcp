# Installation on MAC

<https://documentation.neutrinos.com/articles/#!console-quick-links/install-studio>

Install Studio on your machine.

### Installation on MAC

To install Neutrinos Studio on Mac, perform the following steps:

1. Sign in to [Neutrinos Console](https://console.neutrinos.co/web/) with your username and password.
2. On the **Home** page of the Neutrinos Console, select **Mac **and click the** Download** button to download Neutrinos Studio. The executable file gets downloaded to your local machine.
3. Open the downloaded file to install it.
4. After installing, if you are not able to launch the Neutrinos Studio, perform the following
  1. Open security and privacy settings on your Mac machine.
  2. In the General section, make sure you have selected the **App Store and identified developers** in the **Allow apps downloaded from** section. Click the **Open anyway** option.
  3. A warning prompt appears, click **Open,** and the studio launches.
5. You will be directed to the Studio home page.

Refer [Apple Documentation](https://support.apple.com/en-in/HT202491) to know more.

### Installation on Windows and Ubuntu

To install Neutrinos Studio on windows, perform the following steps:

1. Sign in to [Neutrinos Console](https://console.neutrinos.co/) with your username and password.
2. On the **Home** page of the Neutrinos Console, windows is chosen by default. In the case of Ubuntu, select Ubuntu from the drop-down and click the** Download** button. The executable file gets downloaded to your local machine.![Comsole homepage](/resources/Storage/console-quick-links/app-builder-s-user-guide/console_new.png)
3. Install the software. The steps may differ based on the operating system you are using. On windows, double click the executable file to open the installer and install the software.![neutrinos install page](/resources/Storage/console-quick-links/project-learning-path/neuinstall.png)
4. Choose the destination folder and click **Install**.
5. Neutrinos Studio gets installed on your machine.
6. Launch the studio. You will be directed to the Studio home page. ![studio homepage](/resources/Storage/console-quick-links/project-learning-path/studio%20homeage.png)
