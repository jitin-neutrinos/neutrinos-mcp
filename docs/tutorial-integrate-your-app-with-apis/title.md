# Integrate your App with APIs in Studio 6

<https://documentation.neutrinos.com/articles/#!tutorial-integrate-your-app-with-apis/title>

![](/resources/Storage/tutorial-integrate-your-app-with-apis/gettyimages-1138262343-170x170.jpg)Tutorial: Integrate your App with APIs in Studio 6Background
Neutrinos Modelr is an application that allows you to visually model your application services to link to a variety of backend systems such as Enterprise Service Bus (ESB), Cloud Services, databases, etc. It provides a large number of widgets to external systems such as Salesforce, IBM Watson, BPM Engines, etc., as well as connectivity to the Internet of Things(IoT) devices.In this tutorial, you will be updating an existing app by creating Neutrinos Modelr flows to display the weather based on the city that the user inputs on runtime. This flow will integrate with a weather service named **Open Weather Map** to get the weather data.



 ![Information](/resources/Storage/tutorial-integrate-your-app-with-apis/info.png)


 Neutrinos Modelr is not part of Free trial. You can work with Neutrinos Modelr only if you have an existing account with Neutrinos.


**Prerequisites**Complete the [Creating a simple app tutorial](/smart/project-tutorial-leave-management-system/title) and get familiar with the Neutrinos Platform.To display the weather details in this app, you will be using **openweathermap** as your API provider. Register with the opensource weather provider and get the API key.
