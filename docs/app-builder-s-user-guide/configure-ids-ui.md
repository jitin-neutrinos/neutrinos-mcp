# Configure Authorization Pages

<https://documentation.neutrinos.com/articles/#!app-builder-s-user-guide/configure-ids-ui>

Use the IDS Config UI editor to customize the user interface of the IDS authorization pages such as login, logout, and consent pages. Using the Neutrinos IDS UI config editor saves a lot of development time and effort. It allows you to change the appearance of the IDS authorization pages to suit your company's branding guidelines and logos.

To access this editor, on the Studio Application home page, click **Settings** and select **IDS UI Config**.

There are 2 ways to customize the page elements.
