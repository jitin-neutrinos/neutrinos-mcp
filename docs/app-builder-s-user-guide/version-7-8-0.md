# Features

<https://documentation.neutrinos.com/articles/#!app-builder-s-user-guide/version-7-8-0>

### Features

Here is a list of new features added to Neutrinos Studio version 7.8.0:

- A new **Window** menu option is added to the top menu of the Studio Home and the Studio Application pages using which you can:
  - Open an instance of Neutrinos Studio in a new window.
  - Open an instance of Plugin Builder in a new window.

![Window menu](/resources/Storage/app-builder-s-user-guide/wondow_menu.png)

While building a node, you can configure the node to dynamically change its label based on a node's attribute value. See [Add the node label](/smart/project-node-builder-guide/node-attributes/a/h3__668741143) documentation to learn more.**Enhancement:** You can preserve all the changes that you have made to the settings.json file when you move from one studio version to another. Only the studioVersion and the reInstallTemplate property values are updated when the studio version changes.

Refer to the [Changelog](/smart/project-change-log/release-7-8-0) to learn about the bug fixes in this release.
