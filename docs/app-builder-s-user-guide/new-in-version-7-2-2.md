# Version 7.2.2

<https://documentation.neutrinos.com/articles/#!app-builder-s-user-guide/new-in-version-7-2-2>

Here is a list of enhancements introduced in Neutrinos Studio version 7.2.2:

**Enhancements**:

- From this release, you can enable a **Multi-tenant** authentication option in Azure AD.

![multi tenant option](/resources/Storage/app-builder-s-user-guide/Multi%20tenent.png)

- The **Add** Button is moved for **Pages**, **Models**, **Legacy services **editors on top of their list. For example:

![new add button](/resources/Storage/app-builder-s-user-guide/newadd%20butoon.png)

- Creating a **Page**, **Model**, or a **Legacy Service** automatically opens the respective editors.
- Page List is alphabetically ordered.

Upgraded dependencies related to typescript in the server app.typescript: 3.8.3@types/jsonwebtoken: 8.5.0

Refer to the [Changelog](/smart/project-change-log/release-7-2-2) for all the changes.
