# Create Legacy Services

<https://documentation.neutrinos.com/articles/#!app-builder-s-user-guide/create-legacy-services>

Angular services that cannot be configured by using the nodes provided by **Client services** are hard-coded as legacy services. Navigate to [Create legacy services](/smart/project-tutorial-leave-management-system/create-services) to see an example.

To add a legacy Service, perform the following steps:

1. Click the **Services** from the editor pane.
2. Select **Legacy Service **and click** Add New**.
3. Enter the name of the service, and click **Add**.
