# Remove a Plugin

<https://documentation.neutrinos.com/articles/#!app-builder-s-user-guide/remove-a-plugin>

To remove [global plugins](/smart/project-concepts/plugin/a/h4_324098977) from the [Studio Home page](/smart/project-concepts/studio-home-page):

1. Click** Plugins** on the top menu.
2. Click **Manage Plugins** on the Plugins manager.
3. Select the plugin you want to delete, and click **Remove**.
4. In case of an unexpected error, you can force a plugin to be removed by selecting the plugin and clicking **Force Remove**.

To remove [app plugins](/smart/project-concepts/plugin/a/h4_1634866683) from the [Studio Application page](/smart/project-concepts/studio-application-page):

1. Click **Manage Plugins** on the action menu.
2. Navigate to **App Plugins**.
3. Select the plugin you want to delete, and click **Remove**.
