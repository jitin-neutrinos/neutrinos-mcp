# Create Connectors with Plugin Builder

<https://documentation.neutrinos.com/articles/#!app-builder-s-user-guide/create-connectors-with-plugin-builder>

The [Plugin Builder](/smart/project-concepts/plugins-builder) allows you to create connectors that implement integrations between applications built on Neutrinos Studio and your enterprise Systems like SAP or Salesforce.

The plugin builder allows you to:

- Create connectors for existing systems like SAP, Salesforce, etc.
- Edit previously created connectors to add support to additional entities and attributes of the external system.

To learn how to create a connector, see the [Plugin builder guide](/smart/project-node-builder-guide/node-builder-preface).
