# Switch Workspace

<https://documentation.neutrinos.com/articles/#!app-builder-s-user-guide/switch-workspace>

## 

To change the [workspace](/articles/concepts-publication/studio-workspace), click ![Switch workspace icon](/resources/Storage/app-builder-s-user-guide/ws.png) on the Studio Home page and choose a different folder/directory.

To add and manage custom app dependencies on the workspace, see [Manage Global Plugins](/articles/app-builder-s-user-guide/manage-global-plugins).
