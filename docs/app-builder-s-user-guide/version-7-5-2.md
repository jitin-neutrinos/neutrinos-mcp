# Version 7.5.2

<https://documentation.neutrinos.com/articles/#!app-builder-s-user-guide/version-7-5-2>

Here are a few features and enhancements introduced in Neutrinos Studio version 7.5.2:

- **Proxy Setup on Neutrinos Studio**

You can configure Neutrinos Studio to use a proxy server to communicate with Neutrinos hosted services such as IDS, Store & Console.

Refer [Setup Proxy on Neutrinos Studio](/articles/app-builder-s-user-guide/setup-proxy-on-neutrinos-studio) to learn more.

- Accomodated Connection Strings into the Oracle Database Configuration.

Refer [Oracle database configuration](/smart/project-server-side-service-designer/configure-oracle-database) to learn more.
