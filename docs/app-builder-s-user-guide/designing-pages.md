# Design Pages

<https://documentation.neutrinos.com/articles/#!app-builder-s-user-guide/designing-pages>

To design a [page](/smart/project-concepts/page), click **Pages** in the editor pane and select a page. The Page Designer opens up and displays a palette list with components that you can drag and drop to design your app pages.

To design pages, you drag the components from the **Palette list** and drop them to the** Page** **Container**. You double-click the component to open its attributes window.![](/resources/Storage/app-builder-s-user-guide/page_parts.png)


 Components such as **Row** and **Column**, have droppable regions that allow you to add other components within these components. Components such as **Card, ****Table**, etc. have their sub-components grouped together and are displayed as an advanced component. To create your own component and add it to the Neutrinos Studio , see [Create your Own Component](/smart/project-create-a-widget/create-component).
 Attributes WindowEach component on a page container has properties associated with it. Double-click the component to view its Attributes window and enter values for the existing properties.To learn about attributes for the component, click the ![](/resources/Storage/app-builder-s-user-guide/help_icon.png) icon. The respective component documentation opens up.Set Basic Attributes![basic properties](/resources/Storage/app-builder-s-user-guide/basic_props.png)






 Set Custom Properties![custom properties](/resources/Storage/app-builder-s-user-guide/custom_props.png)You can add your own custom properties using the** Custom Properties** drop-down. A custom property is a property that is not available by default. You can create your own custom properties based on your app requirements. To create a custom property, click the **Custom Properties** drop-down list in the Attributes window. Depending on the type of property you want to create, toggle between **Attribute** or **Key&Value**. By default, **Attribute** is selected.




 If you select **Attribute**, enter the key data, and the Studio auto-completes the attribute's value field. If you select **Key/Value**, enter the key as well as the value data. Click **ADD** to add the custom property.
