# Create a Component

<https://documentation.neutrinos.com/articles/#!create-a-widget-on-studio-7/create-component>

Starting from version 7.1.0, you can create a component of your own and import it to Neutrinos Studio.

By default, Neutrinos Studio provides you a list of palette components for you to design your app pages. See [Default Palette Components](/articles/components-guide-7/components) to learn more.

Apart from the existing components, if you want to create your own component, perform these steps:

1. [Create a Studio Package](/articles/create-a-widget-on-studio-7/create-a-studio-package)
2. [Create a Component](/articles/create-a-widget-on-studio-7/create-component-file)or [Create an advanced component](/articles/create-a-widget-on-studio-7/create-advanced-component-file)
3. [Add assets and styles](/articles/create-a-widget-on-studio-7/package-a-component)
4. [Update index.js file](/articles/create-a-widget-on-studio-7/update-index-js-file)
