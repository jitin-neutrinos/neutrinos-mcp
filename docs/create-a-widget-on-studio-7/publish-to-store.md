# Publish to Store

<https://documentation.neutrinos.com/articles/#!create-a-widget-on-studio-7/publish-to-store>

Submit the .zip file of [components](/articles/concepts-publication/component), [angular packages](/smart/project-concepts/angular-package), and [app templates](/articles/create-a-widget-on-studio-7/create-an-app-template) to Neutrinos by raising a support ticket on [support@neutrinos.co](mailto:support@neutrinos.co).

The Neutrinos team will review the plugin and upload it to [Neutrinos Store](/smart/project-concepts/neutrinos-store).
